- **Temas incluidos:** Acceso a Microsoft Teams desde el correo institucional de Microsoft.

## Procedimiento: Acceder a Microsoft Teams

### Propósito
Acceder a Microsoft Teams. (Fuente: páginas 1–5)

### Requisitos y permisos
- Iniciar sesión en el correo institucional de Microsoft con el usuario y la contraseña de Microsoft. No se reproducen credenciales. (Fuente: páginas 2–3)

### Pasos
1. Acceda al sitio web de Unisimon y vaya a **Servicios → Correo Estudiantes** para iniciar sesión en su correo institucional de Microsoft. (Fuente: página 2)
2. Inicie sesión con su usuario y contraseña de Microsoft. (Fuente: página 3)
3. Seleccione el icono de la aplicación Teams en el panel principal. (Fuente: página 4)

### Resultado esperado
La diapositiva 5 presenta una «Vista general de Teams». (Fuente: página 5)
