# Instructivo del Portal Profesores: calificaciones, inasistencias y listados

## Información del documento
- **Fuente original:** `Calificaciones.pdf`
- **Sistema o módulo:** Portal Profesores; módulo de Calificaciones. (Fuente: páginas 1–3)
- **Público o permisos mencionados por la fuente:** No se especifican permisos ni público. (Fuente: páginas 1–15)
- **Temas incluidos:** Ingreso al portal, registro de calificaciones e inasistencias y visualización de listados. (Fuente: páginas 1–15)

## Procedimiento: Ingresar al Portal Profesores
### Pasos
1. Desde la página web de la universidad, ingrese a la sección «Portales»: `http://www.unisimon.edu.co/portales`. (Fuente: página 2)
2. Ingrese su usuario y contraseña y presione el botón «Acceder». (Fuente: página 2)

## Procedimiento: Ingresar calificaciones
### Propósito
Registrar calificaciones de una asignatura y grupo. (Fuente: páginas 4–8)

### Pasos
1. Para ingresar al módulo, seleccione el ícono «Calificaciones». (Fuente: página 3)
2. En el menú lateral, seleccione «Registro de Calificaciones». (Fuente: página 4)
3. Seleccione el Programa Académico al que pertenece la asignatura donde desea registrar las calificaciones. (Fuente: página 4)
4. En el listado de asignaturas del período académico para el que va a ingresar calificaciones, ubique la asignatura y el grupo deseado. (Fuente: página 5)
5. Debajo del parcial que va a ingresar —Primero, segundo o examen final— seleccione el botón «Calificaciones» o «Diferido», según corresponda. Para asignaturas de posgrados, módulos o vacacionales, solo aparecerá la opción «Definitiva». (Fuente: página 5)
6. Tenga en cuenta que los botones «Calificaciones» y «Diferido» solo se visualizan para cada parcial si las fechas de ingreso de notas para este se encuentran activas. (Fuente: página 6)
7. Ingrese una por una las calificaciones correspondientes en el campo numérico. (Fuente: página 7)
8. Si desea registrar «N.P», seleccione la casilla que se encuentra justo al lado del campo numérico. Esto inhabilitará el campo numérico e indicará al sistema que no se debe digitar una calificación para ese estudiante. (Fuente: página 7)
9. Para mantener un registro temporal de las calificaciones sin finalizar el proceso, presione «Guardar Borrador». (Fuente: página 8)
10. Para enviar las notas contenidas en el borrador, presione «Finalizar». (Fuente: página 8)

### Resultado esperado
- Una vez finalizado el ingreso de calificaciones, el sistema redireccionará a la pantalla de asignaturas. (Fuente: página 9)
- Para descargar el listado de las notas enviadas, diríjase a «Listados» en el menú lateral del módulo de calificaciones. (Fuente: página 9)

### Errores, límites o excepciones documentadas
- Si se vuelve a ingresar a la pantalla de calificaciones de una asignatura cuyas calificaciones ya fueron enviadas, el sistema arrojará un mensaje. El texto del mensaje no está incluido en la fuente extraída. (Fuente: página 9)
- Para posgrados, módulos o vacacionales, solo aparece la opción «Definitiva». (Fuente: página 5)
- Los botones «Calificaciones» y «Diferido» solo se visualizan cuando las fechas de ingreso de notas para el parcial están activas. (Fuente: página 6)

## Procedimiento: Ingresar inasistencias
### Propósito
Registrar inasistencias de estudiantes de una asignatura y grupo. (Fuente: páginas 10–12)

### Pasos
1. En el menú lateral, seleccione «Inasistencias». (Fuente: página 10)
2. Seleccione el Programa Académico al que pertenece la asignatura donde desea registrar las inasistencias. (Fuente: página 10)
3. En el listado de asignaturas del período académico para el que va a ingresar las inasistencias, seleccione el ícono indicado para la asignatura y el grupo deseado. (Fuente: página 11)
4. Seleccione el día, la hora de inicio y el número de horas dictadas. (Fuente: página 12)
5. Seleccione la casilla de verificación correspondiente al estudiante al que se le registrará la inasistencia. (Fuente: página 12)
6. Presione «Guardar». (Fuente: página 12)
7. Repita el procedimiento cada vez que vaya a registrar inasistencias para un estudiante o desee cambiar el día de registro de inasistencias. (Fuente: página 12)
8. Para terminar el proceso, seleccione el botón «Cerrar.». (Fuente: página 12)

## Procedimiento: Visualizar listados
### Propósito
Acceder a los listados disponibles: toma de asistencia, toma de notas, listado en Excel, reporte de novedades, correos de estudiantes y notas enviadas. (Fuente: página 13)

### Pasos
1. En el menú lateral, seleccione «Listados». (Fuente: página 13)
2. Seleccione el Programa Académico al que pertenece la asignatura de la que desea visualizar el listado. (Fuente: página 13)
3. En el listado de asignaturas del período académico para el que va a visualizar los listados, seleccione el ícono indicado para la asignatura y el grupo deseado. (Fuente: página 14)
4. Entre las opciones disponibles, seleccione el listado que desea visualizar. (Fuente: página 15)
5. Seleccione el tipo de parcial para el que generará el listado. Esta selección no aparecerá si la asignatura corresponde a posgrados o módulos, o si se trata de un vacacional. (Fuente: página 15)
6. Presione «Listado». (Fuente: página 15)

### Errores, límites o excepciones documentadas
- La selección del tipo de parcial no aparece para asignaturas de posgrados o módulos ni para vacacionales. (Fuente: página 15)
