# Generar el reporte de estudiantes matriculados en SIAAF WEB

## Información del documento
- **Fuente original:** `Reporte de estudiantes matriculados.pptx`
- **Sistema o módulo:** SIAAF WEB; módulo «Estadísticas Institucionales».
- **Público o permisos mencionados por la fuente:** «Profesores y Administrativos»; se solicita usuario y contraseña para acceder.
- **Temas incluidos:** Acceso al portal, selección de sede y generación del reporte de estudiantes matriculados.

## Procedimiento: Generar el reporte de estudiantes matriculados

### Propósito
Generar el reporte de estudiantes matriculados. (Fuente: diapositivas 1, 7–8)

### Requisitos y permisos
- Acceder al sistema con usuario y contraseña. (Fuente: diapositiva 4)
- La fuente no especifica requisitos adicionales ni permisos concretos. (Fuente: diapositivas 1–8)

### Pasos
1. Desde un navegador, ingrese al sitio web de la Universidad: `http://www.unisimon.edu.co/`. En el menú principal, seleccione «Portales». (Fuente: diapositiva 2)
2. Diríjase a la sección «Portal Profesores y Administrativos». (Fuente: diapositiva 3)
3. Digite su usuario y contraseña para acceder al sistema y presione el botón «Acceder». (Fuente: diapositiva 4)
4. Luego de ingresar al sistema, seleccione el módulo «Estadísticas Institucionales». (Fuente: diapositiva 5)
5. En la sección «Estudiantes», seleccione la sede para la cual generará el reporte. (Fuente: diapositiva 6)
6. En la sección «Distribución de estudiantes Matriculados», presione el botón «Ver». (Fuente: diapositiva 7)
7. Seleccione el Año, Periodo y Filtro. Posteriormente, presione el botón «Generar». (Fuente: diapositiva 8)

### Puntos por validar
- La diapositiva 7 contiene la frase «presionar el botón “Ver” el la sección»; se interpretó «el la» como una errata y se conservó la ubicación indicada: sección «Distribución de estudiantes Matriculados». (Fuente: diapositiva 7)
- El texto extraído no indica qué opciones hay para sede, Año, Periodo o Filtro, ni el resultado que aparece después de presionar «Generar». (Fuente: diapositivas 6–8)
