# Gestión de prácticas formativas: gestión de requisitos, permisos y reporte

## Información del documento
- **Fuente original:** `Gestión Prácticas - Funcionarios.pdf`
- **Sistema o módulo:** Gestión de Prácticas Formativas
- **Público o permisos mencionados por la fuente:** La fuente indica que los programas y cursos listados corresponden a los que el usuario tenga permiso asignado.
- **Temas incluidos:** Acceso al sistema, búsqueda, gestión de requisitos, notificación al estudiante, gestión de permisos y descarga del reporte.

## Procedimiento: Acceder a Gestión de Prácticas Formativas y buscar

### Pasos
1. Desde la página web de la Universidad, ingrese en la sección “Portales” mediante `http://www.unisimon.edu.co/portales/administrativos`. (Fuente: página 3)
2. Ingrese su usuario y contraseña y presione el botón “Acceder”. (Fuente: página 3)
3. Seleccione “Gestión de Prácticas Formativas”. (Fuente: página 4)
4. Para realizar la búsqueda, además de los filtros obligatorios, se recomienda seleccionar al menos uno de los filtros opcionales. Por último, seleccione el botón “Buscar”. (Fuente: página 5)

### Requisitos y permisos
- Los programas listados corresponderán a los que el usuario tenga permiso asignado. (Fuente: página 5)
- Los cursos listados corresponderán a los que el usuario tenga permiso asignado. (Fuente: página 5)
- La página 5 enumera los filtros “Documento”, “Código”, “Nombres” y “Apellidos”, pero no permite determinar cuáles son obligatorios y cuáles opcionales. (Fuente: página 5)

### Puntos por validar
- Confirmar cuáles de los filtros “Documento”, “Código”, “Nombres” y “Apellidos” son obligatorios y cuáles opcionales. La extracción presenta las etiquetas “Filtros Obligatorios” y “Filtros Opcionales”, pero no establece con claridad la correspondencia con cada filtro. (Fuente: página 5)

## Procedimiento: Gestionar requisitos

### Propósito
Gestionar los requisitos de prácticas formativas. (Fuente: páginas 2 y 6)

### Pasos
1. Seleccione el botón “Requisitos”. (Fuente: página 6)
2. En las acciones de gestión de requisitos, la fuente enumera “Aprobar documento”, “Ver documento”, “Reemplazar documento” y “Actualizar listado”; también muestra los estados “Aprobado” y “Pendiente”. (Fuente: página 7)
3. Para las acciones de gestión de requisitos, seleccione uno o más documentos. (Fuente: página 8)

### Errores, límites o excepciones documentadas
- La fuente no especifica qué acción corresponde a cada estado ni detalla los pasos para aprobar, ver o reemplazar un documento, o actualizar el listado. (Fuente: páginas 7–8)

### Puntos por validar
- La página 8 incluye una descripción automática de una ventana de confirmación con las opciones “Aceptar” y “Cancelar”, pero el texto extraído no confirma de forma fiable el mensaje ni a qué acción pertenece. (Fuente: página 8)

## Procedimiento: Enviar una notificación por correo electrónico al estudiante

### Propósito
Enviar un correo electrónico al estudiante. (Fuente: página 9)

### Pasos
1. Seleccione el botón “Notificación”. (Fuente: página 9)

## Procedimiento: Gestionar permisos

### Propósito
Consultar, eliminar o asignar permisos mediante las diferentes opciones. (Fuente: páginas 10–12)

### Pasos
1. Seleccione el botón “Permisos”. (Fuente: página 11)
2. Para consultar, eliminar o asignar permisos, haga uso de las diferentes opciones. La fuente identifica “Filtro de búsqueda (opcional)”, “Eliminar” y “Asignar permiso”. (Fuente: página 12)
3. Para realizar la búsqueda, seleccione el tipo y la consulta, y luego el botón “Buscar”. (Fuente: página 13)
4. Seleccione el registro deseado y luego el botón “Seleccionar”. (Fuente: página 13)

### Puntos por validar
- La fuente no especifica qué tipos de búsqueda están disponibles ni qué consulta debe ingresarse. (Fuente: página 13)
- La fuente no precisa cómo se ejecutan las acciones “Eliminar” y “Asignar permiso”, ni qué permisos pueden asignarse. (Fuente: página 12)

## Procedimiento: Descargar el reporte en formato Excel

### Pasos
