# Autorización de cursos intersemestrales en SIA WEB

## Información del documento
- **Fuente original:** *Autorizaciones cursos intersemestrales.pptx*
- **Sistema o módulo:** SIA WEB; módulo «Matrícula».
- **Público o permisos mencionados por la fuente:** El acceso se realiza desde «Portal Profesores y Administrativos». La fuente no especifica permisos adicionales.
- **Temas incluidos:** Acceso al portal, búsqueda de cursos intersemestrales y confirmación de la autorización.

## Procedimiento: Autorizar un curso intersemestral

### Propósito
Realizar la autorización de un curso intersemestral. Luego de la autorización, el estudiante podrá descargar el volante de pago. (Fuente: diapositivas 2, 9)

### Requisitos y permisos
La fuente indica el acceso mediante «Portal Profesores y Administrativos» y solicita usuario y contraseña. (Fuente: diapositivas 4–5)

### Pasos
1. Desde un navegador, ingrese al sitio web de la Universidad: http://www.unisimon.edu.co/ y seleccione «Portales» en el menú principal. (Fuente: diapositiva 3)
2. Diríjase a la sección «Portal Profesores y Administrativos». (Fuente: diapositiva 4)
3. Digite su usuario y contraseña para acceder al sistema y presione el botón «Acceder». (Fuente: diapositiva 5)
4. Una vez dentro del sistema, seleccione el módulo «Matrícula». (Fuente: diapositiva 6)
5. Ingrese a la sección «Autorización de cursos Intersemestrales». (Fuente: diapositiva 7)
6. Seleccione los filtros de búsqueda de año, periodo, programa y curso para realizar la autorización. (Fuente: diapositiva 8)
7. Ubique al estudiante y presione el icono indicado para realizar la autorización. Únicamente se podrán autorizar los cursos que presenten una oferta activa. (Fuente: diapositiva 9)
8. Para finalizar el proceso, confirme la autorización realizada. (Fuente: diapositiva 10)

### Resultado esperado
Una vez realizada la autorización, el estudiante podrá descargar el volante de pago. (Fuente: diapositiva 9)

### Errores, límites o excepciones documentadas
- Únicamente se podrán autorizar los cursos que presenten una oferta activa. (Fuente: diapositiva 9)
