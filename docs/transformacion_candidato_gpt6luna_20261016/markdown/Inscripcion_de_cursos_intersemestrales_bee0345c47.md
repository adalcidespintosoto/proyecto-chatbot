## Procedimiento: Inscribir cursos intersemestrales

### Propósito
Realizar la inscripción de cursos intersemestrales en SIA WEB. (Fuente: página 2)

### Requisitos y permisos
- Se requiere usuario y contraseña para acceder al sistema. (Fuente: página 5)
- El listado muestra cursos ofertados que se encuentran permitidos para la inscripción. (Fuente: página 7)

### Pasos
1. Desde un navegador, ingrese al sitio web de la Universidad: `http://www.unisimon.edu.co/`. En el menú principal, seleccione «Portales». (Fuente: página 3)
2. Diríjase a la sección «Portal Estudiantes». (Fuente: página 4)
3. Digite su usuario y contraseña y presione el botón «Acceder». (Fuente: página 5)
4. Una vez dentro del sistema, seleccione el módulo «Cursos Intersemestrales». (Fuente: página 6)
5. En el listado, revise los cursos ofertados que estén permitidos para su inscripción y seleccione los cursos intersemestrales que desea inscribir. (Fuente: página 7)
6. Para oficializar la inscripción, presione el botón «Inscribir». (Fuente: página 8)
7. Finalice el proceso confirmando los cursos intersemestrales que va a inscribir. (Fuente: página 9)

### Resultado esperado
- Podrá descargar un reporte de los cursos inscritos mediante el botón «Informe». (Fuente: página 10)
- El volante de pago se podrá generar únicamente cuando su programa académico autorice la inscripción a los cursos intersemestrales seleccionados. Para descargarlo, use el botón «Volante». (Fuente: página 11)
