## Procedimiento: Generar el informe de Matrícula completa / Media matrícula

### Propósito
Crear el informe «Matrícula completa / Media matrícula» en un documento PDF para su visualización. (Fuente: diapositivas 1, 6–7)

### Requisitos y permisos
- El instructivo indica acceder mediante el «Portal Profesores y Administrativos». (Fuente: diapositiva 3)
- Se requieren usuario y contraseña para acceder al sistema. (Fuente: diapositiva 4)

### Pasos
1. Desde un navegador, ingrese al sitio web de la Universidad: `http://www.unisimon.edu.co/`. (Fuente: diapositiva 2)
2. En el menú principal, seleccione «Portales». (Fuente: diapositiva 2)
3. Diríjase a la sección «Portal Profesores y Administrativos». (Fuente: diapositiva 3)
4. Digite su usuario y contraseña y presione el botón «Acceder». (Fuente: diapositiva 4)
5. Luego de ingresar al sistema, seleccione el módulo «Rectoría». (Fuente: diapositiva 5)
6. Luego de ingresar al módulo, seleccione el informe «Matrícula completa / Media matrícula». (Fuente: diapositiva 6)
7. Aplique los filtros solicitados: Año, Periodo y Fecha. (Fuente: diapositiva 7)
8. Presione el botón «Generar». (Fuente: diapositiva 7)

### Resultado esperado
Se crea el reporte en un documento PDF para su visualización. (Fuente: diapositiva 7)
