## Procedimiento: Generar el informe «Transferencia Externa»

### Propósito
Generar el informe de inscripciones y matrículas de Transferencia Externa para visualizarlo en un documento PDF. (Fuente: diapositivas 1, 6–7)

### Requisitos y permisos
- Acceder por «Portal Profesores y Administrativos». (Fuente: diapositiva 3)
- Digitar el usuario y la contraseña para acceder al sistema. (Fuente: diapositiva 4)

### Pasos
1. Desde un navegador, ingresar al sitio web de la Universidad: `http://www.unisimon.edu.co/`. En el menú principal, seleccionar «Portales». (Fuente: diapositiva 2)
2. Dirigirse a la sección «Portal Profesores y Administrativos». (Fuente: diapositiva 3)
3. Digitar el usuario y la contraseña, y presionar el botón «Acceder». (Fuente: diapositiva 4)
4. Luego de ingresar al sistema, seleccionar el módulo «Rectoría». (Fuente: diapositiva 5)
5. Dentro del módulo, seleccionar el informe «Transferencia Externa». (Fuente: diapositiva 6)
6. Aplicar los filtros solicitados: «Año», «Periodo» y «Fecha». (Fuente: diapositiva 7)
7. Presionar el botón «Generar». (Fuente: diapositiva 7)

### Resultado esperado
El botón «Generar» crea el reporte en un documento PDF para su visualización. (Fuente: diapositiva 7)
