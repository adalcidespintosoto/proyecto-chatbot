# Carga de Códigos EK en SIA WEB

## Información del documento
- **Fuente original:** `Carga de codigos EK.pdf`
- **Sistema o módulo:** SIA WEB; módulo «Matrículas». (Fuente: páginas 2 y 6)
- **Público o permisos mencionados por la fuente:** «Portal Profesores y Administrativos». (Fuente: página 4)
- **Temas incluidos:** Acceso al portal, ingreso al sistema y carga masiva de códigos EK. (Fuente: páginas 3–10)

## Procedimiento: Carga masiva de códigos EK

### Propósito
Adjuntar un documento con los códigos EK correspondientes a los estudiantes, revisar el estado de cada registro y procesar la información. (Fuente: páginas 9–10)

### Requisitos y permisos
- La fuente indica que se debe acceder mediante «Portal Profesores y Administrativos». (Fuente: página 4)
- Se requieren un usuario y una contraseña para acceder al sistema. No se reproducen credenciales. (Fuente: página 5)
- Se necesita un documento con los códigos EK correspondientes a los estudiantes. (Fuente: página 9)

### Pasos
1. Desde un navegador, ingresar al sitio web de la Universidad: `http://www.unisimon.edu.co/`. En el menú principal, seleccionar «Portales». (Fuente: página 3)
2. Dirigirse a la sección «Portal Profesores y Administrativos». (Fuente: página 4)
3. Digitar el usuario y la contraseña para acceder al sistema y presionar el botón «Acceder». (Fuente: página 5)
4. Luego de ingresar al sistema, seleccionar el módulo «Matrículas». (Fuente: página 6)
5. Seleccionar el icono «Código EK». (Fuente: página 7)
6. Seleccionar la opción «Cargue masivo Código EK». (Fuente: página 8)
7. Para adjuntar el documento con los códigos EK de los estudiantes, seleccionar el botón «Seleccionar archivo» y, posteriormente, presionar «Cargar». (Fuente: página 9)
8. Revisar la información listada del documento cargado y el estado de cada registro, entre ellos «Valido» y «No válido». Luego de confirmar, almacenar la información presionando el botón «Procesar». (Fuente: página 10)

### Resultado esperado
La información se almacena al presionar «Procesar», después de revisar la información listada y confirmar. (Fuente: página 10)

### Errores, límites o excepciones documentadas
- Los registros pueden aparecer con estado «Valido» o «No válido». La fuente no describe acciones adicionales para los registros no válidos. (Fuente: página 10)
