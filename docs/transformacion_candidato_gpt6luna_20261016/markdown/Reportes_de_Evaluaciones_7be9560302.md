# Generar reportes de evaluaciones en SIAAF WEB

## Información del documento
- **Fuente original:** `Reportes de Evaluaciones.pdf`
- **Sistema o módulo:** SIAAF WEB; módulo “Gestión de Evaluaciones”.
- **Público o permisos mencionados por la fuente:** Se indica ingresar por «Portal Profesores y Administrativos». No se especifican permisos.
- **Temas incluidos:** Acceso al sistema y generación de reportes de evaluaciones.

## Procedimiento: Generar un reporte de evaluaciones

### Propósito
Generar un reporte de evaluaciones. (Fuente: páginas 1, 7–8)

### Pasos
1. Desde un navegador, ingrese al sitio web de la Universidad: `http://www.unisimon.edu.co/`. En el menú principal, seleccione «Portales». (Fuente: página 2)
2. Diríjase a «Portal Profesores y Administrativos». (Fuente: página 3)
3. Digite su usuario y contraseña para acceder al sistema y presione el botón «Acceder». (Fuente: página 4)
4. Luego de ingresar, seleccione el módulo “Gestión de Evaluaciones”. (Fuente: página 5)
5. En el menú principal, seleccione «Reportes». (Fuente: página 6)
6. Seleccione el reporte que desea generar. (Fuente: página 7)
7. Aplique los filtros de búsqueda necesarios según el tipo de reporte y presione el botón «Buscar». (Fuente: página 8)
