# Reporte de inscripciones reactivadas en SIA WEB

## Información del documento
- **Fuente original:** `Reporte - Inscripción Reactivada.pptx`
- **Sistema o módulo:** SIA WEB; módulo «Matricula»
- **Público o permisos mencionados por la fuente:** Portal Profesores y Administrativos
- **Temas incluidos:** Acceso a SIA WEB y consulta del reporte de inscripciones reactivadas

## Procedimiento: Consultar el reporte de inscripciones reactivadas

### Propósito
Generar la información del reporte de inscripciones reactivadas mediante filtros. (Fuente: diapositivas 2, 7–8)

### Requisitos y permisos
- Acceder mediante el «Portal Profesores y Administrativos». (Fuente: diapositiva 4)
- Se requieren usuario y contraseña para acceder al sistema. (Fuente: diapositiva 5)

### Pasos
1. Desde un navegador, ingresar al sitio web de la Universidad: http://www.unisimon.edu.co/ y seleccionar «Portales» en el menú principal. (Fuente: diapositiva 3)
2. Dirigirse a la sección «Portal Profesores y Administrativos». (Fuente: diapositiva 4)
3. Digitar el usuario y la contraseña, y presionar el botón «Acceder». (Fuente: diapositiva 5)
4. Después de ingresar al sistema, seleccionar el módulo «Matricula». (Fuente: diapositiva 6)
5. Seleccionar el apartado «Inscripciones reactivadas». (Fuente: diapositiva 7)
6. Llenar los filtros obligatorios «año» y «periodo». Los filtros «nivel» y «programa» son opcionales. (Fuente: diapositiva 8)
7. Presionar el botón «buscar». (Fuente: diapositiva 8)

### Resultado esperado
La información se genera automáticamente después de presionar «buscar». (Fuente: diapositiva 8)
