- **Público o permisos mencionados por la fuente:** Portal Profesores y Administrativos. El instructivo indica que se debe ingresar con usuario y contraseña, pero no especifica permisos adicionales.
- **Temas incluidos:** Acceso al sistema, búsqueda de matrículas pendientes y oficialización de matrículas de cursos intersemestrales.

## Procedimiento: Oficializar matrículas de cursos intersemestrales

### Propósito
Realizar la oficialización de matrículas de cursos intersemestrales. (Fuente: diapositivas 2 y 8)

### Requisitos y permisos
- Acceder al «Portal Profesores y Administrativos» e ingresar usuario y contraseña. (Fuente: diapositivas 4–5)
- Para que un estudiante aparezca en el listado de matrículas pendientes por oficializar, debe estar inscrito, haber sido aprobado para aplicar al curso y haber realizado el pago del volante correspondiente. (Fuente: diapositiva 10)

### Pasos
1. Desde un navegador, ingrese al sitio web de la Universidad: `http://www.unisimon.edu.co/`. En el menú principal, seleccione «Portales». (Fuente: diapositiva 3)
2. Diríjase a la sección «Portal Profesores y Administrativos». (Fuente: diapositiva 4)
3. Digite su usuario y contraseña para acceder al sistema y presione el botón «Acceder». (Fuente: diapositiva 5)
4. Después de ingresar al sistema, seleccione el módulo «Matrícula». (Fuente: diapositiva 6)
5. Ingrese a la sección «Autorización de cursos intersemestrales». (Fuente: diapositiva 7)
6. Seleccione los filtros de búsqueda de año, periodo, programa y curso para realizar la oficialización de las matrículas. (Fuente: diapositiva 8)
7. Presione el botón «Oficializar». (Fuente: diapositiva 9)
8. En el listado de matrículas pendientes por oficializar, se mostrarán únicamente los estudiantes que estén inscritos, hayan sido aprobados para aplicar al curso y hayan realizado el pago del volante correspondiente. (Fuente: diapositiva 10)
9. Para finalizar el proceso de matrícula, presione el botón «Oficializar». (Fuente: diapositiva 11)

### Puntos por validar
- El instructivo indica presionar «Oficializar» después de seleccionar los filtros y, más adelante, volver a presionarlo para finalizar el proceso. No aclara si el primer uso del botón genera o muestra el listado de matrículas pendientes. (Fuente: diapositivas 8–11)
- Las descripciones automáticas de las imágenes de las diapositivas 3–5 y 9–11 están marcadas como no verificadas y contienen menús extensos o repetidos; no se usan para añadir pasos o nombres de opciones no indicados en el texto principal.
