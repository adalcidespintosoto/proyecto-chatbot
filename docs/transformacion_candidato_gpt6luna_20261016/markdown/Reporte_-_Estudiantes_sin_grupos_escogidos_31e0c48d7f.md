## Procedimiento: Consultar el reporte «Estudiantes sin grupos escogidos»

### Propósito
Consultar información de estudiantes sin horario escogido (00). (Fuente: página 10)

### Requisitos y permisos
- La fuente indica dirigirse a la sección «Portal Profesores y Administrativos» y acceder al sistema con usuario y contraseña. No especifica requisitos adicionales ni permisos. (Fuente: páginas 4–5)

### Pasos
1. Desde un navegador, ingrese al sitio web de la Universidad: `http://www.unisimon.edu.co/`. En el menú principal, seleccione «Portales». (Fuente: página 3)
2. Diríjase a la sección «Portal Profesores y Administrativos». (Fuente: página 4)
3. Digite su usuario y contraseña para acceder al sistema y presione el botón «Acceder». (Fuente: página 5)
4. Seleccione el icono «Asignación Académica». (Fuente: página 6)
5. Seleccione el año y el período en el cual trabajará. Por defecto, se mostrará el período actual. El período indicará al sistema la información que mostrará en todo el módulo. (Fuente: página 7)
6. Después de definir el período, seleccione en el menú la opción «Reporte». (Fuente: página 8)
7. Entre las opciones, seleccione el reporte «Estudiantes sin grupos escogidos». (Fuente: página 8)
8. Complete los filtros, entre ellos: programa, semestre y código de curso. Luego presione «Buscar» para visualizar la información. (Fuente: página 9)
9. Para descargar el reporte en un documento Excel, use el botón «Excel». (Fuente: página 10)

### Resultado esperado
Se podrá visualizar la información de estudiantes sin horario escogido (00). (Fuente: página 10)

### Errores, límites o excepciones documentadas
- La fuente no documenta errores ni soluciones.
- El período actual aparece por defecto. (Fuente: página 7)
