## Procedimiento: Consultar y generar el reporte de proveedores activos

### Propósito
Consultar y generar el reporte «Proveedores activos» para su visualización. (Fuente: diapositivas 1, 6–7)

### Requisitos y permisos
- Acceder desde el «Portal Profesores y Administrativos». (Fuente: diapositiva 3)
- Digitar el usuario y la contraseña para acceder al sistema. (Fuente: diapositiva 4; no se reproducen credenciales)

### Pasos
1. Desde un navegador, ingresar al sitio web de la Universidad: `http://www.unisimon.edu.co/`. (Fuente: diapositiva 2)
2. En el menú principal, seleccionar «Portales». (Fuente: diapositiva 2)
3. Dirigirse a la sección «Portal Profesores y Administrativos». (Fuente: diapositiva 3)
4. Digitar el usuario y la contraseña y presionar el botón «Acceder». (Fuente: diapositiva 4)
5. Después de ingresar al sistema, seleccionar el módulo «Compras». (Fuente: diapositiva 5)
6. Dentro del módulo, seleccionar el informe «Proveedores activos». (Fuente: diapositiva 6)
7. Aplicar los filtros solicitados «Fecha inicio» y «Fecha fin». Luego, presionar el botón «Generar». (Fuente: diapositiva 7)

### Resultado esperado
El botón «Generar» crea el reporte para su visualización. (Fuente: diapositiva 7)

- No se documentan errores ni límites.

## Procedimiento: Imprimir o exportar el reporte de proveedores activos

### Pasos
1. Al finalizar el proceso, se puede imprimir el reporte o exportarlo a Excel con los botones correspondientes. (Fuente: diapositiva 8)
