## Procedimiento: Realizar la evaluación de jefe inmediato

### Propósito
Realizar la evaluación de jefe inmediato para los docentes que aparezcan pendientes por evaluar. (Fuente: páginas 5–7)

### Requisitos y permisos
- Se indica que se debe ingresar con usuario y contraseña. (Fuente: página 4)

### Pasos
1. Desde un navegador, ingrese al sitio web de la Universidad: `http://www.unisimon.edu.co/`, y seleccione en el menú principal la opción «Portales». (Fuente: página 2)
2. Diríjase a la sección «Portal Profesores y Administrativos». (Fuente: página 3)
3. Digite su usuario y contraseña para acceder al sistema y presione el botón «Acceder». (Fuente: página 4)
4. Luego de ingresar al sistema, seleccione el módulo «Evaluación Jefe Inmediato». (Fuente: página 5)
5. En la ventana siguiente, revise el listado de docentes pendientes por evaluar. Para iniciar una evaluación, presione el botón «Comenzar». (Fuente: página 6)
6. En la ventana de evaluación, seleccione una respuesta para cada pregunta. Para finalizar la escogencia de todas las respuestas, presione «Guardar» y continúe con el mismo proceso para las siguientes asignaturas. (Fuente: página 7)

### Resultado esperado
- Al finalizar una evaluación, esta se muestra automáticamente con un icono que indica que ha sido finalizada. (Fuente: página 6)

### Errores, límites o excepciones documentadas
- El sistema no permite finalizar una evaluación si no se han escogido todas sus respuestas. (Fuente: página 7)
