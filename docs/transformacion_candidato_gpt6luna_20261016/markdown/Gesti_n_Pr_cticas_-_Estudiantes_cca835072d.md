# Carga de requisitos para prácticas formativas en el Portal de Estudiantes

## Información del documento
- **Fuente original:** Gestión Prácticas - Estudiantes.pdf
- **Sistema o módulo:** Portal de Estudiantes; formulario de carga de requisitos para prácticas formativas.
- **Público o permisos mencionados por la fuente:** Estudiantes que ingresan al Portal de Estudiantes.
- **Temas incluidos:** Acceso al portal, validación de matrícula y grupo, carga de archivos y seguimiento del estado de los requisitos.

## Procedimiento: Cargar requisitos para prácticas formativas

### Propósito
Cargar en el formulario los documentos correspondientes a los requisitos de prácticas formativas. (Fuente: páginas 1, 3 y 5–7)

### Requisitos y permisos
- Para ingresar al Portal de Estudiantes, se indica que se debe ingresar el usuario y la contraseña. (Fuente: página 2)
- Al ingresar al portal, el sistema valida automáticamente que el estudiante cuente con una matrícula y un grupo asignado a un curso de prácticas formativas. (Fuente: página 3)

### Pasos
1. Desde la página web de la Universidad, entre en la sección **“Portales”**: https://www.unisimon.edu.co/portales/estudiantes. Ingrese su usuario y contraseña y presione **“Acceder”**. (Fuente: página 2)
2. Al ingresar al Portal de Estudiantes, el sistema validará automáticamente si cuenta con una matrícula y un grupo asignado a un curso de prácticas formativas. (Fuente: página 3)
3. En el formulario, revise las secciones del requisito. La fuente identifica el nombre del requisito, la fase o estado, los detalles e instrucciones del documento que se debe cargar, el espacio para cargar el archivo y las características del archivo. También menciona requisitos obligatorios, requisitos opcionales —con una observación— e instrucciones. (Fuente: páginas 4–5)
4. Para cargar un archivo por separado, seleccione el archivo correspondiente al requisito en el campo **“Seleccionar archivo”** y haga clic en **“Cargar archivo(s)”**. (Fuente: página 5)
5. Para hacerlo mediante los pasos ilustrados: haga clic en **“Seleccionar archivo”**; seleccione el archivo y haga clic en **“Abrir”**; luego haga clic en **“Cargar archivo(s)”**. (Fuente: página 6)
6. En cada requisito, consulte el campo **“Estado”** para saber si el documento fue aprobado o sigue pendiente por verificar. Consulte también **“Observación”**, donde se muestra información relevante sobre el documento que se debe cargar, como formato, tamaño máximo (peso) e instrucciones. (Fuente: página 7)
7. Si aparece un mensaje como **“Formato no válido”** o **“El archivo excede el tamaño permitido”**, verifique las características establecidas para el requisito e intente nuevamente. (Fuente: página 7)

### Resultado esperado
- El formulario seguirá apareciendo cada vez que ingrese mientras no se hayan aprobado todos los requisitos que debe cargar. (Fuente: páginas 3 y 7)
- El formulario dejará de aparecer cuando todos los requisitos cargados hayan sido aprobados por el programa académico. (Fuente: página 7)

### Errores, límites o excepciones documentadas
- El formulario solo podrá cerrarse cuando ya se hayan cargado todos los requisitos obligatorios. (Fuente: página 3)
- La fuente indica que los requisitos obligatorios se muestran en color rojo. (Fuente: página 7)
- Los mensajes **“Formato no válido”** y **“El archivo excede el tamaño permitido”** pueden aparecer al cargar un archivo; la fuente indica verificar las características del requisito e intentar nuevamente. (Fuente: página 7)
- Los requisitos opcionales aparecen acompañados de la indicación **“leer observación”**. (Fuente: página 4)
