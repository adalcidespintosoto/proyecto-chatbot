# Instructivo para generar una condonación de saldo de cartera castigada en SIAAF WEB

## Información del documento
- **Fuente original:** `Condonación de saldo cartera castigada.pptx`
- **Sistema o módulo:** SIAAF WEB; módulo «Crédito», opción «Crédito Interno»
- **Público o permisos mencionados por la fuente:** Se indica ingresar por «Portal Profesores y Administrativos». No se especifican permisos adicionales.
- **Temas incluidos:** Acceso al sistema y búsqueda de un crédito para la opción «Condonación de saldo (Cartera castigada)».

## Procedimiento: Acceder a la opción de condonación y buscar un crédito

### Propósito
La fuente presenta un instructivo para generar una condonación de saldo de cartera castigada. (Fuente: diapositiva 1)

### Pasos
1. Desde un navegador, ingrese al sitio web de la Universidad: `http://www.unisimon.edu.co/`. En el menú principal, seleccione «Portales». (Fuente: diapositiva 2)
2. Diríjase a la sección «Portal Profesores y Administrativos». (Fuente: diapositiva 3)
3. Digite su usuario y contraseña para acceder al sistema y presione el botón «Acceder». (Fuente: diapositiva 4)
4. Luego de ingresar, seleccione el módulo «Crédito». (Fuente: diapositiva 5)
5. Seleccione la opción «Crédito Interno». (Fuente: diapositiva 6)
6. Acceda a la opción «App». (Fuente: diapositiva 7)
7. Seleccione «Condonación de saldo (Cartera castigada)». (Fuente: diapositiva 8)
8. Digite el número de crédito y presione el botón «Buscar». (Fuente: diapositiva 9)
