# Gestión de Ingreso de Estudiantes

## Información del documento
- **Fuente original:** `Gestión de Ingreso - Funcionarios.pdf`
- **Sistema o módulo:** Portal; opción “Gestión de Ingreso de Estudiantes”.
- **Público o permisos mencionados por la fuente:** Las opciones de los campos “Proceso”, “Niveles” y “Programas” dependen de los permisos asociados al usuario. Aprobar requisitos está sujeto a permisos de usuario; editar campos de la hoja de vida requiere permiso para hacerlo. Los requisitos documentales deben ser aprobados por un usuario del área u oficina responsable de cada requisito.
- **Temas incluidos:** Ingreso al portal, consulta de aspirantes, requisitos, hoja de vida, admisión, notificaciones, estado de requisitos e informe de aspirantes.

## Procedimiento: Ingresar al módulo y consultar aspirantes

### Propósito
El módulo permite consultar y gestionar el proceso de admisión de un aspirante, desde la inscripción hasta la matrícula. (Fuente: páginas 3–4)

### Pasos
1. Desde la página web de la universidad, ingrese a la sección “Portales”: `http://www.unisimon.edu.co/portales/administrativos`. Ingrese su usuario y contraseña y presione “Acceder”. (Fuente: página 2)
2. Una vez dentro del Portal, seleccione “Gestión de Ingreso de Estudiantes”. (Fuente: página 3)
3. Para consultar aspirantes, seleccione el proceso, periodo, nivel y programa académico. Las opciones disponibles en “Proceso”, “Niveles” y “Programas” dependen de los permisos asociados a su usuario. (Fuente: página 5)
4. De manera opcional, personalice la búsqueda seleccionando opciones en el campo “Tipo de Búsqueda” e ingresando un texto en el campo “Buscar”. (Fuente: página 5)
5. Seleccione “Buscar”. (Fuente: página 5)

## Procedimiento: Gestionar requisitos de inscripción

### Propósito
Consultar, verificar y gestionar los requisitos de un aspirante. (Fuente: páginas 6 y 10–11)

### Requisitos y permisos
- La aprobación está sujeta a permisos de usuario. (Fuente: páginas 10–11)
- Los documentos cargados por aspirantes deben ser aprobados por un usuario del área u oficina responsable del requisito. (Fuente: página 11)
- Las pruebas o evaluaciones son verificadas automáticamente por el sistema; cuando se realiza la prueba o evaluación, el sistema marca el requisito como “realizado”. (Fuente: página 11)

### Pasos
1. Después de buscar al aspirante, seleccione “Requisitos”. Aparecerá una ventana con todos los requisitos que el aspirante deberá cargar. (Fuente: páginas 6 y 10)
2. Para cada requisito, según corresponda, puede realizar estas acciones:
   - **Aprobar:** aprobar el requisito, sujeto a los permisos de usuario y a la responsabilidad del área u oficina indicada para documentos cargados. (Fuente: páginas 10–11)
   - **Ver:** observar y posteriormente descargar los requisitos que sean documentos cargados. (Fuente: página 11)
   - **Actualizar/modificar documento:** reemplazar un archivo cargado por el aspirante si no cumple con lo solicitado o se encuentra dañado. (Fuente: páginas 10–11)
3. Cuando el aspirante cuente con todos los requisitos aprobados, seleccione “Confirmar inscripción”. (Fuente: página 10)

### Resultado esperado
- Las pruebas o evaluaciones realizadas quedan marcadas como “realizado” por el sistema. (Fuente: página 11)
- Cuando todos los requisitos estén aprobados, se puede seleccionar “Confirmar inscripción”. (Fuente: página 10)

## Procedimiento: Consultar o editar la hoja de vida

### Propósito
Consultar los datos que el aspirante ha registrado durante el proceso en trámite y, si se cuenta con permiso, modificarlos. (Fuente: página 12)

### Pasos
1. Seleccione “Hoja de vida”. Aparecerá una ventana con todos los datos que el aspirante ha registrado durante el proceso en trámite. (Fuente: página 12)
2. Si cuenta con permiso para editar campos del formulario, realice la modificación y seleccione “Guardar” para finalizarla. (Fuente: página 12)

## Procedimiento: Editar programa o tipo de admisión de una preinscripción

### Propósito
Modificar el programa o el tipo de admisión de la preinscripción seleccionada. (Fuente: páginas 7–8)

### Pasos
1. En la búsqueda de aspirantes, seleccione “Editar”. La opción permite modificar el programa y/o el tipo de admisión del registro seleccionado. (Fuente: páginas 6–8)
2. Al realizar una de estas modificaciones, los documentos previamente cargados por el aspirante también se modificarán automáticamente, siempre que sean requeridos en el nuevo programa y/o tipo de admisión. (Fuente: página 8)

### Errores, límites o excepciones documentadas
- Si existe una inscripción asociada al programa del registro seleccionado, el sistema indicará que primero se debe modificar la inscripción para que coincida con los parámetros de la preinscripción. (Fuente: página 8)
- Si existe un volante de pago asociado al registro:
  - El programa del volante se modificará únicamente si no está pagado.
  - Si se cambia el programa en la preinscripción sin alterar el volante, la modificación del volante debe hacerse mediante los procedimientos ya establecidos para ello. (Fuente: página 8)

## Procedimiento: Anular una preinscripción

### Propósito
Anular la preinscripción seleccionada. (Fuente: páginas 7 y 9)

### Pasos
1. En la búsqueda de aspirantes, seleccione “Anular”. (Fuente: páginas 6–7 y 9)
2. El sistema enviará un mensaje de confirmación. (Fuente: página 9)
3. Seleccione “Sí” para confirmar. (Fuente: página 9)

### Resultado esperado
Al confirmar, el registro desaparecerá del listado y el aspirante podrá iniciar nuevamente el proceso. (Fuente: página 9)

## Procedimiento: Admitir a un aspirante

### Propósito
Registrar el estado de admisión y el semestre al que ingresará el aspirante. La opción “Admisión” aplica solo para el proceso de selección. (Fuente: páginas 6 y 13)

### Requisitos y permisos
El aspirante debe haber completado los requisitos de inscripción y estos deben haber sido aprobados. (Fuente: página 13)

### Pasos
1. Seleccione “Admitir”. (Fuente: página 13)
2. Seleccione el estado de admisión y el semestre al cual ingresará el aspirante. Ambos campos son obligatorios. (Fuente: página 13)
3. Seleccione “Aceptar” para finalizar. (Fuente: página 13)

## Procedimiento: Enviar una notificación personalizada

### Propósito
Enviar al aspirante un correo personalizado para anunciar cualquier novedad o eventualidad presentada durante su proceso. (Fuente: páginas 6 y 14)

### Pasos
1. Seleccione “Notificación” para enviar el correo personalizado. (Fuente: páginas 6 y 14)

## Procedimiento: Consultar y descargar el estado de requisitos

### Propósito
Visualizar los últimos documentos cargados por los aspirantes de todos los procesos en trámite y descargar el listado en formato Excel. (Fuente: página 15)

### Pasos
1. Seleccione “Estado de requisitos” para visualizar los últimos documentos cargados por los aspirantes de todos los procesos en trámite. (Fuente: página 15)
2. Descargue el listado en formato Excel. (Fuente: página 15)

## Procedimiento: Descargar el informe de aspirantes

### Propósito
Para los programas de posgrado, descargar en formato Excel un listado de aspirantes según los criterios seleccionados y con información sobre los requisitos del proceso de selección y la ponderación de sus resultados. (Fuente: página 16)

### Pasos
1. Para un programa de posgrado, seleccione los criterios de periodo, nivel y programa. (Fuente: página 16)
2. Seleccione “Informe de aspirantes” para descargar el listado en formato Excel. El informe incluye los aspirantes correspondientes a los criterios seleccionados, los diferentes requisitos que deben cumplir durante el proceso de selección y la ponderación de los resultados de estos. (Fuente: página 16)
