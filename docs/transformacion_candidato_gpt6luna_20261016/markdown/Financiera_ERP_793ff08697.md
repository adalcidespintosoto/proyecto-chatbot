# Generar reportes de Financiera ERP en SIAAF WEB

## Información del documento
- **Fuente original:** `Financiera ERP.pptx`
- **Sistema o módulo:** SIAAF WEB; módulo Crédito, opción Crédito Interno
- **Público o permisos mencionados por la fuente:** Portal Profesores y Administrativos; se requiere ingresar con usuario y contraseña.
- **Temas incluidos:** Acceso al portal, navegación hasta los reportes y generación y descarga de un reporte de Financiera ERP.

## Procedimiento: Generar y exportar un reporte de Financiera ERP

### Propósito
Generar un reporte de Financiera ERP y descargarlo como documento de Excel. (Fuente: diapositivas 8–10)

### Requisitos y permisos
- Acceder al portal con usuario y contraseña. (Fuente: diapositiva 4)

### Pasos
1. Desde un navegador, ingresar al sitio web de la Universidad: `http://www.unisimon.edu.co/`. En el menú principal, seleccionar «Portales». (Fuente: diapositiva 2)
2. Dirigirse a la sección «Portal Profesores y Administrativos». (Fuente: diapositiva 3)
3. Digitar el usuario y la contraseña para acceder al sistema y presionar «Acceder». (Fuente: diapositiva 4)
4. Luego de ingresar, seleccionar el módulo «Crédito». (Fuente: diapositiva 5)
5. Seleccionar «Crédito Interno». (Fuente: diapositiva 6)
6. Acceder a «Reportes». (Fuente: diapositiva 7)
7. Para generar el reporte, seleccionar «Financiera ERP». (Fuente: diapositiva 8)
8. Aplicar los filtros necesarios seleccionando el tipo de reporte que se desea generar y la fecha de corte; luego, presionar «Previsualizar». (Fuente: diapositiva 9)
9. Para descargar el reporte como documento de Excel, presionar «Exportar a Excel». (Fuente: diapositiva 10)

### Resultado esperado
El reporte se puede descargar como documento de Excel. (Fuente: diapositiva 10)
