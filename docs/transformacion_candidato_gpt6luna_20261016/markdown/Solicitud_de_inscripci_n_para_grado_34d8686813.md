# Solicitud de inscripción para grado en el Portal de estudiantes

## Información del documento
- **Fuente original:** `Solicitud de inscripción para grado.pdf`
- **Sistema o módulo:** Portal de estudiantes; módulo «Solicitud de inscripción para grado».
- **Público o permisos mencionados por la fuente:** Usuario registrado que se encuentre en el último semestre de un programa académico, si existe una oferta de inscripción para grado activa de ese mismo programa o si ya tiene una inscripción para grado en curso.
- **Temas incluidos:** Ingreso al portal, requisitos previos, diligenciamiento y envío de la solicitud, seguimiento del estado y descarga de documentos.

## Procedimiento: Iniciar y enviar la solicitud de inscripción para grado

### Propósito
Iniciar una solicitud de inscripción para grado y enviarla para su verificación. (Fuente: páginas 4, 9–17)

### Requisitos y permisos
- El módulo solo se visualiza si el usuario registrado está en el último semestre de un programa académico y existe una oferta de inscripción para grado activa de ese mismo programa, o si el usuario ya cuenta con una inscripción para grado en curso. (Fuente: página 4)
- El botón «Inscripción para grado» solo se habilita si se cumplen todos los requisitos de cumplimiento previo. (Fuente: página 7)
- Si hay documentos requeridos para la inscripción, deben estar listos, escaneados y en formato PDF para cargarlos durante la solicitud. (Fuente: página 7)

### Pasos
1. Desde la página web de la universidad, ingrese en la sección «Portales» mediante `https://www.unisimon.edu.co/portales/estudiantes`. Ingrese su usuario y contraseña y presione «Acceder». (Fuente: página 3)
2. En el Portal de estudiantes, seleccione el icono «Solicitud de inscripción para grado». (Fuente: página 4)
3. Seleccione el icono correspondiente al programa académico para el cual iniciará el proceso. (Fuente: página 5)
4. Lea atentamente la información sobre algunos de los requisitos para iniciar el proceso. (Fuente: página 6)
5. Revise los requisitos de cumplimiento previo. El sistema verifica automáticamente el estado de cada requisito. Si alguno figura como «Pendiente», el botón «Inscripción para grado» no se habilitará; comuníquese con la dependencia correspondiente para verificar el estado del requisito. (Fuente: páginas 7–8)
6. Si cumple todos los requisitos previos, reúna los documentos requeridos escaneados y en formato PDF. Seleccione el botón «Inscripción para grado» para iniciar la solicitud. (Fuente: página 7)
7. En la ventana que se abre, lea atentamente los mensajes informativos de cada pestaña del formulario. (Fuente: página 9)
8. **Paso 1 – Información:** lea los párrafos informativos, que incluyen información relevante sobre el proceso de inscripción para grado, información sobre la ley de protección de datos de la Universidad y una guía de pasos del proceso. Acepte los términos y condiciones y haga clic en «Siguiente». (Fuente: página 10)
9. **Paso 2 – Identificación:** lea los párrafos informativos, actualice sus datos de contacto si han cambiado y haga clic en «Siguiente». En esta etapa se visualizan datos básicos de solo lectura y se muestra la guía y navegación de pasos del proceso. (Fuente: página 11)
10. **Paso 3 – Medio de Pago:** seleccione el o los medios de pago previstos para pagar su derecho a grado y haga clic en «Siguiente». La etapa muestra opciones de forma de pago y la guía y navegación de pasos del proceso. (Fuente: página 12)
11. **Paso 4 – Adjuntos:** cargue los documentos requeridos para la solicitud en formato PDF y haga clic en «Enviar». Esta etapa muestra los documentos a cargar y la guía y navegación de pasos del proceso. (Fuente: página 13)
12. En la ventana de confirmación del envío, haga clic en «Sí». (Fuente: página 14)

### Resultado esperado
- Después de enviar la solicitud, se brinda información sobre el proceso de verificación y se envía un correo electrónico notificando el inicio del proceso. (Fuente: página 15)
- Se puede visualizar y descargar el formulario de inscripción diligenciado como constancia del inicio del proceso. (Fuente: página 16)
- Se debe estar atento a la notificación por correo electrónico sobre el estado del proceso. (Fuente: página 17)

### Errores, límites o excepciones documentadas
- Si algún requisito de cumplimiento previo está en estado «Pendiente», el botón «Inscripción para grado» no se habilita. La fuente indica comunicarse con el área correspondiente —por ejemplo, Programa académico u Oficina de créditos— para verificar el estado del requisito. (Fuente: páginas 7–8)
- El formulario descargado no necesita firma ni datos adicionales. No constituye aval de que la solicitud haya sido aprobada. La decisión se notifica en un correo electrónico posterior a la verificación de requisitos por parte de un funcionario de la oficina de Matrículas y Graduación. (Fuente: página 16)

## Procedimiento: Descargar documentos después de la aprobación

### Requisitos y permisos
- Haber recibido la notificación de que la solicitud fue aprobada. (Fuente: página 18)

### Pasos
1. Ingrese nuevamente al Portal de estudiantes. (Fuente: página 18)
2. Abra el módulo «Solicitud de Inscripción para grado». (Fuente: página 18)
3. Descargue el volante de pago y la constancia de su inscripción a grado. (Fuente: página 18)

## Puntos por validar
- La página 2 contiene el título «Solicitud de Inscripciones para Grados», pero no aporta pasos del procedimiento. Su descripción automática incluye elementos repetidos de navegación que no permiten identificar con certeza otros datos operativos. (Fuente: página 2)
- La página 1 es una descripción automática de una imagen institucional y no documenta pasos del trámite. La imagen se describe como de la «Universidad de San Simón Bolívar», mientras que el resto del documento identifica el portal de la Universidad Simón Bolívar; la denominación de la página 1 no se resuelve aquí. (Fuente: página 1)
- Las descripciones automáticas de imágenes en las páginas 9–14 mencionan elementos de interfaz que no coinciden claramente con el texto del procedimiento. Se conservaron los pasos operativos del texto extraído; hace falta revisar las imágenes originales para confirmar si contienen instrucciones adicionales. (Fuente: páginas 9–14)
- La fuente no enumera cuáles son los requisitos previos ni cuáles son los documentos requeridos; indica que se muestran en el proceso. (Fuente: páginas 7 y 13)
