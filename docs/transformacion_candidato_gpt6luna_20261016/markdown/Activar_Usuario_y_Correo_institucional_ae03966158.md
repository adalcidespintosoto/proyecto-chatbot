# Activar usuario y correo institucional para el primer semestre

## Información del documento
- **Fuente original:** *Activar Usuario y Correo institucional.pdf*
- **Sistema o módulo:** Portal Estudiantes; también se mencionan Aula Extendida y Correo Estudiantil.
- **Público o permisos mencionados por la fuente:** Estudiantes.
- **Temas incluidos:** Acceso al Portal Estudiantes, cambio de contraseña y acceso al correo institucional.

## Procedimiento: Activar el usuario y cambiar la contraseña del Portal Estudiantes

### Requisitos y permisos
- El usuario y la contraseña se encuentran al final del recibo de matrícula. (Fuente: página 5)
- La nueva contraseña debe tener entre 8 y 15 caracteres, incluir mayúsculas, minúsculas y al menos un número. No puede contener datos personales, como nombres, apellidos, identificación, números de teléfono o fecha de nacimiento. (Fuente: página 7)

### Pasos
1. Ingrese a https://www.unisimon.edu.co/portales y seleccione “Portal Estudiantes”. (Fuente: página 3)
2. Seleccione Barranquilla. (Fuente: página 4)
3. Acceda con el usuario y la contraseña que aparecen al final del recibo de matrícula. (Fuente: página 5)
4. Cuando el sistema solicite cambiar la contraseña a una de seguridad, seleccione “Cambiar”. (Fuente: página 6)
5. Establezca una nueva contraseña que cumpla los requisitos indicados. (Fuente: páginas 6–7)

### Resultado esperado
- Después de restablecer la contraseña del Portal de Estudiantes, esa misma contraseña sirve para Aula Extendida y Correo Estudiantil. (Fuente: página 8)

### Errores, límites o excepciones documentadas
- Si presenta inconvenientes con la contraseña, la fuente indica escribir a trabajodesdecasa@unisim
onbolivar.edu.co con sus datos personales. El correo aparece dividido entre líneas en la fuente; se conserva aquí sin reproducir ni completar el dato de contacto. (Fuente: página 5)

## Procedimiento: Acceder al correo institucional estudiantil

### Pasos
1. Acceda al correo institucional desde la página web de la Universidad, en la sección “Servicios” y luego “Correo Estudiantes”. (Fuente: página 8)

### Errores, límites o excepciones documentadas
- La fuente advierte que, de lo contrario, la cuenta no será reconocida. (Fuente: página 8)

## Puntos por validar
- En la página 5, el correo de contacto está partido entre líneas y la instrucción solicita enviar “sus datos personales”. No se reproduce el correo ni se detallan cuáles datos deben enviarse.
- La página 1 contiene una descripción automática de una imagen institucional no verificada, sin instrucciones operativas identificables para estos trámites.
- La descripción automática de la página 2 no permite identificar con certeza contenido operativo adicional.
