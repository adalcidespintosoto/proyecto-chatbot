# Instructivo para evaluaciones de selección ILE-TICS

## Información del documento
- **Fuente original:** `Evaluaciones de selección ILE-TICS (ASPIRANTES).pdf`
- **Sistema o módulo:** Plataforma de evaluaciones de selección ILE-TICS; el nombre del sistema no se especifica en el texto.
- **Público o permisos mencionados por la fuente:** Aspirantes.
- **Temas incluidos:** Ingreso a las evaluaciones, realización de pruebas y comunicación de inconvenientes.

## Procedimiento: Ingresar y realizar las evaluaciones

### Propósito
Ingresar a las evaluaciones disponibles y completar cada una. (Fuente: páginas 2–7)

### Requisitos y permisos
- Tener el enlace de la evaluación correspondiente. (Fuente: página 2)
- Ingresar el número de identificación y la fecha de expedición del documento de identidad. La fecha debe escribirse en formato `AAAA-MM-DD` (año, mes, día). (Fuente: página 3)

### Pasos
1. Haga clic en el enlace de la evaluación correspondiente. (Fuente: página 2)
2. Ingrese su número de identificación y la fecha de expedición del documento de identidad. Seleccione **“Continuar”**. (Fuente: página 3)
3. Por cada evaluación que aparezca en el listado, realice el procedimiento indicado. Para comenzar una prueba, presione el icono **«Comenzar»**. (Fuente: página 4)
4. Antes de iniciar cada prueba, lea atentamente las instrucciones. Estas indican el tipo de preguntas y respuestas, y el tiempo máximo disponible para realizar la prueba. Después de leerlas, seleccione **“Continuar”** para iniciar. (Fuente: página 5)
5. Responda todas las preguntas y presione **“Guardar”**. (Fuente: página 6)
6. Cuando haya realizado todas las evaluaciones disponibles, presione **“Cerrar sesión”**. (Fuente: página 7)

### Resultado esperado
- Se inicia la prueba al seleccionar **“Continuar”** después de leer sus instrucciones. (Fuente: página 5)
- Las respuestas se guardan al presionar **“Guardar”**, siempre que se hayan respondido todas las preguntas. (Fuente: página 6)

### Errores, límites o excepciones documentadas
- El sistema no permitirá finalizar la evaluación si falta responder alguna pregunta. Indicará el número de la pregunta pendiente. (Fuente: página 6)
- Se indica que cada prueba tiene un tiempo máximo, pero no se especifica cuánto dura. (Fuente: página 5)

## Procedimiento: Reportar inconvenientes con las evaluaciones o el registro

### Propósito
Comunicar inconvenientes relacionados con las pruebas o con un registro o código de estudiante duplicado. (Fuente: página 8)

### Pasos
1. Si presenta alguno de estos inconvenientes, comuníquese con el correo correspondiente a la prueba, indique la situación y adjunte una captura de pantalla:
   - **Prueba suficiencia de lengua extranjera:** `ltorres39@unisimonbolivar.edu.co`
   - **Prueba suficiencia de manejo TICS:** `gcolpas@unisimonbolivar.edu.co` (Fuente: página 8)
2. Los inconvenientes indicados para contactar esos correos son:
   - No pudo culminar la prueba y, al ingresar nuevamente, el sistema indica que el tiempo expiró.
   - No pudo culminar la prueba y, al intentar guardar las respuestas, el sistema indica que no se pueden guardar sus nuevas respuestas.
   - No aparece una de las dos pruebas mencionadas o una de ellas aparece duplicada. (Fuente: página 8)
3. Si al ingresar el sistema indica que tiene un registro o código de estudiante duplicado, comuníquese con `admisiones.posgrados@unisimonbolivar.edu.co`. (Fuente: página 8)
4. También puede escribir a la mesa de ayuda: `trabajodesdecasa@unisimonbolivar.edu.co`. (Fuente: página 8)
