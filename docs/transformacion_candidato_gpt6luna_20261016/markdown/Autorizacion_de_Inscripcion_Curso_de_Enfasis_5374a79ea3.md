## Procedimiento: Crear una autorización de inscripción a curso de énfasis

### Propósito
Realizar la autorización de inscripción a un curso de énfasis para un estudiante. (Fuente: diapositivas 1 y 7)

### Requisitos y permisos
- Acceder al sistema desde «Portal Profesores y Administrativos» con usuario y contraseña. (Fuente: diapositivas 2–4)
- Tener el año, el periodo y el programa para seleccionar los filtros. (Fuente: diapositiva 7)
- Se solicita el número de documento del estudiante. (Fuente: diapositiva 9)

### Pasos
1. Desde el navegador, ingrese al sitio web de la Universidad: `http://www.unisimon.edu.co/`. En el menú principal, seleccione «Portales». (Fuente: diapositiva 2)
2. Diríjase a la sección «Portal Profesores y Administrativos». (Fuente: diapositiva 3)
3. Digite su usuario y contraseña y presione el botón «Acceder». (Fuente: diapositiva 4)
4. Después de ingresar al sistema, seleccione el módulo «Matrícula». (Fuente: diapositiva 5)
5. Acceda a la sección «Autorización de Inscripción Curso de Énfasis». (Fuente: diapositiva 6)
6. Seleccione los filtros de año, periodo y programa. (Fuente: diapositiva 7)
7. Presione el botón «Nuevo» para crear el registro de autorización. (Fuente: diapositiva 8)
8. En la ventana desplegada, digite el número de documento del estudiante y presione «Guardar» para finalizar el proceso. (Fuente: diapositiva 9)
