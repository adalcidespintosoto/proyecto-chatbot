- **Público o permisos mencionados por la fuente:** Se indica el ingreso con usuario y contraseña. No se especifican permisos adicionales.
- **Temas incluidos:** Ingreso al módulo, consulta de bloqueos, sanciones y excepciones, y generación de reportes.

## Procedimiento: Ingresar al módulo «Bloqueos, Sanciones y Excepciones»

### Pasos
1. Desde la página web de la universidad, ingrese en la sección «Portales» mediante `http://www.unisimon.edu.co/portales/administrativos`. (Fuente: página 2)
2. Ingrese su usuario y contraseña y presione el botón «Acceder». (Fuente: página 2)
3. Una vez dentro del Portal, seleccione la opción «Matrícula». (Fuente: página 3)
4. En el menú de Matrícula, seleccione «Bloqueos, Sanciones y Excepciones». (Fuente: página 4)

## Procedimiento: Consultar bloqueos, sanciones o excepciones asociados a un estudiante

### Propósito
Consultar los bloqueos, sanciones o excepciones asociados a un estudiante. (Fuente: página 6)

### Pasos
1. Seleccione «bloqueos», «sanciones» o «excepciones». (Fuente: página 6)
2. Seleccione alguno de los diferentes criterios de búsqueda. (Fuente: página 6)
3. Seleccione el botón «Buscar». (Fuente: página 6)

### Resultado esperado
El módulo permite consultar los bloqueos, sanciones o excepciones asociados a un estudiante. Además, permite descargar reportes en formato Excel. (Fuente: página 6)

## Procedimiento: Generar un reporte

### Pasos
1. Seleccione el botón «Reportes». (Fuente: página 8)
2. Cuando se abra la ventana emergente, seleccione los datos del reporte que requiera. (Fuente: página 8)
3. Seleccione «Generar». (Fuente: página 8)
