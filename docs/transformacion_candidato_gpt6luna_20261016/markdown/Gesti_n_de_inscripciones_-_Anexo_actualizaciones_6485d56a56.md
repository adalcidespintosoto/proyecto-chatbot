# Gestión de inscripciones para grado y ofertas de inscripción para grado: actualizaciones

## Información del documento
- **Fuente original:** Gestión de inscripciones - Anexo actualizaciones.pptx
- **Sistema o módulo:** Gestión de inscripciones; la fuente menciona los módulos “Inscripción para grados”, “Oferta de inscripciones para grados” y “Actualización”. (Fuente: diapositivas 2–3)
- **Público o permisos mencionados por la fuente:** Para algunas funcionalidades se indica un usuario específico; el identificador se omite. (Fuente: diapositiva 3)
- **Temas incluidos:** Inscripciones para grado, ofertas de inscripción para grado, cambio de periodo o mes de ceremonia, liberación y anulación de inscripciones, aprobación posterior a la finalización de la oferta, excepciones al requisito de acta de grado y modificación de fechas en ofertas. (Fuente: diapositivas 2–3, 5)

## Procedimiento: Cambio de periodo y/o mes de ceremonia

### Propósito
Asignar a una inscripción seleccionada un nuevo año, periodo y mes de ceremonia de graduación. (Fuente: diapositiva 6)

### Requisitos y permisos
- La funcionalidad se atribuye en la fuente a un usuario específico; su identificador se omite. (Fuente: diapositiva 3)
- La longitud máxima del campo “observación” es de 180 caracteres, incluidos espacios. (Fuente: diapositiva 6)

### Pasos
1. Seleccione un registro. (Fuente: diapositiva 6)
2. Diligencie todos los campos, incluidos el nuevo año, periodo y mes de ceremonia de graduación. (Fuente: diapositiva 6)
3. Seleccione el botón “guardar”. (Fuente: diapositiva 6)

## Procedimiento: Listado de inscripciones anuladas

### Propósito
Obtener un listado de las inscripciones anuladas en formato Excel. (Fuente: diapositiva 8)

### Pasos
1. En el campo “estado”, seleccione la opción “Anuladas”. (Fuente: diapositiva 8)
2. Aparecerá automáticamente un botón para descargar el listado en formato Excel. (Fuente: diapositiva 8)

## Procedimiento: Agregar, anular o activar excepciones al requisito de acta de grado

### Propósito
Agregar programas a la excepción del requisito de acta de grado y anular excepciones existentes. Si una excepción anulada debe volver a funcionar, se puede activar nuevamente. (Fuente: diapositiva 11)

### Pasos
1. Para agregar un programa a la excepción, seleccione el botón “Agregar”. (Fuente: diapositiva 11)
2. Para anular una excepción existente, seleccione el botón “Anular”. (Fuente: diapositiva 11)
3. Para que una excepción ya anulada vuelva a funcionar, seleccione el botón “Activar”. (Fuente: diapositiva 11)

## Procedimiento: Modificar fechas de inscripción y de grado en ofertas

### Propósito
Asignar nuevas fechas de inicio y fin para inscripción y/o grado a una o más ofertas seleccionadas. (Fuente: diapositiva 12)

### Requisitos y permisos
- La funcionalidad se atribuye en la fuente a un usuario específico; su identificador se omite. (Fuente: diapositiva 3)

### Pasos
1. Realice la búsqueda. (Fuente: diapositiva 12)
2. Seleccione una o más ofertas. (Fuente: diapositiva 12)
3. Para cambiar las fechas de inscripción, seleccione “Fechas Inscripción”; para cambiar las fechas de grado, seleccione “Fechas Grados”. Se puede seleccionar uno de esos botones o ambos, según las fechas que se quieran asignar. (Fuente: diapositiva 12)
4. En la ventana que se abrirá, ingrese las nuevas fechas. (Fuente: diapositiva 12)
