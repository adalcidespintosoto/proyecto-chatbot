# Instructivo de aprobación de requisitos para aspirantes

## Información del documento
- **Fuente original:** Instructivo Aprobación de Requisitos.pdf
- **Sistema o módulo:** SIA WEB; la página de ingreso también menciona la sección «Portales».
- **Público o permisos mencionados por la fuente:** Usuario con permisos asociados al área que aparece como «Dependencia Responsable» del requisito.
- **Temas incluidos:** Ingreso al portal, búsqueda de aspirantes, consulta de requisitos y aprobación de requisitos.

## Procedimiento: Ingresar al portal y localizar aspirantes

### Pasos
1. Desde la página web de la universidad, ingrese en la sección «Portales» mediante `http://www.unisimon.edu.co/portales/administrativos`. Ingrese su usuario y contraseña y presione «Acceder». (Fuente: página 2)
2. Al ingresar al portal (SIA WEB), seleccione el icono «Procesos estudiantes». (Fuente: página 3)
3. Seleccione el proceso, periodo actual, nivel y programa académico. Se listarán todos los aspirantes que están en ese proceso. (Fuente: página 4)
4. Para buscar a un aspirante por su número de identificación, digítelo en el campo «Documento» y haga clic en «Buscar». (Fuente: página 4)

## Procedimiento: Consultar y aprobar requisitos de un aspirante

### Propósito
Visualizar los requisitos parametrizados para el programa académico del aspirante y aprobar los requisitos asignados al área a la que pertenece el usuario. (Fuente: páginas 5–6)

### Requisitos y permisos
- Para aprobar un requisito, el usuario debe poseer permisos asociados al área que aparece como «Dependencia Responsable» de ese requisito. Si no los posee, el sistema arrojará el respectivo mensaje de error. (Fuente: página 7)

### Pasos
1. En las opciones del aspirante, seleccione «Ver Requisitos» para visualizar los requisitos asignados al área a la que pertenece el usuario. (Fuente: página 5)
2. En la sección de requisitos se listarán los que se hayan parametrizado para el programa académico del aspirante. (Fuente: página 6)
3. Seleccione un requisito con la intención de aprobarlo. El sistema pedirá confirmación. (Fuente: página 7)

### Resultado esperado
- Al aprobar un requisito, este queda aprobado. La fuente indica que «Ver Requisitos» permite visualizar y aprobar cada requisito asignado al área del usuario. (Fuente: página 5)

### Errores, límites o excepciones documentadas
- Si el usuario no posee permisos asociados al área indicada como «Dependencia Responsable» del requisito, el sistema arrojará un mensaje de error. (Fuente: página 7)

## Otras opciones disponibles para el aspirante

- **«Ver Hoja de Vida»:** permite visualizar todos los datos pertenecientes a la Hoja de Vida del aspirante. (Fuente: página 5)
- **«Aprobar/Admitir»:** permite aprobar la solicitud para que el aspirante pueda continuar el proceso. (Fuente: página 5)
- **«Enviar Correo Personalizado»:** permite enviar un correo personalizado en caso de novedad e inconveniente durante el proceso. (Fuente: página 5)

## Palabras y formas de búsqueda
Paráfrasis editoriales para mejorar la búsqueda; no son afirmaciones adicionales del documento: aprobar requisitos de aspirantes, revisar requisitos de aspirante, buscar aspirante por documento, ingresar a SIA WEB, aprobar o admitir solicitud, enviar correo personalizado.

## Puntos por validar
- La página 2 indica el acceso mediante «Portales» y una URL, pero no explica la relación entre ese ingreso y el portal SIA WEB mencionado en la página 3.
- La fuente menciona en la página 6 «Actualizar listado» y «Aprobar requisito», pero no especifica acciones o pasos asociados a «Actualizar listado».
- La fuente indica que el sistema pide confirmación al seleccionar un requisito para aprobarlo, pero no detalla cómo confirmar ni cuál es el resultado inmediato de esa confirmación.
- La descripción automática de la imagen de la página 2 no está verificada y contiene texto que parece ajeno al procedimiento; no se incorpora como instrucción operativa.
