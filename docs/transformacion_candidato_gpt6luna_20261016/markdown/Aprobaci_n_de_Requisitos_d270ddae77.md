# Aprobación de requisitos de aspirantes en SIA WEB

## Información del documento
- **Fuente original:** `Aprobación de Requisitos.pptx`
- **Sistema o módulo:** SIA WEB; la fuente también menciona «Procesos estudiantes». (Fuente: diapositiva 3)
- **Público o permisos mencionados por la fuente:** La persona usuaria debe tener permisos asociados al área que aparece como «Dependencia Responsable» del requisito para aprobarlo. (Fuente: diapositiva 7)
- **Temas incluidos:** Ingreso al portal, búsqueda de aspirantes, consulta y aprobación de requisitos, consulta de hoja de vida, aprobación/admisión y envío de correo personalizado. (Fuente: diapositivas 1–7)

## Procedimiento: Consultar aspirantes y gestionar sus requisitos

### Propósito
El instructivo trata sobre la aprobación de requisitos de aspirantes. (Fuente: diapositiva 1)

### Requisitos y permisos
- La fuente indica que para aprobar un requisito se requieren permisos asociados al área que aparece como «Dependencia Responsable» de ese requisito. Si la persona usuaria no posee esos permisos, el sistema muestra el mensaje de error correspondiente. (Fuente: diapositiva 7)

### Pasos
1. Desde la página web de la universidad, ingrese en la sección «Portales»: http://www.unisimon.edu.co/portales/administrativos. Escriba su usuario y contraseña y presione «Acceder». (Fuente: diapositiva 2)
2. Al ingresar al portal (SIA WEB), seleccione el icono «Procesos estudiantes». (Fuente: diapositiva 3)
3. Seleccione el proceso, el periodo actual, el nivel y el programa académico. El sistema listará los aspirantes que están en ese proceso. (Fuente: diapositiva 4)
4. Para buscar a un aspirante por su número de identificación, digítelo en el campo «Documento» y haga clic en «Buscar». (Fuente: diapositiva 4)
5. Para consultar y gestionar un aspirante, la fuente presenta estas opciones:
   - **Ver Requisitos:** visualizar y aprobar cada uno de los requisitos asignados al área a la que pertenece la persona usuaria. (Fuente: diapositiva 5)
   - **Ver Hoja de Vida:** visualizar todos los datos pertenecientes a la Hoja de Vida del Aspirante. (Fuente: diapositiva 5)
   - **Aprobar/Admitir:** aprobar la solicitud para que el Aspirante pueda continuar el proceso. (Fuente: diapositiva 5)
   - **Enviar Correo Personalizado:** permite enviar un correo personalizado en caso de novedad e inconveniente durante el proceso. (Fuente: diapositiva 5)
6. En «Ver requisitos» se listan los requisitos parametrizados para el programa académico del Aspirante, para su visualización y aprobación. (Fuente: diapositiva 6)
7. Para aprobar un requisito, selecciónelo. El sistema solicitará confirmación. (Fuente: diapositiva 7)

### Resultado esperado
- Al aprobar la solicitud mediante «Aprobar/Admitir», el Aspirante puede continuar el proceso. (Fuente: diapositiva 5)
- Los requisitos parametrizados para el programa académico del Aspirante quedan disponibles para su visualización y aprobación. (Fuente: diapositiva 6)

### Errores, límites o excepciones documentadas
- Si la persona usuaria no tiene permisos asociados al área que aparece como «Dependencia Responsable» del requisito, el sistema muestra el mensaje de error correspondiente. La fuente no especifica el texto del mensaje. (Fuente: diapositiva 7)
- «Enviar Correo Personalizado» se presenta como una opción para casos de novedad e inconveniente durante el proceso. (Fuente: diapositiva 5)
