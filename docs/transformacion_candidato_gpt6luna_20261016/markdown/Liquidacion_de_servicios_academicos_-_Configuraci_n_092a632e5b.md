## Procedimiento: Configurar valores de descuentos para créditos de posgrado

### Propósito
Configurar valores de descuentos para los créditos de programas de posgrado según el año, periodo, nivel académico y tipo de curso. (Fuente: diapositivas 5–7)

### Requisitos y permisos
- La fuente identifica el instructivo como dirigido a funcionarios. No detalla permisos específicos. (Fuente: diapositiva 1)

### Pasos
1. Desde un navegador, ingrese al sitio web de estudiantes de la Universidad: https://barranquilla.unisimon.edu.co/academico/ e inicie sesión. (Fuente: diapositiva 2)
2. Después de iniciar sesión, diríjase al logo de “Matricula”. (Fuente: diapositiva 3)
3. Busque y presione el módulo “Autorización de compra de créditos” en el menú lateral. (Fuente: diapositiva 4)
4. Para crear y visualizar registros de programas académicos de posgrado, use el nuevo filtro “Nivel”. (Fuente: diapositiva 5)
5. Presione el botón “configuración” para acceder a la funcionalidad de configuración. (Fuente: diapositiva 6)
6. Para crear una configuración, presione “Crear configuración”. (Fuente: diapositiva 8)
7. Complete el formulario que se carga y, después de diligenciarlo, presione “Guardar”. (Fuente: diapositiva 9)
8. Para modificar un registro, presione “editar”. Se desplegará un formulario con la información del registro seleccionado; modifique la información y presione “Guardar”. (Fuente: diapositiva 10)
9. Para eliminar un registro, presione “Eliminar”. Se desplegará una ventana de confirmación; para proceder con la eliminación, presione “Si”. (Fuente: diapositiva 11)

### Errores, límites o excepciones documentadas
- La fuente indica que el filtro “Nivel” permite la creación y visualización de registros con programas académicos de posgrado, pero no especifica valores disponibles ni cómo seleccionar uno. (Fuente: diapositiva 5)
