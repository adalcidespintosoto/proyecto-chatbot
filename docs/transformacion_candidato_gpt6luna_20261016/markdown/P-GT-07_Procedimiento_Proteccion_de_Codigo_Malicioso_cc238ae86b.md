- **Sistema o módulo:** Antimalware y protección contra código malicioso.
- **Público o permisos mencionados por la fuente:** Funcionarios y contratistas de la Universidad Simón Bolívar que utilizan algún sistema informático de la compañía. (Fuente: página 2)
- **Temas incluidos:** Políticas de protección; instalación, configuración y actualización del antimalware; análisis de discos; desinfección y cuarentena; generación de reportes y acciones preventivas. (Fuentes: páginas 2–3)

## Procedimiento: Protección contra código malicioso

### Propósito
Describir cómo realizar la protección contra códigos maliciosos, teniendo en cuenta el antimalware como protección principal. El procedimiento indica cómo se instalan y actualizan las plataformas de detección, reporte y recuperación de ataques contra software malicioso, y cómo controlar la infección vía email. (Fuente: página 2)

### Requisitos y permisos
- Todas las estaciones de trabajo deben tener instalado y actualizado un software antimalware, debidamente actualizado y licenciado. (Fuente: página 2)
- El antimalware debe configurarse para inspeccionar automáticamente los dispositivos de almacenamiento removibles cuando se conecten. (Fuente: página 2)
- Ante cualquier correo sospechoso, el funcionario no debe abrirlo y debe informar de inmediato al Oficial de Seguridad de la Información o, en su defecto, a la Dirección de TI, para su inspección. (Fuente: página 2)
- No se deben reenviar correos spam ni hacer reenvíos masivos de emails dentro de la Universidad Simón Bolívar. (Fuente: página 2)
- La Coordinación de Seguridad Informática o, en su defecto, el personal designado por la Dirección de TI, deben evaluar cualquier tipo de evento o incidente de seguridad, como virus o malware, para establecer soluciones que ayuden a controlar la eventualidad. (Fuente: página 3)
- El funcionario es responsable de respaldar la información almacenada en su estación de trabajo. Para ello, debe utilizar la unidad de red o el disco externo definido para esto cada tres días o máximo cada semana. (Fuente: página 3)

### Pasos
1. **Instalar el producto antimalware.** En cada computador nuevo se debe instalar y configurar la licencia del producto antimalware. La fuente también indica una verificación cada seis meses dentro del mantenimiento preventivo, relacionada con la instalación y actualización del producto. **Responsable:** Coordinación de Servicio y Soporte. (Fuente: página 3)
2. **Configurar el producto antimalware.** Configurarlo para que inicie automáticamente al iniciar el sistema. Configurar las reglas del firewall, activar el sistema de detección de intrusiones, la protección del cliente de correo electrónico y el control web; además, colocar una contraseña para la administración del antimalware. **Responsable:** Coordinación de Servicio y Soporte. (Fuente: página 3)
3. **Actualizar el producto antimalware.** Actualizar la base de datos de firmas. **Responsable:** Coordinación de Seguridad Informática. (Fuente: página 3)
4. **Analizar los discos.** Iniciar un escaneo del disco en búsqueda de malware instalado en la computadora y vacunar con el producto. **Responsable:** Coordinación de Seguridad Informática. (Fuente: página 3)
5. **Realizar la desinfección y cuarentena.** Al detectarse un malware, realizar la acción de desinfección y/o eliminación del disco. **Responsable:** Coordinación de Seguridad Informática. (Fuente: página 3)
6. **Generar el reporte.** Guardar el reporte de las acciones realizadas para su posterior análisis en la consola de administración del producto antimalware. **Responsable:** Coordinación de Seguridad Informática. (Fuente: página 3)
7. **Tomar acciones preventivas.** Tomar medidas preventivas y realizar capacitación de usuario para mitigar riesgos. **Responsables:** Coordinación de Seguridad Informática y Coordinación de Servicio y Soporte. (Fuente: página 3)

### Resultado esperado
- Protección contra códigos maliciosos mediante el antimalware como protección principal. (Fuente: página 2)
- Un reporte guardado de las acciones realizadas, para su posterior análisis en la consola de administración del producto antimalware. (Fuente: página 3)
- Medidas preventivas y capacitación de usuario para mitigar riesgos. (Fuente: página 3)

## Definiciones
- **Análisis forense:** Aplicación de técnicas científicas y analíticas especializadas a infraestructura tecnológica que permiten identificar, preservar, analizar y presentar datos, y generar un registro de un evento informático ocurrido para tenerlo en cuenta dentro de una investigación corporativa o de un proceso legal. (Fuente: página 2)
- **Antimalware:** Tipo de programa diseñado para prevenir, detectar y remediar software malicioso en los dispositivos informáticos. (Fuente: página 2)
- **Malware:** Abreviatura de *Malicious software*. El término engloba todo tipo de programa o código informático malicioso cuya función es dañar un sistema o causar un mal funcionamiento. Entre los tipos mencionados están virus, troyanos, gusanos (*Worm*), *keyloggers* y *Botnets*. (Fuente: página 2)

## Puntos por validar
- La frase sobre la verificación cada seis meses dentro del mantenimiento preventivo no especifica con claridad cómo se relacionan la verificación, la instalación y la actualización del antimalware. (Fuente: página 3)
- En la actividad “Desinfección y cuarentena”, la fuente indica “desinfección y/o eliminación del disco”, pero no aclara qué se elimina ni cómo se relaciona esa acción con la cuarentena. (Fuente: página 3)
- El objetivo menciona controlar la infección vía email, pero el documento no detalla pasos específicos de control de infecciones por email más allá de las políticas sobre correos sospechosos, spam y reenvíos masivos. (Fuentes: páginas 2–3)
