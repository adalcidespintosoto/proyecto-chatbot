# Manual de usuario del Sistema Administrativo de Ingreso — Portal CovidApp

## Información del documento
- **Fuente original:** *Manual de Usuario - Portal CovidApp.pdf*
- **Sistema o módulo:** Sistema Administrativo de Ingreso, Portal CovidApp.
- **Público o permisos mencionados por la fuente:** Estudiantes, docentes, funcionarios administrativos, contratistas y visitantes. Los módulos de gestión se muestran según el rol correspondiente; se mencionan los roles **Bienestar Universitario** y **Bienestar Laboral**.
- **Temas incluidos:** Acceso al sistema, datos personales, factores de riesgo, sintomatología, ingreso con código QR, autorizaciones, bloqueos, reportes y gestión de usuarios externos.

## Procedimiento: Acceder al Portal CovidApp

### Propósito
Ingresar al Sistema Administrativo de Ingreso — Portal CovidApp. (Fuente: páginas 2–4)

### Requisitos y permisos
- Los estudiantes pueden iniciar sesión con sus credenciales del **Portal Estudiantes**. (Fuente: página 4)
- Los docentes y funcionarios administrativos pueden iniciar sesión con sus credenciales del **Portal Gestión Académico - Administrativo**. (Fuente: página 4)

### Pasos
1. Acceder al sistema en [https://covidapp.unisimon.edu.co](https://covidapp.unisimon.edu.co). (Fuente: página 3)
2. Iniciar sesión con las credenciales correspondientes al perfil: **Portal Estudiantes** para estudiantes o **Portal Gestión Académico - Administrativo** para docentes y funcionarios administrativos. (Fuente: página 4)

### Resultado esperado
Al iniciar sesión, se muestra el dashboard o página de aterrizaje. El usuario tiene acceso a los módulos habilitados según su perfil. (Fuente: página 5)

## Procedimiento: Consultar o actualizar datos personales

### Propósito
Consultar la información básica del usuario y actualizarla si es necesario. (Fuente: página 6)

### Pasos
1. Ingresar a la opción **Datos personales**. (Fuente: página 6)
2. Revisar la información básica que se muestra y actualizarla en caso de ser requerido. (Fuente: página 6)

## Procedimiento: Registrar o actualizar factores de riesgo

### Propósito
Registrar las condiciones de salud preexistentes que correspondan. (Fuente: página 7)

### Pasos
1. Revisar el listado de condiciones de salud. Si presenta alguna de las condiciones descritas, seleccionar la que corresponda. (Fuente: página 7)
2. Si no presenta ninguna condición de salud preexistente, pasar directamente al paso de guardar. (Fuente: página 7)
3. Hacer clic en **Guardar**. (Fuente: página 7)
4. Diligenciar la encuesta una sola vez, salvo que cambie la condición de salud. Si cambia, actualizarla. (Fuente: página 7)

### Límites o excepciones documentadas
- La encuesta se diligencia una sola vez, salvo cambio en la condición de salud. (Fuente: página 7)

## Procedimiento: Diligenciar la encuesta diaria de sintomatología

### Propósito
Completar la encuesta de síntomas requerida diariamente para el ingreso a la institución. (Fuente: página 8)

### Pasos
1. Realizar diariamente la encuesta de síntomas. La fuente indica que es obligatoria para ingresar a la institución. (Fuente: página 8)
2. Si presenta algún síntoma, marcarlo y guardar la información. (Fuente: página 8)
3. Si no presenta síntomas, presionar **Guardar**. (Fuente: página 8)
4. Diligenciar la encuesta una sola vez al día. Si cambia la condición de salud, actualizarla. (Fuente: página 8)

### Límites o excepciones documentadas
- La encuesta se diligencia una vez al día, salvo que cambie la condición de salud. (Fuente: página 8)

## Procedimiento: Obtener y presentar el código QR de ingreso

### Requisitos y permisos
- La generación del código QR se describe después de realizar la encuesta de síntomas. (Fuente: página 9)
- Para la autorización individual, la fuente también indica que el usuario debe tener realizados correctamente los factores de riesgo y la encuesta de sintomatología. (Fuente: página 13)

### Pasos
1. Después de realizar la encuesta de síntomas, ingresar a la sección **Ingreso**. (Fuente: página 9)
2. Mostrar el código QR al personal de seguridad al ingresar a la institución. (Fuente: página 9)
3. Si el código QR expira, volver a acceder a la sección **Ingreso** para generar uno nuevo. (Fuente: página 9)

### Resultado esperado
La sección **Ingreso** muestra un código QR para exhibir al personal de seguridad. (Fuente: página 9)

### Límites o excepciones documentadas
- El código QR tiene una vigencia de **3 minutos**. Si expira, se debe generar uno nuevo desde la sección **Ingreso**. (Fuente: página 9)

## Procedimiento: Acceder a los módulos de gestión

### Requisitos y permisos

- Para **Bienestar Universitario** se enumeran: **Autorización**, **Bloqueos** y **Reportes**. (Fuente: página 10)
- Para **Bienestar Laboral** se enumeran: **Autorización**, **Bloqueos**, **Reportes** y **Externos**. (Fuente: página 10)

## Procedimiento: Gestionar autorizaciones

### Propósito
Autorizar estudiantes y funcionarios. El módulo incluye opciones de creación y edición individual o masiva, búsqueda, generación de reportes y remoción de autorizaciones. (Fuente: páginas 11–18)

### Requisitos y permisos
- El módulo se utiliza para autorizar tanto a estudiantes como a funcionarios. (Fuente: página 11)
- El acceso a los módulos de gestión depende del rol correspondiente. (Fuente: página 10)

### Panel de búsqueda de personas autorizadas
1. Ingresar al panel. Se muestra el listado de personas autorizadas, que pueden haberse cargado de forma masiva o individual. (Fuente: página 12)
2. Para filtrar por fecha de autorización, usar los filtros de **fecha inicial** y **fecha final**. El listado incluye las autorizaciones con fecha comprendida dentro del rango ingresado. (Fuente: página 12)
3. Usar **buscar** o el buscador para filtrar directamente los resultados obtenidos en la búsqueda del listado de personas autorizadas. (Fuente: página 12)

### Creación o edición individual
1. Ingresar a la opción de creación y edición individual. (Fuente: página 13)
2. En el formulario, ingresar el **tipo documento**, el **número de documento** y la **fecha máxima de ingreso**. (Fuente: página 13)
3. Hacer clic en **Autorizar**. (Fuente: página 13)
4. El estudiante o funcionario queda autorizado para generar su código QR al momento de ingresar a la institución, siempre que tenga realizados correctamente los factores de riesgo y la encuesta de sintomatología. (Fuente: página 13)

### Creación o edición masiva
1. En el módulo, ir a la sección **Administración de Autorización**. Desde allí se puede descargar la plantilla de Excel mediante el enlace **Click aquí**, que aparece en letras verdes. (Fuente: página 14)
2. Al ingresar a la opción de carga masiva, revisar el aviso importante sobre el llenado de la información y las siglas permitidas. (Fuente: página 15)
3. Seleccionar **Descargar Formato**. (Fuente: página 15)
4. Completar las tres columnas de la plantilla:
   - Tipo de documento: ingresar la sigla correspondiente sugerida en el aviso informativo.
   - Número de cédula del usuario que se va a autorizar.
   - Fecha máxima de ingreso a la institución. (Fuente: página 16)
5. Usar el mismo formato para autorizar estudiantes y funcionarios. (Fuente: página 16)
6. Para actualizar masivamente la fecha de ingreso de usuarios ya autorizados, realizar los pasos anteriores y cargar el archivo. El sistema actualizará los registros que coincidan en tipo y número de identificación. (Fuente: página 16)

### Remover una autorización
1. Buscar en el listado de usuarios autorizados la cédula cuya autorización se desea eliminar. (Fuente: página 17)
2. Seleccionar la cédula y oprimir el icono indicado para eliminar la autorización. (Fuente: página 17)
3. En la ventana emergente, confirmar si se está seguro de eliminar la autorización. (Fuente: página 17)

### Generar un reporte de personas autorizadas
1. Usar el icono indicado para descargar el listado de usuarios autorizados. (Fuente: página 18)
2. El resultado es un archivo Excel con la información que se obtiene en el panel de búsqueda. (Fuente: página 18)

### Errores, límites o excepciones documentadas
- Es indispensable respetar las siglas permitidas para la carga masiva; de lo contrario, la carga puede sufrir errores y no registrar la autorización del listado de usuarios. (Fuente: página 15)
- La fuente indica que el archivo masivo actualiza registros que coinciden por tipo y número de identificación. (Fuente: página 16)

### Puntos por validar
- La imagen asociada al aviso de carga masiva contiene una descripción automática, no verificada, que enumera siglas y tipos de documento. El texto extraído de la diapositiva 15 confirma que hay siglas permitidas, pero no las transcribe en el cuerpo del manual. Confirmar visualmente la lista antes de usarla. (Fuente: página 15)
- En las instrucciones de creación y edición individual y de carga masiva, no se transcribe el nombre de la opción que se debe seleccionar para abrir cada formulario; las imágenes no permiten confirmar ese texto con fiabilidad. (Fuente: páginas 13–14)

## Procedimiento: Gestionar bloqueos de estudiantes y funcionarios

### Propósito
Gestionar bloqueos de estudiantes y funcionarios. El módulo ofrece panel de búsqueda de usuarios bloqueados, bloqueo individual, generación de reportes y desbloqueo. (Fuente: página 19)

### Requisitos y permisos
- El acceso a los módulos de gestión depende del rol correspondiente. (Fuente: página 10)

### Panel de búsqueda de usuarios bloqueados
1. Ingresar al panel para consultar el listado de usuarios bloqueados. La fuente indica que un usuario puede aparecer en ese estado por:
   - Bloqueo por reporte de factores de riesgo.
   - Bloqueo por reporte de síntomas en la encuesta diaria de sintomatología.
   - Registro individual de un usuario bloqueado. (Fuente: página 20)
2. Para filtrar por fecha de bloqueo, usar los filtros de **fecha inicial** y **fecha final**. El listado incluye usuarios con fecha de bloqueo comprendida dentro del rango ingresado. (Fuente: página 21)
3. Usar **buscar** o el filtro general para filtrar directamente los resultados obtenidos en la búsqueda del listado de usuarios bloqueados. (Fuente: página 21)

### Bloqueo individual
1. Ingresar a la opción de bloqueo individual. (Fuente: página 22)
2. En el formulario, ingresar el tipo y número de documento que se desea bloquear. (Fuente: página 22)
3. Realizar la búsqueda del estudiante o funcionario. Como resultado, se muestra la información básica del usuario. (Fuente: página 22)
4. Verificar que el resultado corresponda al usuario que se desea bloquear. (Fuente: página 23)
5. Ingresar una razón de bloqueo, como evidencia del motivo del bloqueo individual. (Fuente: página 23)
6. Realizar el bloqueo. La fuente indica que el usuario queda restringido del acceso a la aplicación. (Fuente: página 23)

### Desbloqueo de un usuario
1. Buscar al estudiante o funcionario en el listado de usuarios bloqueados. (Fuente: página 24)
2. Seleccionar el usuario que se desea desbloquear y oprimir el icono indicado. (Fuente: página 24)
3. En el formulario con la información básica del usuario, ingresar una razón de desbloqueo como constancia. (Fuente: página 24)
4. Desbloquear al usuario. (Fuente: página 24)

### Generar un reporte de usuarios bloqueados
1. Usar el icono indicado para descargar el listado de usuarios bloqueados. (Fuente: página 25)
2. El resultado indicado es un archivo Excel. (Fuente: página 25)

### Resultado esperado
- Después del bloqueo individual, el estudiante o funcionario queda restringido del acceso a la aplicación y no puede realizar la encuesta diaria de sintomatología ni generar el código QR de ingreso. La restricción se mantiene hasta que se aclare su situación y se proceda al desbloqueo. (Fuente: página 23)
- Después del desbloqueo, el usuario puede volver a utilizar la aplicación para los fines establecidos. (Fuente: página 24)

### Puntos por validar
- La fuente no transcribe el nombre de la opción para iniciar el bloqueo individual ni el nombre del icono para bloquear o desbloquear; las imágenes asociadas no permiten confirmar esos nombres con fiabilidad. (Fuente: páginas 22–24)

## Procedimiento: Generar reportes

### Propósito
Generar reportes de **Sintomatología**, **Ingreso** y **Factores de Riesgo** para obtener información de la comunidad académica —estudiantes y funcionarios— o de usuarios externos —contratistas y visitantes—. (Fuente: página 26)

### Requisitos y permisos
- Se mencionan campos obligatorios y campos adicionales no obligatorios para los reportes. Los campos específicos varían según el tipo de reporte. (Fuente: páginas 27, 31 y 36)

### Reporte de sintomatología
1. Seleccionar los cuatro campos obligatorios: **Reporte de**, **filtro por tipo**, **fecha inicio** y **fecha fin**. (Fuente: página 27)
2. Si se requiere un resultado más específico, se pueden usar los campos adicionales **Tipo documento** y **documento identificación**. No son obligatorios. (Fuente: página 27)
3. Ejecutar la búsqueda con los filtros seleccionados. El sistema muestra la información que corresponde a la búsqueda. (Fuente: página 28)
4. Para consultar el ejemplo de estudiantes y profesores entre el 9 y el 12 de octubre de 2020, seleccionar los filtros correspondientes al reporte de sintomatología, al tipo académico y a ese rango de fechas. La fuente indica que el resultado comprende estudiantes y profesores que reportaron sus encuestas en ese rango y permite determinar quiénes reportaron algún síntoma, para proceder con el seguimiento de ese usuario. (Fuente: página 28)
5. Consultar la tabla debajo del panel de búsqueda. La tabla muestra información básica del usuario y campos seleccionados en la encuesta de sintomatología. (Fuente: página 29)
6. Usar **buscar** o el buscador para filtrar directamente los resultados obtenidos del listado de sintomatología académica. (Fuente: página 29)
7. Si se necesita un archivo Excel, usar el icono indicado para descargar la información obtenida. La fuente señala que esta opción puede ser necesaria por el gran volumen de datos y que trabajar la información directamente en Excel puede facilitar su manejo. (Fuente: página 30)
8. Para consultar encuestas de sintomatología de personal externo —contratistas o visitantes—, cambiar el campo **filtro por tipo**. Después de buscar, se obtiene la información de los usuarios externos que realizaron la encuesta en el rango de fechas ingresado. (Fuente: página 30)

### Reporte de ingreso
1. Seleccionar los cuatro campos obligatorios: **Reporte de**, **filtro por tipo**, **fecha inicio** y **fecha fin**. (Fuente: página 31)
2. Si se requiere un resultado más específico, se pueden usar los campos adicionales **Tipo documento** y **documento identificación**. No son obligatorios. (Fuente: página 31)
3. Ejecutar la búsqueda con los filtros seleccionados. El sistema muestra la información que corresponde a la búsqueda. (Fuente: página 32)
4. Para consultar el ejemplo de estudiantes y profesores entre el 9 y el 12 de octubre de 2020, seleccionar los filtros correspondientes al reporte de ingreso, al tipo académico y a ese rango de fechas. La fuente indica que el resultado comprende estudiantes y profesores que ingresaron a la institución luego de mostrar su código QR y de que este fuera verificado en portería, dentro de ese rango. (Fuente: página 32)
5. Consultar la tabla debajo del panel de búsqueda. La tabla muestra información básica del usuario, temperatura de ingreso y área de visita. (Fuente: página 33)
6. Usar **buscar** o el buscador para filtrar directamente los resultados obtenidos del listado de acceso académico. (Fuente: página 33)
7. Si se necesita un archivo Excel, usar el icono indicado para descargar la información obtenida. La fuente señala que esta opción puede ser necesaria por el gran volumen de datos y que trabajar la información directamente en Excel puede facilitar su manejo. (Fuente: página 34)
8. Para consultar el ingreso de personal externo —contratistas o visitantes—, cambiar el campo **filtro por tipo** y realizar la búsqueda. El resultado comprende a los usuarios externos que ingresaron en el rango de fechas indicado. (Fuente: páginas 34–35)

### Reporte de factores de riesgo
1. Seleccionar los cinco campos obligatorios: **Reporte de**, **filtro por tipo**, **presenta factor riesgo**, **fecha inicio** y **fecha fin**. (Fuente: página 36)
2. Si se requiere un resultado más específico, se pueden usar los campos adicionales **Tipo documento** y **documento identificación**. No son obligatorios. (Fuente: página 36)
3. Ejecutar la búsqueda con los filtros seleccionados. El sistema muestra la información que corresponde a la búsqueda. (Fuente: página 37)
4. Para consultar el ejemplo de estudiantes y profesores que sí presentan comorbilidades entre el 9 y el 12 de octubre de 2020, seleccionar los filtros correspondientes al reporte de factores de riesgo, al tipo académico, a la opción afirmativa de **presenta factor riesgo** y a ese rango de fechas. La fuente indica que el resultado comprende estudiantes y profesores que reportaron factores de riesgo al guardar sus datos. (Fuente: página 37)
5. Consultar la tabla debajo del panel de búsqueda. La tabla muestra información básica del usuario y sus respuestas de factores de riesgo. (Fuente: página 38)
6. Usar **buscar** o el buscador para filtrar directamente los resultados obtenidos del listado indicado en la fuente como “listado acceso académico”. (Fuente: página 38)
7. Si se necesita un archivo Excel, usar el icono indicado para descargar la información obtenida. La fuente señala que esta opción puede ser necesaria por el gran volumen de datos y que trabajar la información directamente en Excel puede facilitar su manejo. (Fuente: página 39)
8. Para obtener el listado de estudiantes y funcionarios que guardaron sus factores de riesgo, pero no reportaron ninguno, cambiar el campo **presenta factor riesgo** a la opción **NO**. (Fuente: página 39)

### Errores, límites o excepciones documentadas
- Para el ingreso de personal externo, la fuente indica que este no presenta código QR: al ingresar se toman sus datos y responde brevemente la encuesta diaria; luego se registra su ingreso tomando la temperatura y el área de visita, si todo está bien. (Fuente: página 35)
- La fuente asocia la opción **NO** del campo **presenta factor riesgo** con el listado de estudiantes y funcionarios que guardaron sus factores de riesgo sin reportar ninguno. (Fuente: página 39)

### Puntos por validar
- En las descripciones de los campos de filtro, la fuente no detalla las opciones disponibles para **Reporte de** ni para **filtro por tipo**. (Fuente: páginas 27–28, 31–32 y 36–37)
- La fuente dice “los 4 primeros campos obligatorios” para sintomatología e ingreso y “los 5 primeros campos obligatorios” para factores de riesgo, pero no muestra aquí el panel completo con el orden visual de esos campos. (Fuente: páginas 27, 31 y 36)
- La fuente indica que se filtra por tipo para obtener reportes de personal externo, pero no transcribe el nombre de la opción que debe seleccionarse. (Fuente: páginas 30 y 34–35)
- La diapositiva 38 llama al resultado “listado acceso académico” aunque el procedimiento corresponde al reporte de factores de riesgo. Confirmar si ese nombre es correcto o si se trata de un error de redacción. (Fuente: página 38)

## Procedimiento: Gestionar usuarios externos

### Propósito
Gestionar contratistas y visitantes. El módulo incluye creación y edición de contratistas y visitantes, y bloqueo de contratistas o visitantes. (Fuente: página 40)

### Requisitos y permisos
- El acceso a los módulos de gestión depende del rol correspondiente; la fuente enumera **Externos** bajo el rol **Bienestar Laboral**. (Fuente: página 10)

### Consultar el listado de externos
1. Ingresar al módulo **Externos**. Se muestra el listado de contratistas o visitantes creados en el sistema. (Fuente: página 41)
2. Usar el filtro general para buscar en la información del listado. (Fuente: página 41)

### Crear un contratista o visitante
1. Ingresar a la opción de creación de usuario externo. (Fuente: página 42)
2. En el formulario, ingresar la información básica del usuario externo que se va a registrar. (Fuente: página 42)

### Editar un contratista o visitante
1. Ingresar a la opción de edición del contratista o visitante. (Fuente: página 43)
2. En el formulario, revisar la información que se muestra y editarla según sea necesario. La fuente indica que el formulario es igual al de creación, pero muestra los datos existentes. (Fuente: página 43)
3. Si se edita un contratista, tener en cuenta que tiene una fecha máxima de ingreso. Una vez cumplida, su ingreso queda restringido; la fuente indica que sería necesario editar su fecha de ingreso. (Fuente: página 43)

### Bloquear un contratista o visitante
1. Seleccionar la opción de bloqueo individual. (Fuente: página 44)
2. Ingresar una razón de bloqueo para el contratista o visitante. (Fuente: página 44)

### Desbloquear un contratista o visitante
1. Para desbloquear a un usuario bloqueado mediante la opción anterior, seleccionar la opción de desbloqueo. (Fuente: página 44)
2. Proporcionar una razón del desbloqueo. (Fuente: página 44)

### Errores, límites o excepciones documentadas
- Un contratista puede tener restringido el ingreso cuando se cumple su fecha máxima de ingreso; la fuente indica que se puede editar esa fecha. (Fuente: página 43)
- La fuente también indica que un usuario externo puede vencer su fecha de ingreso y quedar restringido o bloqueado el acceso a la institución. (Fuente: página 44)

### Puntos por validar
- La fuente no transcribe los nombres de las opciones para crear, editar, bloquear o desbloquear usuarios externos. (Fuente: páginas 42–44)
- La fuente describe la restricción por vencimiento de fecha de ingreso para contratistas y, en la diapositiva siguiente, menciona usuarios externos en general. No especifica si la misma condición se aplica también a visitantes. (Fuente: páginas 43–44)
- La información concreta que se solicita en el formulario de creación de externos no puede confirmarse a partir del texto extraído; la descripción de imagen es automática y no verificada. (Fuente: página 42)
