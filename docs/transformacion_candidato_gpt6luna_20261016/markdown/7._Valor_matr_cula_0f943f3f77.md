- **Sistema o módulo:** SIAAF WEB; módulo «Rectoría».
- **Público o permisos mencionados por la fuente:** Portal Profesores y Administrativos. La fuente indica que se debe ingresar con usuario y contraseña, pero no detalla permisos adicionales.
- **Temas incluidos:** Acceso al sistema y generación del informe «Valor Matrícula».

## Procedimiento: Generar el informe «Valor Matrícula»

### Propósito
Generar el informe de inscripciones y matrículas correspondiente a «Valor Matrícula». (Fuente: diapositiva 1)

### Requisitos y permisos
- Acceder al «Portal Profesores y Administrativos». (Fuente: diapositiva 3)
- Digitar el usuario y la contraseña para acceder al sistema. No se reproducen credenciales. (Fuente: diapositiva 4)

### Pasos
1. Desde un navegador, ingresar al sitio web de la Universidad: `http://www.unisimon.edu.co/`. En el menú principal, seleccionar «Portales». (Fuente: diapositiva 2)
2. Dirigirse a la sección «Portal Profesores y Administrativos». (Fuente: diapositiva 3)
3. Digitar el usuario y la contraseña para acceder al sistema y presionar el botón «Acceder». (Fuente: diapositiva 4)
4. Luego de ingresar al sistema, seleccionar el módulo «Rectoría». (Fuente: diapositiva 5)
5. Luego de ingresar al módulo, seleccionar el informe «Valor Matrícula». (Fuente: diapositiva 6)
6. Aplicar los filtros solicitados de «Año», «Periodo» y «Fecha». Posteriormente, presionar el botón «Generar». (Fuente: diapositiva 7)

### Resultado esperado
Al presionar «Generar», se crea el reporte en un documento PDF para su visualización. La diapositiva siguiente está titulada «Reporte Generado». (Fuente: diapositivas 7–8)
