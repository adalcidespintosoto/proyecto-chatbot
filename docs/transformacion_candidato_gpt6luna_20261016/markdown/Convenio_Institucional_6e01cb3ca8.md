# Consulta y exportación de Convenio Institucional en SIA WEB

## Información del documento
- **Fuente original:** Convenio Institucional.pdf
- **Sistema o módulo:** SIA WEB; módulo “Convenio Institucional”.
- **Público o permisos mencionados por la fuente:** La fuente indica que se debe ingresar con usuario y contraseña, pero no especifica quién puede hacerlo ni los permisos requeridos.
- **Temas incluidos:** Acceso al sistema, consulta de información, exportación a Excel, visualización del carné y opciones de ordenamiento y filtros.

## Procedimiento: Consultar información de Convenio Institucional
### Propósito
Generar una consulta con la información solicitada mediante el filtro obligatorio “Convenio”. (Fuente: páginas 7–9)

### Requisitos y permisos
- Se requiere un usuario y una contraseña para acceder al sistema. (Fuente: página 5)
- La consulta tiene un filtro obligatorio: “Convenio”. (Fuente: página 7)

### Pasos
1. Desde un navegador, ingrese al sitio web de la Universidad: `http://www.unisimon.edu.co/`. En el menú principal, seleccione “Portales”. (Fuente: página 2)
2. Diríjase a la sección “Portal Laboral”. (Fuente: página 3)
3. Seleccione “Gestión Académico-Administrativa”. (Fuente: página 4)
4. Digite su usuario y contraseña y presione el botón “ACCEDER”. (Fuente: página 5)
5. Después de ingresar al sistema, seleccione el módulo “Convenio Institucional”. (Fuente: página 6)
6. Llene el filtro obligatorio “Convenio” y presione el botón “Generar”. (Fuente: páginas 7–8)

### Resultado esperado
- Se muestra la información solicitada. (Fuente: página 8)
- La información incluye número de identificación, nombres, apellidos, código, usuario y fecha máxima de ingreso. (Fuente: página 9)

## Procedimiento: Exportar la información a Excel
### Pasos
1. Después de generar la consulta, use el botón “Excel” para exportar la información en un archivo de Excel. (Fuente: página 10)

## Procedimiento: Ver y descargar el carné
### Pasos
1. En la información generada, haga clic en la acción “Ver carné” para visualizarlo. (Fuente: página 11)
2. En la vista del carné, use el botón “Descargar”; la fuente indica que permite imprimirlo o guardarlo como archivo PDF. (Fuente: página 12)

## Procedimiento: Ordenar, elegir columnas visibles y filtrar datos de la consulta
### Pasos
1. En “Datos complementarios”, use la flecha situada al lado de cada columna para acceder a opciones de ordenamiento, selección de las columnas que se visualizan y filtros. (Fuente: páginas 13–14)
2. Para ordenar de menor a mayor o de “A” a “Z”, use “Ordenar en forma ascendente”. (Fuente: página 15)
3. Para ordenar de mayor a menor o de “Z” a “A”, use “Ordenar en forma descendente”. (Fuente: página 15)
4. Use “Filtros” para filtrar los datos de la consulta actual. (Fuente: página 16)
