# Evaluaciones de selección (ILE–TICS): ofertas y reportes

## Información del documento
- **Fuente original:** *Evaluaciones de selección ILE-TICS (FUNCIONARIOS).pdf*
- **Sistema o módulo:** Evaluaciones de selección (ILE–TICS)
- **Público o permisos mencionados por la fuente:** La fuente identifica a funcionarios en el nombre del archivo. Indica que el usuario debe ingresar con usuario y contraseña y que la selección del tipo de prueba depende de su asignación.
- **Temas incluidos:** Acceso al portal, configuración de ofertas de pruebas y generación de reportes.

## Procedimiento: Acceder a Evaluaciones de selección
### Pasos
1. Desde la página web de la universidad, ingrese a la sección «Portales» mediante `http://www.unisimon.edu.co/portales/administrativos`. (Fuente: página 2)
2. Ingrese su usuario y contraseña y presione el botón «Acceder». (Fuente: página 2)
3. Seleccione «Evaluaciones de selección». (Fuente: página 3)

## Procedimiento: Crear, modificar o eliminar una oferta
### Pasos
1. En la sección «OFERTAS», seleccione «Configuración Evaluaciones». (Fuente: páginas 4–5)
2. Según su asignación, seleccione el tipo de prueba que va a crear, modificar o eliminar. La fuente vuelve a nombrar «Configuración Evaluaciones» al describir esta selección. (Fuente: página 6)
3. Para crear una oferta:
   1. Después de seleccionar el tipo de prueba, seleccione «Crear».
   2. Diligencie los datos en el formulario que se abrirá.
   3. Seleccione «Guardar» para finalizar. (Fuente: página 7)
4. Para modificar una oferta:
   1. Después de seleccionar el tipo de prueba, seleccione «Editar» en la oferta que desea modificar.
   2. Modifique los campos necesarios en el formulario que se abrirá con los datos de la oferta.
   3. Seleccione «Guardar». (Fuente: página 8)
5. Para eliminar una oferta:
   1. Después de seleccionar el tipo de prueba, seleccione «Eliminar» en la oferta que desea borrar.
   2. En la ventana de confirmación, seleccione «Si» para eliminar. (Fuente: página 9)

### Errores, límites o excepciones documentadas
- La selección del tipo de prueba depende de la asignación del usuario. (Fuente: página 6)

## Procedimiento: Generar reportes de evaluaciones
### Propósito
Generar el informe de las pruebas ya realizadas y consultar o descargar resultados. (Fuente: página 12)

### Pasos
1. En la sección «REPORTES», seleccione «Reportes Evaluaciones». (Fuente: páginas 10–11)
2. Seleccione el periodo académico, el tipo de prueba y el programa académico. (Fuente: página 12)
3. Seleccione «Generar» para visualizar los resultados. (Fuente: página 12)
4. Seleccione «Reporte» para descargar los resultados en un archivo de Excel. (Fuente: página 12)
5. En la columna «acciones», podrá descargar los resultados de la prueba si el aspirante la finalizó correctamente. (Fuente: página 12)
6. Si el aspirante no pudo finalizar la prueba, podrá reiniciarla para que la realice nuevamente. (Fuente: página 12)

### Errores, límites o excepciones documentadas
- La descarga de resultados desde la columna «acciones» se indica para los casos en que el aspirante finalizó correctamente la prueba. (Fuente: página 12)
- La opción de reiniciar se indica para los casos en que el aspirante no pudo finalizar la prueba. (Fuente: página 12)
