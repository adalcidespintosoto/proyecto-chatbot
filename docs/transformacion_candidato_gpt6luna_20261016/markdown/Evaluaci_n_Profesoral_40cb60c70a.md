# Evaluación profesoral en SIA WEB

## Información del documento
- **Fuente original:** Evaluación Profesoral.pdf
- **Sistema o módulo:** SIA WEB; módulo «Evaluaciones».
- **Público o permisos mencionados por la fuente:** Se indica el acceso por «Portal Profesores y Administrativos». No se especifican permisos adicionales.
- **Temas incluidos:** Acceso al sistema, selección de una evaluación y registro de respuestas.

## Procedimiento: Realizar una evaluación profesoral

### Requisitos y permisos
- Se requieren usuario y contraseña para acceder al sistema. (Fuente: página 5)
- La guía indica dirigirse a «Portal Profesores y Administrativos». No precisa otros requisitos ni permisos. (Fuente: páginas 3–5)

### Pasos
1. Desde un navegador, ingresar al sitio web de la Universidad: `http://www.unisimon.edu.co/`. (Fuente: página 3)
2. En el menú principal, seleccionar «Portales». (Fuente: página 3)
3. Dirigirse a la sección «Portal Profesores y Administrativos». (Fuente: página 4)
4. Digitar el usuario y la contraseña para acceder al sistema y presionar el botón «Acceder». (Fuente: página 5)
5. Luego de ingresar al sistema, seleccionar el módulo «Evaluaciones». (Fuente: página 6)
6. Revisar las evaluaciones disponibles, que se muestran por pestañas, y seleccionar la que se desea realizar. (Fuente: página 7)
7. Seleccionar el icono correspondiente a la evaluación que se desea realizar. (Fuente: página 8)
8. Seleccionar todas las respuestas de la evaluación y finalizar presionando el botón «Guardar». (Fuente: página 9)
