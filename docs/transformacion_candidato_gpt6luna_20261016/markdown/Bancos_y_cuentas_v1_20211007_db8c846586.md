# Bancos y cuentas bancarias en SIA Web

## Información del documento
- **Fuente original:** `Bancos y cuentas_v1_20211007.pdf`
- **Sistema o módulo:** SIA Web; módulo Contabilidad. (Fuente: páginas 1–2, 6–8)
- **Público o permisos mencionados por la fuente:** Se indica el acceso desde «Portal Profesores y Administrativos» y el uso de usuario y contraseña institucionales. (Fuente: páginas 4–5)
- **Temas incluidos:** Acceso a SIA Web, consulta de bancos activos, creación y anulación de bancos, y creación de cuentas bancarias. (Fuente: páginas 1–18)

## Procedimiento: Acceder a SIA Web y entrar a Bancos y cuentas bancarias

### Pasos
1. Desde un navegador, ingrese al sitio web de la Universidad: `http://www.unisimon.edu.co/`. En el menú principal, seleccione «Portales». (Fuente: página 3)
2. Diríjase a la sección «Portal Profesores y Administrativos». (Fuente: página 4)
3. Digite su usuario y contraseña institucional para acceder al sistema y presione el botón «Acceder». (Fuente: página 5)
4. Luego de ingresar al sistema, seleccione el módulo «Contabilidad». (Fuente: páginas 6–7)
5. Seleccione la opción «Bancos y cuentas bancarias». (Fuente: página 8)
6. Se visualizará el listado de bancos creados en el sistema que se encuentren en estado activo. (Fuente: página 9)

## Procedimiento: Crear un banco

### Pasos
1. Presione el botón «Crear banco». (Fuente: páginas 10–11)
2. En el formulario, ingrese el nombre del banco y un nombre abreviado. (Fuente: página 12)
3. Para guardar el banco, presione el botón «Aceptar». (Fuente: página 12)

## Procedimiento: Anular uno o más bancos

### Pasos
1. Seleccione la casilla correspondiente al banco o los bancos que requiera anular. (Fuente: páginas 13–14)
2. Presione el botón «Anular». (Fuente: página 14)
3. Realice la confirmación de la anulación para finalizar el proceso. (Fuente: página 15)

## Procedimiento: Crear una cuenta bancaria

### Pasos
1. Presione el icono «Crear cuenta». (Fuente: páginas 16–17)
2. Complete la información solicitada en el formulario de cuentas bancarias. (Fuente: página 18)
3. Finalice el proceso presionando el botón «Aceptar». (Fuente: página 18)
