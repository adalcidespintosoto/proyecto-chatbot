# Reporte de Inscripciones reactivadas en SIA WEB

## Información del documento
- **Fuente original:** `Reporte - Inscripción Reactivada.pdf`
- **Sistema o módulo:** SIA WEB; módulo «Matricula».
- **Público o permisos mencionados por la fuente:** «Profesores y Administrativos».
- **Temas incluidos:** Acceso al portal, ingreso al sistema y consulta de inscripciones reactivadas.

## Procedimiento: Consultar inscripciones reactivadas

### Propósito
La fuente identifica la tarea como «Reporte de Inscripciones reactivadas» y muestra el apartado «Inscripciones reactivadas». (Fuente: páginas 2 y 7)

### Requisitos y permisos
- Dirigirse a la sección «Portal Profesores y Administrativos». (Fuente: página 4)
- Se indica que se debe ingresar un usuario y una contraseña para acceder al sistema. No se especifican requisitos adicionales para esas credenciales. (Fuente: página 5)
- Los filtros obligatorios son año y periodo; los opcionales son nivel y programa. (Fuente: página 8)

### Pasos
1. Desde un navegador, ingresar al sitio web de la Universidad: `http://www.unisimon.edu.co/`. (Fuente: página 3)
2. Seleccionar en el menú principal la opción «Portales». (Fuente: página 3)
3. Dirigirse a la sección «Portal Profesores y Administrativos». (Fuente: página 4)
4. Digitar el usuario y la contraseña para acceder al sistema; luego, presionar el botón «Acceder». (Fuente: página 5)
5. Después de ingresar al sistema, seleccionar el módulo «Matricula». (Fuente: página 6)
6. Seleccionar el apartado «Inscripciones reactivadas». (Fuente: página 7)
7. Llenar los filtros obligatorios: año y periodo. Los filtros nivel y programa son opcionales. (Fuente: página 8)
8. Presionar el botón «buscar». La fuente indica que la información se generará automáticamente. (Fuente: página 8)

### Resultado esperado
Después de presionar «buscar», se genera automáticamente la información. (Fuente: página 8)
