# Manual de usuario de SITE 2.0

## Información del documento
- **Fuente original:** `SITE 2.0.pptx`
- **Sistema o módulo:** SITE 2.0
- **Público o permisos mencionados por la fuente:** La diapositiva de inicio de sesión indica que cada funcionario tiene un usuario y una contraseña de carácter individual. La eliminación de registros de pago requiere privilegios configurados para ese proceso.
- **Temas incluidos:** Inicio de sesión y navegación; agenda y reportes; configuración de clientes, salones, utilería, festivos y tarifas; cotizaciones y reservas internas; pagos; logística de eventos; acceso desde dispositivos móviles. (Fuente: diapositivas 2–43)

## Procedimiento: Iniciar sesión en SITE 2.0
### Propósito
Acceder al sistema SITE 2.0. (Fuente: diapositiva 3)

### Requisitos y permisos
- Se requiere el usuario y la contraseña individuales del funcionario. La fuente indica que ya son de su conocimiento. No se reproducen credenciales. (Fuente: diapositiva 3)

### Pasos
1. Abra un navegador. Se puede utilizar cualquier navegador; se prefieren Chrome o Firefox Mozilla. (Fuente: diapositiva 3)
2. Ingrese a `https://site.unisimon.edu.co`. (Fuente: diapositiva 3)
3. Ingrese el usuario y la contraseña cuando la página los solicite. (Fuente: diapositiva 3)

### Resultado esperado
Si el usuario y la contraseña son correctos, el sistema muestra el Dashboard o página de aterrizaje. (Fuente: diapositiva 4)

### Errores, límites o excepciones documentadas
- La diapositiva 3 incluye una descripción automática de imagen no verificada que menciona una interfaz distinta y varios elementos repetidos. No se toma como instrucción del procedimiento. (Fuente: diapositiva 3)

## Procedimiento: Consultar el Dashboard y usar el menú principal
### Propósito
El Dashboard muestra eventos por confirmar para cotizaciones y reservas internas. El menú principal permite acceder a los módulos del sistema. (Fuente: diapositivas 4–5)

### Pasos
1. Después de iniciar sesión correctamente, consulte en el Dashboard el listado de eventos por confirmar para cotizaciones y reservas internas. También se indica que puede visualizarse otra información. (Fuente: diapositiva 4; diapositiva 5)
2. Utilice el menú situado a la izquierda de la pantalla para acceder a los distintos módulos. (Fuente: diapositiva 4)
3. Para cerrar sesión, haga clic en el nombre de usuario y seleccione en el menú desplegado la opción para culminar o cerrar sesión. La fuente no proporciona el nombre exacto de esa opción. (Fuente: diapositiva 5)
4. Use las opciones descritas en el menú:
   - **Dashboard:** página de aterrizaje con información de cotizaciones y eventos internos por confirmar, entre otra información. (Fuente: diapositiva 5)
   - **Agenda:** módulo para consultar el calendario de eventos y reservas. (Fuente: diapositiva 5)
   - **Reportes:** módulo que gestiona los reportes utilizados. (Fuente: diapositiva 5)

## Procedimiento: Administrar clientes
### Propósito
Buscar y gestionar la información de clientes externos. La administración permite crear clientes, generar un reporte completo de clientes y eliminar o dar de baja a un cliente específico. (Fuente: diapositivas 8–9)

### Pasos
1. Ingrese a **Clientes** desde el módulo **Configuración**. (Fuente: diapositivas 8–9)
2. Use el panel de búsqueda para buscar un cliente específico y gestionar su información. (Fuente: diapositiva 9)
3. Para crear un cliente:
   1. Seleccione la opción de color naranjado **“Nuevo Cliente”**.
   2. Complete el formulario con la información del nuevo cliente.
   3. Guarde la información. (Fuente: diapositiva 10)
4. Para generar un reporte, use la opción para generar el reporte completo de clientes. La fuente no especifica el nombre de la opción ni los pasos adicionales. (Fuente: diapositiva 9)
5. Para eliminar o dar de baja a un cliente:
   1. Seleccione en el panel de búsqueda la opción correspondiente. La fuente no permite identificar el nombre o icono de esta opción.
   2. Ingrese una razón de eliminación cuando el sistema la solicite. La razón quedará guardada en el sistema. (Fuente: diapositiva 11)

### Puntos por validar
- La descripción automática de imagen de la diapositiva 10 enumera posibles campos de formulario, pero su repetición y legibilidad no permiten confirmar cuáles son los campos reales. (Fuente: diapositiva 10)
- La opción de eliminación de cliente aparece como un espacio en blanco en el texto extraído. No se identifica su nombre o icono. (Fuente: diapositiva 11)

   3. Guarde los cambios. (Fuente: diapositiva 14)
5. Para eliminar un salón:
   1. Seleccione en el panel de búsqueda la opción correspondiente. La fuente no permite identificar el nombre o icono.
   2. Ingrese una razón de eliminación cuando el sistema la solicite. La razón quedará guardada en el sistema. (Fuente: diapositiva 15)

## Procedimiento: Administrar periodos festivos
### Propósito
Consultar y gestionar periodos anuales y los días festivos comprendidos en cada periodo. El sistema permite buscar, crear, editar y eliminar periodos. (Fuente: diapositiva 19)

### Pasos
1. Ingrese a **Festivo** desde el módulo **Configuración**. (Fuente: diapositivas 8, 19)
2. Para crear un periodo festivo:
   1. Seleccione la opción de color naranjado **“Nueva Festivo”**.
   2. Ingrese el número del periodo que desea crear.
   3. Seleccione el tipo de ingreso de los días festivos: **“Días Festivos Individual”** o **“Cargar Excel de Días”**. (Fuente: diapositiva 20)
3. Si selecciona **“Días Festivos Individual”**:
   1. Ingrese uno a uno los días festivos que desea configurar.
   2. Seleccione **agregar día**.
   3. Si ingresó un día festivo erróneo, puede eliminarlo de la vista temporal de días festivos por guardar mediante una opción cuyo nombre o icono no se distingue en el texto extraído. (Fuente: diapositiva 21)
4. Si selecciona **“Cargar Excel de Días”**:
   1. Prepare previamente un archivo Excel con la información de los días festivos ordenada en una sola columna.
   2. Cargue el archivo al sistema.
   3. Guarde. (Fuente: diapositiva 22)
   4. Si ingresó un día festivo erróneo, puede eliminarlo de la vista temporal de días festivos por guardar mediante una opción cuyo nombre o icono no se distingue en el texto extraído. (Fuente: diapositiva 22)

### Errores, límites o excepciones documentadas
- La fuente señala que cargar un Excel resulta “mucho más rápido” que el ingreso individual; no proporciona una duración ni una comparación adicional. (Fuente: diapositiva 22)

### Puntos por validar
- La fuente no detalla cómo buscar, editar o eliminar periodos, aunque indica que esas acciones están disponibles. (Fuente: diapositiva 19)
- La opción para retirar un día de la vista temporal aparece en blanco en el texto extraído. (Fuente: diapositivas 21–22)

## Procedimiento: Administrar tarifas
### Propósito
Consultar y gestionar periodos tarifarios de auditorios, salones, salas y teatro. El sistema permite buscar, crear, editar y eliminar. (Fuente: diapositiva 23)

### Pasos
1. Ingrese a **Tarifas** desde el módulo **Configuración**. (Fuente: diapositivas 8, 23)
2. Para crear un periodo de tarifa:
   1. Seleccione la opción de color naranjado **“Nueva Tarifa”**.
   2. Ingrese el periodo de la tarifa.
   3. Ingrese la información individual de cada tarifa que se cobrará por los salones. (Fuente: diapositiva 24)
3. Para agregar una tarifa individual a un salón:
   1. En el formulario, seleccione **“Agregar Individual”**.
   2. En la ventana emergente, ingrese los datos para agregar la tarifa a un salón específico: salón, jornada, fecha de inicio y fin, valor y vigencia.
   3. Seleccione **agregar**.
   4. Continúe configurando los salones que hagan falta para completar la tarifa. (Fuente: diapositiva 25)
4. Para editar una tarifa:
   1. Seleccione en el panel de búsqueda la opción correspondiente. El texto extraído no identifica su nombre o icono.
   2. Se abrirá el detalle de la tarifa seleccionada. (Fuente: diapositiva 26)
5. Para eliminar una tarifa de un salón, seleccione la opción correspondiente. El texto extraído no identifica su nombre o icono. (Fuente: diapositiva 26)
6. Para crear un nuevo registro de tarifa desde la edición, ingrese a **“Nueva tarifa”** y complete el pequeño formulario para configurar el registro. (Fuente: diapositiva 26)

### Puntos por validar
- La diapositiva 25 menciona los campos **fecha inicio – fin** y **vigencia**. La descripción automática de imagen también menciona “Vencimiento”, pero no permite confirmar si es un campo adicional del formulario.
- La fuente no describe qué ocurre al guardar el periodo de tarifa completo ni identifica los controles de edición y eliminación de tarifas. (Fuente: diapositivas 24–26)

## Procedimiento: Crear una cotización
### Propósito
Registrar una cotización con la información del cliente y los eventos que se cargarán a ella. (Fuente: diapositivas 31–32)

### Pasos
1. Seleccione la opción de color naranjado **“Nueva Cotización”**. Se abrirá un formulario. La fuente indica que los formularios de cotización y de evento interno comparten similitudes. (Fuente: diapositiva 31)
2. Ingrese la fecha de creación y el plazo. El sistema calcula automáticamente la fecha de vencimiento para reservar la cotización a partir del plazo. (Fuente: diapositiva 32)
3. Ingrese los datos del cliente al que se cargará la cotización. (Fuente: diapositiva 32)
4. Agregue el listado de eventos que se cargarán a la cotización. (Fuente: diapositiva 32)
5. Para agregar un evento, ingrese la información pertinente, desde el nombre con el que se identificará el evento hasta una breve observación, si es necesaria. Algunos campos son obligatorios y están marcados en el formulario. (Fuente: diapositiva 33)
6. Revise los valores parcial y total del evento, que se muestran en la parte derecha de la ventana y se calculan según la configuración de la tarifa seleccionada, el salón y los demás campos ingresados. (Fuente: diapositiva 33)

### Puntos por validar
- La fuente no detalla los campos del formulario de cotización ni cómo guardar o finalizar la cotización.
- La descripción automática de imagen de la diapositiva 33 no permite confirmar otros campos o controles del formulario. (Fuente: diapositiva 33)

## Procedimiento: Consultar, registrar y gestionar pagos
### Propósito
Consultar los pagos realizados a cotizaciones y acceder a opciones para registrar, imprimir, ver o eliminar registros de pago. (Fuente: diapositiva 35)

### Pasos
1. Ingrese a **Pagos** desde el módulo **Movimientos**. (Fuente: diapositivas 27, 35)
2. Para registrar un pago:
   1. Seleccione la opción para crear un nuevo pago.
   2. Seleccione el cliente al que se registrará el pago.
   3. Ingrese la información solicitada, que incluye fecha de pago, valor de pago y tipo de pago, entre otros campos. (Fuente: diapositiva 36)
3. Para ver un pago, ingrese a la opción correspondiente. Se mostrará el detalle del registro de pago seleccionado, desde la información del cliente hasta el método de pago utilizado y otros datos. El texto extraído no identifica el nombre o icono de la opción. (Fuente: diapositiva 37)
4. Para imprimir un recibo de pago, use la opción correspondiente, disponible en la administración de pagos. La fuente no describe los pasos posteriores. (Fuente: diapositiva 35)
5. Para eliminar un registro de pago:
   1. Seleccione en el panel de búsqueda la opción correspondiente. El texto extraído no identifica su nombre o icono.
   2. Ingrese un usuario y una contraseña de autenticación cuando el sistema los solicite. No se reproducen credenciales.
   3. La eliminación solo puede realizarla un usuario con los privilegios configurados para ese proceso; no todos los usuarios están autorizados. (Fuente: diapositiva 38)

### Errores, límites o excepciones documentadas
- La eliminación de un registro de pago está restringida a usuarios con los privilegios configurados para el proceso. (Fuente: diapositiva 38)

### Puntos por validar
- La descripción automática de imagen de la diapositiva 38 muestra un formulario de autenticación y un mensaje de error, pero la fuente no permite establecer si ese mensaje corresponde al procedimiento general o a un caso específico. No se reproduce el mensaje como una solución o resultado esperado. (Fuente: diapositiva 38)

2. Seleccione si configurará la logística para una cotización o para un evento interno. (Fuente: diapositiva 39)

4. Si selecciona una reserva interna, ingrese el usuario interno; la fuente indica que el funcionamiento es equivalente al de la selección de cotización. (Fuente: diapositiva 40)
5. Ingrese la información básica de logística: seleccione el elemento de utilería, indique la cantidad y agregue una breve descripción si se necesita más información para el personal de logística. (Fuente: diapositiva 41)
6. Seleccione el evento o los eventos a los que se aplicará esa configuración. Un mismo conjunto de configuración puede aplicarse a varios eventos para agilizar la creación de logística. (Fuente: diapositiva 42)

### Puntos por validar

- Las descripciones automáticas de imagen de las diapositivas 40–42 contienen elementos que no se pueden confirmar como parte de este procedimiento. No se utilizan para completar pasos ni nombres de controles. (Fuente: diapositivas 40–42)
