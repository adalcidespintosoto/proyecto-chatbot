# Oferta de inscripción para grados en SIA WEB

## Información del documento
- **Fuente original:** *Ofertas de inscripción para grados.pdf*
- **Sistema o módulo:** SIA WEB; Registro y Control Académico. (Fuente: páginas 4–5)
- **Público o permisos mencionados por la fuente:** El procedimiento de ingreso indica usar usuario y contraseña; no especifica quién puede realizarlo ni los permisos requeridos. (Fuente: página 3)
- **Temas incluidos:** Ingreso al portal, búsqueda, creación, activación y anulación de ofertas de inscripción para grados.

## Procedimiento: Ingresar a la oferta de inscripción para grados

### Pasos
1. Desde la página web de la universidad, ingrese a la sección «Portales» en `http://www.unisimon.edu.co/portales/administrativos`. Ingrese su usuario y contraseña y presione «Acceder». (Fuente: página 3)
2. Al ingresar al portal SIA WEB, seleccione el icono «Registro y Control Académico». (Fuente: página 4)
3. Seleccione el icono «Oferta Inscripción para Grados». (Fuente: página 5)

## Procedimiento: Consultar y filtrar ofertas

### Pasos
1. Seleccione el año y el periodo académico. A continuación, cargarán las demás opciones disponibles. (Fuente: página 6)
2. Seleccione «Buscar» para listar todas las ofertas creadas. (Fuente: página 7)
3. Si desea filtrar, seleccione el campo por el cual desea filtrar: nivel académico, programa académico o estado de la oferta. Luego, seleccione nuevamente «Buscar». (Fuente: página 7)

## Procedimiento: Crear una oferta de inscripción para grados

### Pasos
1. Seleccione «Crear». (Fuente: página 8)
2. En la ventana emergente, seleccione el nivel académico. (Fuente: página 8)
3. Seleccione el o los programas. (Fuente: página 8)
4. Seleccione el rango de fecha de inscripciones. (Fuente: página 8)
5. Seleccione el rango de fecha de grados. (Fuente: página 8)
6. Haga clic en «Guardar». (Fuente: página 8)

## Procedimiento: Activar ofertas

### Pasos
1. Seleccione los registros que desea activar. (Fuente: página 9)
2. Seleccione «Activar». (Fuente: página 9)
3. En la ventana de confirmación, seleccione «Si». (Fuente: página 9)

## Procedimiento: Anular ofertas

### Pasos
1. Seleccione los registros que desea anular. (Fuente: página 10)
2. Seleccione «Anular». (Fuente: página 10)
3. En la ventana de confirmación, seleccione «Si». (Fuente: página 10)
