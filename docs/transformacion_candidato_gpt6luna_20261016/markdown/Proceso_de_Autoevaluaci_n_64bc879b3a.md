# Instructivo para realizar el proceso de autoevaluación en SIAAF WEB

## Información del documento
- Fuente original: `Proceso de Autoevaluación.pptx`
- Sistema o módulo: SIAAF WEB
- Público o permisos mencionados por la fuente: diapositivarofesor, Estudiante e Invitado.
- Temas incluidos: acceso al sistema, evaluación de factores y evaluación de aspectos.

## Procedimiento: Acceder al proceso de autoevaluación

### Propósito
Ingresar al proceso de autoevaluación en SIAAF WEB. (Fuente: diapositivas 1–5)

### Pasos
1. Desde un navegador, ingrese al sitio web de la Universidad: `http://www.unisimon.edu.co/`. En el menú principal, seleccione «Servicios». (Fuente: diapositiva 2)
2. Diríjase a la sección «Autoevaluación». (Fuente: diapositiva 3)
3. Seleccione el icono «Procesos en curso». (Fuente: diapositiva 4)
4. Seleccione el tipo de usuario: Profesor, Estudiante o Invitado. Digite la información solicitada según el caso y presione el botón «Ingresar». (Fuente: diapositiva 5)

## Procedimiento: Ponderar factores y evaluar sus características

### Propósito
Ponderar factores y evaluar las características correspondientes. (Fuente: diapositivas 6–10)

### Pasos
1. Al ingresar, se mostrarán las evaluaciones disponibles para ponderar los factores y las características. (Fuente: diapositiva 6)
2. En la ventana «Evaluaciones disponibles», presione el icono que aparece sobre la evaluación que desea realizar para ponderar los factores. La fuente no identifica el icono con un nombre. (Fuente: diapositiva 7)
3. Se mostrarán los factores con sus respectivas características a evaluar y el estado de cada característica. La fuente enumera los estados «Realizado» y «Pendiente». (Fuente: diapositiva 8)
4. Para realizar la evaluación de una característica, presione el botón indicado en la pantalla; la fuente no identifica el botón con un nombre. (Fuente: diapositiva 8)
5. Digite los valores y las observaciones para cada característica. Los valores deben estar entre 0.01 y 5.00, inclusive. (Fuente: diapositiva 9)
6. Presione «Aceptar». (Fuente: diapositiva 9)
7. Al aceptar la evaluación digitada, se solicitará confirmar la información. En esa instancia se podrá finalizar la evaluación de la característica o guardarla con la posibilidad de modificarla posteriormente. (Fuente: diapositiva 10)

## Procedimiento: Evaluar aspectos y sus características

### Propósito
Evaluar aspectos y sus características correspondientes. (Fuente: diapositivas 11–12)

### Pasos
1. En la ventana «Evaluaciones disponibles», presione el icono que aparece sobre la evaluación que desea realizar para ponderar los aspectos. La fuente no identifica el icono con un nombre. (Fuente: diapositiva 11)
2. Se mostrarán los aspectos con sus respectivas características a evaluar. Digite los valores para cada ítem y presione «Siguiente» para continuar y finalizar el proceso. (Fuente: diapositiva 12)
