# Instructivo para generar el reporte de Franja Horaria en SIAAF WEB

## Información del documento
- **Fuente original:** Reporte - Franja Horaria.pdf
- **Sistema o módulo:** SIAAF WEB; módulo «Asignación Académica».
- **Público o permisos mencionados por la fuente:** Se indica acceder desde la sección «Profesores y Administrativos». No se especifican permisos adicionales.
- **Temas incluidos:** Acceso al sistema, selección del módulo y del período, y generación del reporte «Franja Horaria».

## Procedimiento: Generar el reporte de Franja Horaria

### Propósito
Generar el reporte «Franja Horaria» en el módulo «Asignación Académica». (Fuente: páginas 1 y 6–7)

### Requisitos y permisos
- La fuente indica ingresar desde la sección «Profesores y Administrativos» con usuario y contraseña. (Fuente: página 3)

### Pasos
1. Desde un navegador, ingrese al sitio web de la Universidad: http://www.unisimon.edu.co/. En el menú principal, seleccione «Portales». (Fuente: página 2)
2. Diríjase a la sección «Profesores y Administrativos», digite su usuario y contraseña y presione el botón «Ingresar». (Fuente: página 3)
3. Después de ingresar, seleccione el módulo «Asignación Académica». (Fuente: página 4)
4. Seleccione el año y el período en el cual trabajará. Por defecto, se mostrará el período actual. El período seleccionado le indica al sistema qué información mostrará en todo el módulo. (Fuente: página 5)
5. Después de definir el período, seleccione «Reporte» en el menú. (Fuente: página 6)
6. Dentro de las opciones, seleccione el reporte «Franja Horaria». (Fuente: página 6)
7. Aplique los filtros para generar el reporte por franja horaria y presione «Buscar». (Fuente: página 7)

### Resultado esperado
La fuente indica que, después de aplicar los filtros y presionar «Buscar», se genera el reporte por franja horaria. No especifica cómo se presenta el resultado. (Fuente: página 7)

Paráfrasis editoriales para mejorar la búsqueda; no son afirmaciones adicionales del documento: reporte de franja horaria, buscar franja horaria, generar reporte por horario, reporte en Asignación Académica, seleccionar período para el reporte.
