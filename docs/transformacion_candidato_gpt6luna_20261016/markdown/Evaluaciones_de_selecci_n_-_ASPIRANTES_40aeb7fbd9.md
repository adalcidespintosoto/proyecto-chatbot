# Evaluaciones de selección de Medicina: instructivo para aspirantes

## Información del documento
- **Fuente original:** *Evaluaciones de selección - ASPIRANTES.pdf*
- **Sistema o módulo:** Portal de evaluaciones de selección; la fuente identifica el proceso como «Medicina».
- **Público o permisos mencionados por la fuente:** Aspirantes.
- **Temas incluidos:** Acceso al portal, inicio y realización de evaluaciones, consulta de instrucciones y confirmación de finalización.

## Procedimiento: Acceder al portal de evaluaciones de selección

### Requisitos y permisos
- Las credenciales de acceso son el número de identificación y la fecha de expedición del documento. (Fuente: página 2)
- La fecha de expedición debe escribirse con el formato `AAAA-MM-DD`. La fuente da como ejemplo una fecha, que se omite aquí por tratarse de un dato de ejemplo. (Fuente: página 2)

### Pasos
1. Escanee el código QR o acceda desde un navegador web a `https://portal.unisimon.edu.co/seleccion/`. (Fuente: página 2)
2. Para una mejor experiencia, la fuente recomienda usar Google Chrome. (Fuente: página 2)
3. Ingrese el número de identificación y la fecha de expedición del documento. (Fuente: página 2)
4. Seleccione **“Continuar”**. (Fuente: página 2)

## Procedimiento: Realizar una evaluación

### Propósito
Completar las evaluaciones que se muestran al ingresar al sistema. El procedimiento descrito debe realizarse para cada evaluación del listado. (Fuente: página 3)

### Pasos
1. Al ingresar, consulte el listado de evaluaciones que deberá realizar. (Fuente: página 3)
2. Para comenzar una prueba, presione el icono **“Comenzar”**. (Fuente: página 3)
3. Antes de iniciar cada prueba, lea atentamente las instrucciones, donde se indica el tipo de preguntas y respuestas. (Fuente: página 4)
4. Una vez leídas las instrucciones, seleccione **“Continuar”** para iniciar la prueba. (Fuente: página 4)
5. Lea y responda cada pregunta. (Fuente: página 5)
6. Presione **“Guardar”** para finalizar la evaluación. (Fuente: página 5)

### Resultado esperado
- Al finalizar cada evaluación, el sistema actualizará la página, mostrará el mensaje **“Evaluación realizada correctamente”** y marcará la evaluación como realizada. (Fuente: página 6)

### Errores, límites o excepciones documentadas
- Si al guardar se ha olvidado responder alguna pregunta, el sistema mostrará una advertencia con el número de la pregunta sin respuesta. (Fuente: página 5)
- El instructivo estará disponible durante la realización de cada evaluación mediante un icono. La fuente no identifica el icono con un nombre; la imagen contiene un símbolo de interrogación. (Fuente: página 5)

## Palabras y formas de búsqueda
