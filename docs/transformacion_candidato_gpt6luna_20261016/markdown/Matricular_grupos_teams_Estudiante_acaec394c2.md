# Matricular grupos en Teams desde el portal de Estudiantes

## Información del documento

- **Sistema o módulo:** Portal de Estudiantes y Teams
- **Público o permisos mencionados por la fuente:** Estudiantes
- **Temas incluidos:** Consultar el estado de matrícula de un grupo en Teams y solicitar la matrícula.

## Procedimiento: Matricular un grupo en Teams desde el portal de Estudiantes

### Propósito
Consultar si un grupo ya está matriculado en Teams y, si no lo está, solicitar la matrícula. (Fuente: páginas 2–4)

### Requisitos y permisos
- El procedimiento está dirigido a estudiantes. (Fuente: página 1)
- Se indica que un grupo puede aparecer como **“No activo”** si no se ha escogido horario para ese grupo o si no posee profesor asignado. (Fuente: página 4)

### Pasos
1. Ingrese al portal de Estudiantes: https://www.unisimon.edu.co/portales/estudiantes. (Fuente: página 2)
2. Seleccione **Calificaciones**. (Fuente: página 3)
3. Permita que el sistema verifique durante unos segundos el estado de cada grupo en Teams. Después, el sistema mostrará si el grupo ya está matriculado. (Fuente: página 4)
4. Si el grupo no está matriculado, seleccione el botón **“Matricular en Teams …”**. La fuente también muestra el nombre del botón como **“Matricular en Teams…”**. (Fuente: páginas 4–5)
5. Después de seleccionar el botón, espere unos segundos mientras el sistema envía la información. (Fuente: página 5)
6. Luego, espere aproximadamente 5 minutos para que se realice la asignación en Teams. (Fuente: página 6)

### Resultado esperado
El sistema muestra si el grupo ya está matriculado en Teams. Si se solicita la matrícula, la asignación en Teams queda realizada después de esperar aproximadamente 5 minutos. (Fuente: páginas 4 y 6)

### Errores, límites o excepciones documentadas
- Si el estado indica **“No activo”**, significa que no se ha escogido horario para ese grupo o que no posee profesor asignado. (Fuente: página 4)
