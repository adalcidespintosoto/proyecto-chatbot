# Reportes de desertores en SIA WEB

## Información del documento
- **Fuente original:** `Reportes de Desertores.pdf`
- **Sistema o módulo:** SIA WEB; módulo «Desertores».
- **Público o permisos mencionados por la fuente:** «Portal Profesores y Administrativos»; se indica ingresar con usuario y contraseña.
- **Temas incluidos:** Acceso a SIA WEB y generación de reportes de desertores por programa consolidado, por factores, por factores por semestre, por factores y edad, y por factores y género. (Fuente: páginas 2–27)

## Procedimiento: Acceder al módulo de reportes de desertores

### Pasos
1. Desde un navegador, ingresar al sitio web de la Universidad: `http://www.unisimon.edu.co/`. (Fuente: página 3)
2. En el menú principal, seleccionar «Portales». (Fuente: página 3)
3. Dirigirse a la sección «Portal Profesores y Administrativos». (Fuente: página 4)
4. Digitar el usuario y la contraseña para acceder al sistema y presionar el botón «Acceder». (Fuente: página 5)
5. Luego de ingresar al sistema, seleccionar el módulo «Desertores». (Fuente: página 6)
6. Seleccionar el icono «Reportes». (Fuente: página 7)
7. Se mostrarán los reportes disponibles. (Fuente: página 8)

## Procedimiento: Generar el reporte por programa consolidado

### Pasos
1. En los reportes disponibles, seleccionar «Reporte por programa consolidado». (Fuente: páginas 8–9)
2. Completar todos los filtros: año, periodo, tipo deserción, nivel y programa. (Fuente: página 10)
3. Presionar el botón «buscar». (Fuente: página 10)
4. Se mostrará un aviso previo para generar el reporte. Presionar «Si» para que se genere automáticamente. (Fuente: página 11)

### Resultado esperado
- El reporte se genera automáticamente después de confirmar con «Si». (Fuente: página 11)
