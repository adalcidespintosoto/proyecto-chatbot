# Instructivo para generar los reportes de Bienestar en SIAAF WEB

## Información del documento
- Fuente original: `Reportes de Bienestar.pptx`
- Sistema o módulo: SIAAF WEB; módulo «Bienestar».
- Público o permisos mencionados por la fuente: diapositivaortal Profesores y Administrativos.
- Temas incluidos: acceso al sistema y generación de reportes de Bienestar.

## Procedimiento: Acceder a SIAAF WEB y abrir Reportes de Bienestar

### Propósito
Acceder al módulo «Bienestar» y abrir el informe «Reportes». (Fuente: diapositivas 1–6)

### Pasos
1. Desde el navegador, ingrese al sitio web de la Universidad: `http://www.unisimon.edu.co/`. En el menú principal, seleccione «Portales». (Fuente: diapositiva 2)
2. Diríjase a la sección «Portal Profesores y Administrativos». (Fuente: diapositiva 3)
3. Digite su usuario y contraseña y presione el botón «Acceder». (Fuente: diapositiva 4)
4. Una vez dentro del sistema, seleccione el módulo «Bienestar». (Fuente: diapositiva 5)
5. Una vez dentro del módulo, seleccione el informe «Reportes». (Fuente: diapositiva 6)

### Requisitos y permisos
- La fuente indica el acceso por «Portal Profesores y Administrativos» y solicita usuario y contraseña. No especifica permisos adicionales. (Fuente: diapositivas 3–4)

## Procedimiento: Generar el reporte «Detalle de Selección/Caracterización»

### Pasos
1. En el «Menú de Reportes», elija el reporte que desea. (Fuente: diapositiva 7)
2. Aplique los filtros solicitados: Año, Periodo, Nivel y Programa. (Fuente: diapositivas 7–8)
3. Presione «Imprimir» o «Exportar Excel» para crear el reporte. (Fuente: diapositivas 7–8)

### Resultado esperado
Se crea el reporte; la fuente indica que puede generarse mediante «Imprimir» o «Exportar Excel». (Fuente: diapositivas 7–8)
