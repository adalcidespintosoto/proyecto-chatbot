## Procedimiento: Consultar el reporte de reingresos y transferencias internas

### Propósito
Consultar información del reporte de reingresos y transferencias internas. (Fuente: páginas 1, 7–10)

### Requisitos y permisos
- Se requiere usuario y contraseña para acceder al sistema. (Fuente: página 5)
- El reporte tiene filtros obligatorios de **Año**, **Periodo** y **Nivel de formación**; **Programa** es opcional. (Fuente: página 8)

### Pasos
1. Desde un navegador, ingrese al sitio web de la Universidad: `http://www.unisimon.edu.co/`. En el menú principal, seleccione «Portales». (Fuente: página 2)
2. Diríjase a la sección «Portal Laboral». (Fuente: página 3)
3. Seleccione la sección «Gestión Académico-Administrativa». (Fuente: página 4)
4. Digite su usuario y contraseña y presione el botón «ACCEDER». (Fuente: página 5)
5. Una vez dentro del sistema, seleccione el módulo «Reportes». (Fuente: página 6)
6. Seleccione el apartado «Reingresos y Transferencias Internas». (Fuente: página 7)
7. Complete los filtros obligatorios: **Año**, **Periodo** y **Nivel de formación**. Si lo desea, use el filtro opcional **Programa**. (Fuente: páginas 8–9)
8. Presione el botón «Generar». Se mostrará la información solicitada. (Fuente: página 9)

### Resultado esperado
La información del reporte incluye nombre, número de identificación, correo, teléfonos, dirección, fecha de inscripción, facultad, programa, nivel de avance, tipo de inscripción y si está matriculado. (Fuente: página 10)

### Errores, límites o excepciones documentadas
- La fuente no documenta errores ni límites de uso del reporte.
- La fuente indica que **Programa** es un filtro opcional. (Fuente: página 8)

## Procedimiento: Exportar el reporte a Excel

### Propósito
Exportar la información del reporte a un archivo de Excel. (Fuente: página 11)

### Pasos
1. Después de generar la información, use el botón «Excel» para exportarla a un archivo de Excel. (Fuente: páginas 9–11)

## Procedimiento: Ordenar y filtrar las columnas del reporte

### Propósito
Ordenar los datos y filtrar los datos de la consulta actual mediante las opciones de las columnas. (Fuente: páginas 13–15)

### Pasos
1. Haga clic en la flecha situada junto a cada columna para acceder a las opciones de ordenamiento, selección de columnas visibles y filtros. (Fuente: página 13)
2. Para ordenar de menor a mayor o de «A» a «Z», use «Ordenar en forma ascendente». (Fuente: página 14)
3. Para ordenar de mayor a menor o de «Z» a «A», use «Ordenar en forma descendente». (Fuente: página 14)
4. Use «Filtros» para filtrar los datos de la consulta actual. (Fuente: página 15)
