# Aplicativo Elecciones: módulo Usuarios Votantes

## Información del documento
- **Fuente original:** *Aplicativo Elecciones - Módulo Usuarios Votantes.pptx*.
- **Sistema o módulo:** Aplicativo Elecciones, módulo Usuarios Votantes. (Fuente: diapositivas 1–2)
- **Temas incluidos:** agregar un usuario, importar usuarios y usar la plantilla de Excel. (Fuente: diapositivas 3–5)

## Procedimiento: Agregar un usuario

### Pasos
1. Seleccione el botón “Agregar Usuario”. (Fuente: diapositiva 3)
2. Diligencie los campos de la ventana emergente que aparecerá. (Fuente: diapositiva 3)
3. Seleccione el botón “Guardar”. (Fuente: diapositiva 3)

## Procedimiento: Importar usuarios de forma masiva

### Propósito
Crear múltiples usuarios de forma masiva. (Fuente: diapositiva 4)

### Pasos
1. Seleccione el botón “Importar Usuario”. (Fuente: diapositiva 4)
2. En la ventana emergente que aparecerá, cargue el archivo Excel con la información requerida para la creación de los usuarios. (Fuente: diapositiva 4)
3. Seleccione el botón “Guardar”. (Fuente: diapositiva 4)

### Errores, límites o excepciones documentadas
- El archivo Excel que debe diligenciarse y cargarse puede descargarse seleccionando el botón “Plantilla Excel”. (Fuente: diapositiva 4)

## Procedimiento: Descargar y diligenciar la plantilla de usuarios

### Pasos
1. Seleccione el botón “Plantilla Excel”. (Fuente: diapositiva 5)
2. Diligencie la información requerida para la creación de los usuarios en la ventana emergente que aparecerá. (Fuente: diapositiva 5)

Estas son paráfrasis editoriales para mejorar la búsqueda; no son afirmaciones adicionales del documento: crear usuario, agregar votante, cargar usuarios en bloque, importar usuarios desde Excel, plantilla de usuarios, descargar plantilla Excel.
