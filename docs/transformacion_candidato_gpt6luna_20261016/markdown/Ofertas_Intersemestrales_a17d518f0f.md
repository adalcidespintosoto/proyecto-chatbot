# Creación de ofertas para cursos intersemestrales en SIA WEB

## Información del documento
- **Fuente original:** Ofertas Intersemestrales.pptx
- **Sistema o módulo:** SIA WEB; módulo «Matrícula»
- **Público o permisos mencionados por la fuente:** Portal Profesores y Administrativos. La fuente indica que se debe ingresar con usuario y contraseña.
- **Temas incluidos:** Acceso al sistema y creación de una oferta para cursos intersemestrales.

## Procedimiento: Crear una oferta para cursos intersemestrales

### Propósito
Crear una oferta para cursos intersemestrales. (Fuente: diapositivas 2, 8–11)

### Requisitos y permisos
- Ingresar al «Portal Profesores y Administrativos». (Fuente: diapositivas 3–4)
- Digitar el usuario y la contraseña para acceder al sistema. (Fuente: diapositiva 5)

### Pasos
1. Desde un navegador, ingrese al sitio web de la Universidad: `http://www.unisimon.edu.co/`. En el menú principal, seleccione «Portales». (Fuente: diapositiva 3)
2. Diríjase a la sección «Portal Profesores y Administrativos». (Fuente: diapositiva 4)
3. Digite su usuario y contraseña y presione el botón «Acceder». (Fuente: diapositiva 5)
4. Luego de ingresar al sistema, seleccione el módulo «Matrícula». (Fuente: diapositiva 6)
5. Ingrese a la sección «Ofertas Intersemestrales». (Fuente: diapositiva 7)
6. Seleccione los filtros de búsqueda de año, periodo, programa y semestre para realizar la creación de la oferta. (Fuente: diapositiva 8)
7. Presione el botón «Crear». (Fuente: diapositiva 9)
8. Seleccione la fecha de inicio, la fecha de fin y las asignaturas correspondientes a la oferta que va a crear. (Fuente: diapositiva 10)
9. Finalice el proceso presionando el botón «Guardar». (Fuente: diapositiva 11)
