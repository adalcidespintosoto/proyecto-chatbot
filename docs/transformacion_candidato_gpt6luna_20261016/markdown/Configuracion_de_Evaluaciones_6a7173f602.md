# Configuración de evaluaciones de Bienestar en SIAAF WEB

## Información del documento
- **Fuente original:** `Configuracion de Evaluaciones.pptx`
- **Sistema o módulo:** SIAAF WEB; módulo «Bienestar»
- **Público o permisos mencionados por la fuente:** El acceso se realiza desde «Portal Profesores y Administrativos». La fuente indica que se debe ingresar usuario y contraseña, pero no especifica permisos adicionales.
- **Temas incluidos:** Acceso al portal, navegación al módulo de Bienestar y creación de una oferta para evaluaciones CAQ o KOLB.

## Procedimiento: Crear una oferta para la configuración de evaluaciones

### Propósito
Configurar las ofertas en las cuales estará permitido al estudiante realizar una evaluación. (Fuente: diapositiva 8)

### Requisitos y permisos
- Acceder a SIAAF WEB desde «Portal Profesores y Administrativos» con usuario y contraseña. (Fuentes: diapositivas 2–4)

### Pasos
1. Desde el navegador, ingrese al sitio web de la Universidad: `http://www.unisimon.edu.co/`. (Fuente: diapositiva 2)
2. En el menú principal, seleccione la opción «Portales». (Fuente: diapositiva 2)
3. Diríjase a la sección «Portal Profesores y Administrativos». (Fuente: diapositiva 3)
4. Digite su usuario y contraseña para acceder al sistema y presione el botón «Acceder». (Fuente: diapositiva 4)
5. Luego de ingresar, seleccione el módulo «Bienestar». (Fuente: diapositiva 5)
6. Seleccione el icono «Evaluaciones». (Fuente: diapositiva 6)
7. Ingrese a la sección «Configuración de Evaluaciones». (Fuente: diapositiva 7)
8. Seleccione el tipo de evaluación: CAQ o KOLB. (Fuente: diapositiva 8)
9. Presione el icono «Crear». (Fuente: diapositiva 8)
10. Complete la información solicitada en el formulario desplegado. (Fuente: diapositiva 9)
11. Registre la oferta presionando el botón «Guardar». (Fuente: diapositiva 9)

### Resultado esperado
La oferta queda registrada al presionar «Guardar». (Fuente: diapositiva 9)
