# Instructivo para autoevaluación por grupos en SIAAF WEB

## Información del documento
- **Fuente original:** `Autoevaluacion por Grupos - Funcionarios.pdf`
- **Sistema o módulo:** SIAAF WEB; módulo «Autoevaluación por Grupo».
- **Público o permisos mencionados por la fuente:** Instructivo del funcionario. El listado de asignaturas pendientes depende de la carga académica del profesor.
- **Temas incluidos:** Acceso al sistema y autoevaluación de asignaturas por grupo.

## Procedimiento: Acceder a SIAAF WEB

### Pasos
1. Desde un navegador, ingrese al sitio web de la Universidad: `http://www.unisimon.edu.co/`. (Fuente: página 2)
2. En el menú principal, seleccione la opción «Portales». (Fuente: página 2)
3. Diríjase a la sección «Portal Profesores y Administrativos». (Fuente: página 3)
4. Digite su usuario y contraseña para acceder al sistema y presione el botón «Acceder». (Fuente: página 4)

## Procedimiento: Autoevaluar asignaturas por grupo

### Propósito
Completar la autoevaluación de las asignaturas pendientes que aparecen según la carga académica del profesor. (Fuente: páginas 5–6)

### Pasos
1. Luego de ingresar al sistema, seleccione el módulo «Autoevaluación por Grupo». (Fuente: página 5)
2. En la ventana que muestra el listado de asignaturas pendientes por autoevaluar, presione el botón «Comenzar» junto a la asignatura que desea evaluar. (Fuente: página 6)
3. En la ventana de evaluación, revise las preguntas y las posibles respuestas de cada una. (Fuente: página 7)
4. Escoja una respuesta para cada pregunta. El sistema no permite finalizar la evaluación si no se han escogido todas las respuestas. (Fuente: página 7)
5. Para finalizar la escogencia de todas las respuestas, presione el botón «Guardar». Luego, continúe con el mismo proceso para las siguientes asignaturas. (Fuente: página 7)

### Resultado esperado
Al finalizar una evaluación, esta se muestra automáticamente con un icono que indica que ha sido finalizada. (Fuente: página 6)
