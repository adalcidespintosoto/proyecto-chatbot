# Habilitar y deshabilitar permisos por usuario y curso en SIAAF WEB

## Información del documento
- **Fuente original:** `Habilitar permisos PAC (Director de programa).pdf`
- **Sistema o módulo:** SIAAF WEB; módulo «Permisos» y módulo «Programa analítico».
- **Público o permisos mencionados por la fuente:** El título del archivo menciona a «Director de programa». El instructivo no especifica requisitos de autorización.
- **Temas incluidos:** Acceso a SIAAF WEB; habilitación y deshabilitación de permisos por usuario y curso para «Programa analítico».

## Procedimiento: Acceder a SIAAF WEB

### Pasos
1. Desde un navegador, ingrese a `http://www.unisimon.edu.co/` y seleccione «Portales» en el menú principal. (Fuente: página 3)
2. Acceda a la sección «Portal Profesores y Administrativos». (Fuente: páginas 4–5)
3. Digite su usuario y contraseña y presione «Acceder». (Fuente: página 6)

## Procedimiento: Habilitar permisos por usuario y curso en «Programa analítico»

### Propósito
Habilitar un permiso para un usuario y un curso en el módulo «Programa analítico». (Fuente: páginas 8–13)

### Pasos
1. Ingrese al módulo «Permisos». (Fuente: página 7)
2. Seleccione el módulo al cual desea habilitar permisos; en este caso, «Programa analítico». (Fuente: página 8)
3. Seleccione el programa al que pertenezca el curso deseado y presione «Crear». (Fuente: página 10)
4. Busque el usuario y el curso presionando el botón correspondiente a cada uno. (Fuente: página 11)
5. En la ventana de búsqueda, digite para el usuario nombres, apellidos o número de documento; para el curso, código de curso o nombre. (Fuente: página 12)
6. Escoja el registro y presione «Seleccionar». (Fuente: página 12)
7. Para finalizar y habilitar el permiso, presione «Guardar». (Fuente: página 13)

## Procedimiento: Deshabilitar permisos por usuario y curso

### Pasos
1. Seleccione el programa al que pertenezca el curso deseado. (Fuente: página 15)
2. En el listado que se muestra para el programa seleccionado, ubique el permiso que desea deshabilitar y presione el icono indicado. (Fuente: página 16)
3. Para finalizar y deshabilitar el permiso, confirme el proceso. (Fuente: página 17)
