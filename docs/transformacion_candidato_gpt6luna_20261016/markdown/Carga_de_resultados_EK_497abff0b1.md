# Carga masiva de resultados EK en SIA WEB

## Información del documento
- **Fuente original:** Carga de resultados EK.pdf
- **Sistema o módulo:** SIA WEB; módulo «Matrículas» y opción «Código EK».
- **Público o permisos mencionados por la fuente:** La ruta de acceso menciona «Portal Profesores y Administrativos».
- **Temas incluidos:** Acceso al sistema y carga masiva de resultados EK.

## Procedimiento: Cargar resultados EK

### Propósito
Adjuntar y procesar un documento con resultados EK correspondientes a los estudiantes. (Fuente: páginas 2 y 9–10)

### Requisitos y permisos
- La ruta de acceso indicada dirige al «Portal Profesores y Administrativos». (Fuente: página 4)
- Se solicita ingresar usuario y contraseña para acceder al sistema. No se reproducen credenciales. (Fuente: página 5)

### Pasos
1. Desde un navegador, ingresar al sitio web de la Universidad: `http://www.unisimon.edu.co/`. En el menú principal, seleccionar «Portales». (Fuente: página 3)
2. Dirigirse a la sección «Portal Profesores y Administrativos». (Fuente: página 4)
3. Digitar el usuario y la contraseña para acceder al sistema y presionar «Acceder». (Fuente: página 5)
4. Una vez dentro del sistema, seleccionar el módulo «Matrículas». (Fuente: página 6)
5. Seleccionar el icono «Código EK». (Fuente: página 7)
6. Seleccionar la opción «Cargue masivo resultado EK». (Fuente: página 8)
7. Para adjuntar el documento con los resultados EK de los estudiantes, seleccionar «Seleccionar archivo» y luego presionar «Cargar». (Fuente: página 9)
8. Revisar la información listada del documento cargado, incluidos los estados de cada registro, entre ellos «Valido» y «No válido». (Fuente: página 10)
9. Luego de confirmar la información, seleccionar el año y el periodo de carga. (Fuente: página 10)
10. Finalizar presionando «Procesar». (Fuente: página 10)

### Resultado esperado
Se lista la información del documento cargado con el estado de cada registro. El procedimiento indica finalizar presionando «Procesar» después de confirmar la información y seleccionar el año y el periodo de carga. (Fuente: página 10)

Confirmar la denominación institucional que debe figurar. (Fuente: páginas 1–3)
- La diapositiva 5 indica que se deben introducir usuario y contraseña, pero no especifica cómo obtenerlos ni si existen requisitos adicionales de acceso. Los campos y opciones descritos solo en la descripción automática de imagen no se incorporan como pasos, porque no están confirmados en el texto de instrucciones. (Fuente: página 5)
- La fuente no explica qué hacer si algún registro aparece como «No válido», ni describe el resultado posterior a presionar «Procesar». (Fuente: página 10)
