# Gestión de inscripciones para grados en SIA WEB

## Información del documento
- Fuente original: `Gestión de inscripciones.pdf`
- Sistema o módulo: SIA WEB; Registro y Control Académico; Inscripción para Grados.
- Público o permisos mencionados por la fuente: Usuarios del portal. Para modificar datos de la hoja de vida se requiere contar con el permiso correspondiente. Desde que se aprueba el primer requisito, la solicitud queda a cargo del usuario que realizó esa acción.
- Temas incluidos: ingreso al portal, oferta de inscripción para grados, búsqueda de solicitudes pendientes, consulta y aprobación de requisitos, consulta y modificación de hoja de vida, aprobación de solicitudes, envío de correo personalizado y descarga de documentos de inscripción.

## Procedimiento: Ingresar al portal SIA WEB
### Pasos
1. Desde la página web de la universidad, ingrese a la sección «Portales» en `http://www.unisimon.edu.co/portales/administrativos`. Ingrese su usuario y contraseña y presione «Acceder». (Fuente: página 3)
2. Al ingresar al portal SIA WEB, seleccione el icono «Registro y Control Académico». (Fuente: página 4)
3. Seleccione el icono «Inscripción para Grados». (Fuente: página 5)

## Procedimiento: Consultar solicitudes de inscripción para grados
### Pasos
1. Al ingresar, se cargarán automáticamente el proceso, el periodo actual y todas las solicitudes de inscripción para grados que estén en estado «Pendiente». (Fuente: página 6)
2. Para usar filtros adicionales, seleccione nivel, programa y estado. Después de escoger los filtros, haga clic en «Buscar». (Fuente: página 6)

## Procedimiento: Revisar y aprobar requisitos
### Propósito
Visualizar y aprobar los requisitos parametrizados para el programa académico del aspirante. (Fuente: página 8)

### Pasos
1. En las opciones de la solicitud, seleccione «Ver Requisitos». La sección listará los requisitos parametrizados para el programa académico del aspirante. (Fuente: páginas 7–8)
2. Desde esta sección, puede visualizar cada requisito y, si es de tipo Documento, descargarlo. (Fuente: páginas 7–8)
3. Para aprobar un requisito, use la opción «Aprobar requisito». La fuente también identifica las opciones «Actualizar listado» y «Visualizar requisito». (Fuente: página 8)

### Errores, límites o excepciones documentadas
- Desde la aprobación del primer requisito, la solicitud queda a cargo del usuario que realizó esa acción. Un usuario diferente no podrá realizar ninguna otra acción sobre esa misma solicitud. (Fuente: página 8)

## Procedimiento: Consultar o modificar la hoja de vida del aspirante
### Propósito
Visualizar los datos personales y de contacto del aspirante. (Fuente: página 9)

### Requisitos y permisos
- Para modificar datos, es necesario contar con el permiso correspondiente. (Fuente: página 9)

### Pasos
1. En las opciones de la solicitud, seleccione «Ver Hoja de Vida» para visualizar los datos del aspirante. (Fuente: páginas 7 y 9)
2. Si cuenta con el permiso, modifique el o los campos necesarios y haga clic en «Guardar». (Fuente: página 9)

## Procedimiento: Aprobar o admitir una solicitud de inscripción
### Propósito
Aprobar la solicitud para que el aspirante pueda continuar el proceso. (Fuente: página 7)

### Pasos
1. En las opciones de la solicitud, seleccione «Aprobar/Admitir solicitud de inscripción». (Fuente: página 7)
2. Consulte el detalle del valor que debe pagar el aspirante. (Fuente: página 7)
3. El sistema verificará si el aspirante ha realizado abonos al pago de su derecho a grado; también verificará los datos de fechas límites y los datos del aspirante. (Fuente: página 10)
4. Si todo está correcto, haga clic en «Continuar» para aprobar la solicitud de inscripción. (Fuente: página 10)

### Resultado esperado
- Una vez aprobada la solicitud, el aspirante puede continuar el proceso. (Fuente: página 7)

### Errores, límites o excepciones documentadas
- La fuente indica que se puede hacer clic en «Continuar» si todo está correcto; no especifica qué hacer si alguna verificación no es correcta. (Fuente: página 10)

## Procedimiento: Enviar un correo personalizado al aspirante
### Propósito
Enviar desde el aplicativo un correo al aspirante para notificar un inconveniente o una novedad durante el proceso. (Fuente: página 11)

### Pasos
1. En las opciones de la solicitud, seleccione «Enviar Correo Personalizado». (Fuente: páginas 7 y 11)
2. Use esta opción para enviar el correo personalizado al aspirante cuando se presente una novedad o un inconveniente durante el proceso. (Fuente: páginas 7 y 11)

## Procedimiento: Descargar la constancia o el formulario de inscripción
### Propósito
Visualizar o descargar los formatos de Constancia y Formulario de inscripción. (Fuente: páginas 7 y 12)

### Pasos
1. En las opciones de la solicitud, seleccione «Descargar Constancia/Formulario de Inscripción». (Fuente: página 7)
2. Seleccione una de las opciones disponibles. (Fuente: página 12)
3. Se abrirá el documento en formato PDF, que podrá visualizar o descargar. (Fuente: página 12)
