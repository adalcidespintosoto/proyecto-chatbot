# Generar el reporte de Asignaturas por Grupos en SIAAF WEB

## Información del documento
- Fuente original: `Reporte - Asignaturas por Grupos.pptx`
- Sistema o módulo: SIAAF WEB; módulo «Asignación Académica»
- Público o permisos mencionados por la fuente: «Profesores y Administrativos»
- Temas incluidos: acceso al sistema, selección del año y período, búsqueda del reporte «Asignaturas por Grupos»

## Procedimiento: Generar el reporte de Asignaturas por Grupos

### Propósito
Consultar el reporte «Asignaturas por Grupos». (Fuente: diapositivas 1, 6–7)

### Requisitos y permisos
- Acceder desde la sección «Profesores y Administrativos» e ingresar el usuario y la contraseña para acceder al sistema. (Fuente: diapositiva 3)

### Pasos
1. Desde un navegador, ingresar al sitio web de la Universidad: `http://www.unisimon.edu.co/`. En el menú principal, seleccionar «Portales». (Fuente: diapositiva 2)
2. Dirigirse a la sección «Profesores y Administrativos», digitar el usuario y la contraseña y presionar el botón «Ingresar». (Fuente: diapositiva 3)
3. Seleccionar el módulo «Asignación Académica». (Fuente: diapositiva 4)
4. Seleccionar el año y el período en el cual se trabajará. Por defecto, se muestra el período actual. El período indica al sistema qué información mostrará en todo el módulo. (Fuente: diapositiva 5)
5. Una vez definido el período, seleccionar en el menú la opción «Reporte». (Fuente: diapositiva 6)
6. Entre las opciones, seleccionar el reporte «Asignaturas por Grupos». (Fuente: diapositiva 6)
7. Digitar el código o el nombre de la asignatura y presionar el botón «Buscar». (Fuente: diapositiva 7)

## Palabras y formas de búsqueda
Paráfrasis editoriales para mejorar la búsqueda; no son afirmaciones adicionales del documento:
- reporte de asignaturas por grupos
- buscar una asignatura por código o nombre en SIAAF WEB
- seleccionar año y período en Asignación Académica
