# Instructivo para generar el reporte de inversiones aprobadas - ejecutadas en SIAAF WEB

## Información del documento
- Fuente original: `Reporte de aprobadas vs ejecutadas.pdf`
- Sistema o módulo: SIAAF WEB; módulo «Planeación Estratégica».
- Público o permisos mencionados por la fuente: «Profesores y Administrativos».
- Temas incluidos: acceso al portal, ingreso al sistema, navegación al reporte de inversiones aprobadas para adquisición y exportación del reporte.

## Procedimiento: generar y exportar el reporte de inversiones aprobadas - ejecutadas

### Propósito
La sección «Reporte Aprobadas Vs Ejecutadas» muestra los registros con la información reportada por planeación, cruzada con los valores de las compras. (Fuente: página 8)

### Requisitos y permisos
- La fuente indica dirigirse a la sección «Portal Profesores y Administrativos». (Fuente: página 3)
- Se requiere digitar el usuario y la contraseña para acceder al sistema. (Fuente: página 4)

### Pasos
1. Desde un navegador, ingrese al sitio web de la Universidad: `http://www.unisimon.edu.co/`. En el menú principal, seleccione «Portales». (Fuente: página 2)
2. Diríjase a la sección «Portal Profesores y Administrativos». (Fuente: página 3)
3. Digite su usuario y contraseña para acceder al sistema y presione el botón «Acceder». (Fuente: página 4)
4. Luego de ingresar al sistema, seleccione el módulo «Planeación Estratégica». (Fuente: página 5)
5. En la sección «Planeación Estratégica», seleccione la opción «Inversiones Aprobadas para Adquisición». (Fuente: página 6)
6. Seleccione la opción «Reporte». (Fuente: página 7)
7. En la sección «Reporte Aprobadas Vs Ejecutadas», consulte los registros con la información reportada por planeación, cruzada con los valores de las compras. (Fuente: página 8)
8. El reporte se podrá exportar en formato de hojas de cálculo de Excel. (Fuente: página 9)
