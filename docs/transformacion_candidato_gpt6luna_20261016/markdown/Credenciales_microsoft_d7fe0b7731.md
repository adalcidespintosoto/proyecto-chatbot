# Consulta y cambio de credenciales de Microsoft

## Información del documento
- **Fuente original:** `Credenciales microsoft.pdf`
- **Sistema o módulo:** Portal de Gestión Académico-Administrativa y Microsoft Temas.
- **Público o permisos mencionados por la fuente:** No se especifican.
- **Temas incluidos:** Acceso al portal, consulta de credenciales de Microsoft Temas y cambio de contraseña.

## Procedimiento: Consultar las credenciales de Microsoft Temas

### Propósito
Consultar las credenciales de acceso a Microsoft Temas desde el Portal de Gestión Académico-Administrativa. (Fuente: página 3)

### Pasos
1. Desde la página web de la universidad, acceda a la sección «Portales» y abra el Portal de Gestión Académico-Administrativa. La fuente indica esta dirección: `http://www.unisimon.edu.co/portales/administrativos`. (Fuente: página 2)
2. Ingrese su usuario y contraseña y presione el botón «Acceder». (Fuente: página 2)
3. Al ingresar al portal, aparecerá una ventana emergente con las credenciales de acceso a Microsoft Temas. La fuente muestra la etiqueta «Número de documento». (Fuente: página 3)

### Errores, límites o excepciones documentadas
- La fuente describe la composición de la clave inicial mediante datos personales. Ese patrón no se reproduce aquí. (Fuente: página 3)

## Procedimiento: Cambiar la contraseña asignada

### Propósito
Cambiar la contraseña asignada por una de preferencia. (Fuente: página 4)

### Pasos
1. Seleccione el enlace que se indica en la imagen. La fuente señala que se abrirá al instante una ventana emergente para cambiar la contraseña. (Fuente: página 4)
2. Cree una nueva clave que tenga entre 8 y 15 caracteres, ambas longitudes incluidas; que contenga mayúsculas, minúsculas y al menos un número; y que no contenga ningún dato personal. (Fuente: página 4)
