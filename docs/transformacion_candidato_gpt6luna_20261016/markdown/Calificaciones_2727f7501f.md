## Procedimiento: Consultar e imprimir calificaciones

### Propósito
Consultar las calificaciones de un programa y período seleccionados y, si se desea, imprimir el listado. (Fuente: diapositivas 1, 5–6)

### Requisitos y permisos
- Se indica que se debe ingresar con usuario y contraseña; no se especifican requisitos adicionales. (Fuente: diapositiva 4)

### Pasos
1. Desde un navegador, ingrese al sitio web de la Universidad: `http://www.unisimon.edu.co/`. En el menú principal, seleccione «Portales». (Fuente: diapositiva 2)
2. Diríjase a la sección «Portal Estudiantes». (Fuente: diapositiva 3)
3. Digite su usuario y contraseña y presione el botón «Acceder». (Fuente: diapositiva 4)
4. Para ingresar al módulo, presione el icono «Calificaciones». (Fuente: diapositiva 5)
5. Para consultar las calificaciones, seleccione el «Programa» y el «Período» que desea visualizar. (Fuente: diapositiva 6)
6. Para imprimir el listado de calificaciones, presione el icono indicado en la diapositiva. (Fuente: diapositiva 6)

### Resultado esperado
Se pueden visualizar las calificaciones del programa y período seleccionados. La fuente también indica que se puede imprimir el listado. (Fuente: diapositiva 6)

Paráfrasis editoriales para mejorar la búsqueda; no son afirmaciones adicionales del documento: consultar notas, ver calificaciones, imprimir listado de calificaciones, acceder al Portal de Estudiantes.
