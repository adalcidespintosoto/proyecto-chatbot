## Procedimiento: Consultar y editar registros de Código EK

### Propósito
Consultar registros de Código EK y editar el código de los estudiantes listados. (Fuente: páginas 9–11)

### Requisitos y permisos
- Ingresar al sistema con usuario y contraseña. (Fuente: página 5)
- Para realizar la consulta, completar los filtros obligatorios «Año» y «periodo». Los filtros «Nivel», «programa» y «completado» son opcionales. (Fuente: página 9)
- La fuente no especifica permisos adicionales para editar registros.

### Pasos
1. Desde un navegador, ingresar al sitio web de la Universidad: `http://www.unisimon.edu.co/`. (Fuente: página 3)
2. En el menú principal, seleccionar «Portales». (Fuente: página 3)
3. Dirigirse a la sección «Portal Profesores y Administrativos». (Fuente: página 4)
4. Digitar el usuario y la contraseña para acceder al sistema y presionar «Acceder». (Fuente: página 5)
5. Luego de ingresar al sistema, seleccionar el módulo «Matrículas». (Fuente: página 6)
6. Seleccionar el icono «Código EK». (Fuente: página 7)
7. Ingresar a la sección «Listado Código EK». (Fuente: página 8)
8. Para consultar registros, completar los filtros obligatorios «Año» y «periodo». De forma opcional, completar «Nivel», «programa» y «completado». El campo «Completado» hace referencia a si los estudiantes tienen registros de código EK o no. (Fuente: página 9)
9. En los estudiantes listados, usar el icono señalado para editar el Código EK. (Fuente: página 10)
10. Después de presionar el botón de edición, digitar el código en la ventana que se muestra y guardar presionando «Aceptar». (Fuente: página 11)

### Resultado esperado
La fuente indica que se puede consultar el listado de registros según los filtros y editar el Código EK de los estudiantes listados. No describe una confirmación ni otro resultado posterior a guardar. (Fuente: páginas 9–11)
