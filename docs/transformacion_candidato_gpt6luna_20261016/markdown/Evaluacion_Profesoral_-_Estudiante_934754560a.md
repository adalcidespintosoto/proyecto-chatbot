# Instructivo para realizar la evaluación profesoral en SIAAF WEB

## Información del documento
- **Fuente original:** `Evaluacion Profesoral - Estudiante.pdf`
- **Sistema o módulo:** SIAAF WEB
- **Público o permisos mencionados por la fuente:** Estudiante
- **Temas incluidos:** Acceso al Portal Estudiantes y evaluación de asignaturas pendientes.

## Procedimiento: Realizar la evaluación profesoral de una asignatura

### Propósito
Completar la evaluación profesoral de las asignaturas pendientes que aparecen en el portal, de acuerdo con la proyección del estudiante. (Fuente: páginas 1 y 5)

### Requisitos y permisos
- El instructivo está dirigido al estudiante.
- Se requiere el usuario y la contraseña para acceder al sistema. (Fuente: página 4)

### Pasos
1. Desde un navegador, ingrese al sitio web de la Universidad: `http://www.unisimon.edu.co/`. (Fuente: página 2)
2. En el menú principal, seleccione «Portales». (Fuente: página 2)
3. Diríjase a la sección «Portal Estudiantes». (Fuente: página 3)
4. Digite su usuario y contraseña y presione el botón «Acceder». (Fuente: página 4)
5. Al acceder al portal, consulte el listado de asignaturas pendientes por evaluar, según la proyección del estudiante. (Fuente: página 5)
6. Para iniciar la evaluación de una asignatura, presione el icono «Comenzar». (Fuente: página 5)
7. En la ventana que se despliega, escoja una respuesta para cada pregunta. (Fuente: página 6)
8. Cuando haya escogido las respuestas de todas las preguntas, presione «Guardar» para continuar con el mismo proceso en las siguientes asignaturas. (Fuente: página 6)

### Resultado esperado
- Al finalizar la evaluación de una asignatura, esta se elimina automáticamente del listado de pendientes. (Fuente: página 5)

### Errores, límites o excepciones documentadas
- El sistema no permite finalizar una evaluación si no se han escogido todas sus respuestas. (Fuente: página 6)
