## Procedimiento: Editar la proyección académica de un estudiante

### Propósito
Editar la proyección académica mediante las funciones de agregar o eliminar cursos, habilitar un curso u homologar cursos. (Fuente: diapositivas 1 y 6)

### Pasos
1. Desde la página web de la universidad, ingrese en la sección «Portales» mediante `http://www.unisimon.edu.co/portales/administrativos`. Ingrese su usuario y contraseña y presione «Acceder». (Fuente: diapositiva 2)
2. Seleccione «Matrícula». (Fuente: diapositiva 3)
3. Seleccione la opción «Matrícula», realice la búsqueda del estudiante y seleccione «Ver» (icono en forma de lupa). (Fuente: diapositiva 4)
4. En el registro correspondiente al período sobre el que desea editar la proyección, seleccione «Calificaciones» (icono en forma de lista). (Fuente: diapositiva 5)
5. En la ventana de calificaciones, utilice la función correspondiente a la acción que desea realizar:
   - **Agregar curso:** incluye un nuevo curso en la proyección académica. (Fuente: diapositiva 6)
   - **Eliminar:** excluye el curso seleccionado de la proyección académica. (Fuente: diapositiva 6)
   - **HA (Habilitación):** autoriza la habilitación del curso seleccionado en la proyección académica. (Fuente: diapositiva 6)
   - **HO (Homologación):** realiza la homologación de cursos en la proyección académica; la fuente indica que se usa para períodos históricos. (Fuente: diapositiva 6)

### Procedimiento: Agregar un curso

#### Pasos
1. Seleccione «Agregar curso». Se abrirá una ventana. (Fuente: diapositiva 7)
2. Seleccione el semestre al que pertenece el curso que desea agregar. (Fuente: diapositiva 7)
3. En la lista resultante, seleccione uno o más cursos. (Fuente: diapositiva 7)
4. Seleccione «Agregar». (Fuente: diapositiva 7)

#### Resultado esperado
Al cerrar la ventana, el listado de calificaciones se actualizará y mostrará el o los cursos agregados. (Fuente: diapositiva 7)

### Procedimiento: Eliminar un curso

#### Pasos
1. Seleccione «Eliminar». Se abrirá una ventana para confirmar que desea eliminar el registro. (Fuente: diapositiva 8)
2. Para confirmar, seleccione «Si». (Fuente: diapositiva 8)

#### Resultado esperado
Al cerrar la ventana, el listado de calificaciones se actualizará. (Fuente: diapositiva 8)

### Procedimiento: Habilitar un curso (HA)

#### Pasos
1. Seleccione «HA». Se abrirá una ventana para confirmar que desea eliminar el registro. (Fuente: diapositiva 9)
2. Para confirmar, seleccione «Si». (Fuente: diapositiva 9)

#### Resultado esperado
Al cerrar la ventana, el listado de calificaciones se actualizará. (Fuente: diapositiva 9)

#### Errores, límites o excepciones documentadas
- Para crear una autorización, el sistema validará que se cumplan los criterios de mínimo y máximo de calificaciones, así como el número de autorizaciones que tenga el estudiante para el mismo período. (Fuente: diapositiva 9)

### Procedimiento: Homologar cursos (HO)

#### Requisitos y permisos
- La opción está disponible solo para períodos históricos. (Fuente: diapositiva 10)

#### Pasos
1. Seleccione «HO». Se abrirá una ventana. (Fuente: diapositiva 10)
2. Seleccione el semestre al que pertenece el curso que desea homologar. (Fuente: diapositiva 10)
3. En la lista resultante, seleccione uno o más cursos. (Fuente: diapositiva 10)
4. Seleccione «Agregar». (Fuente: diapositiva 10)

#### Resultado esperado
Al cerrar la ventana, el listado de calificaciones se actualizará con la modificación correspondiente. (Fuente: diapositiva 10)

#### Errores, límites o excepciones documentadas
- Para realizar esta acción, el sistema validará que se cumplan los criterios de mínimo y máximo de calificaciones y las demás validaciones establecidas para este proceso. (Fuente: diapositiva 10)
