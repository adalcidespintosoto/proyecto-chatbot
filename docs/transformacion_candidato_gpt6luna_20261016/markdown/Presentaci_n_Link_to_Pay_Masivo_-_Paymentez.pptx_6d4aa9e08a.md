# Generación y consulta masiva de links to pay

## Información del documento
- **Fuente original:** Presentación Link to Pay Masivo - Paymentez.pptx.pdf
- **Sistema o módulo:** Dashboard; opción Link de pago.
- **Público o permisos mencionados por la fuente:** No se especifican.
- **Temas incluidos:** Creación masiva de links to pay mediante archivo CSV y consulta de su estado y detalles. (Fuente: páginas 1–13)

## Procedimiento: Crear links to pay de manera masiva

### Propósito
Cargar un archivo `.csv` para crear links to pay de manera masiva para cada app code. (Fuente: página 5)

### Pasos
1. Ingrese mediante el Dashboard. (Fuente: página 2)
2. En el menú que se despliega a mano izquierda, ingrese a **Link de pago → Crear**. (Fuente: página 3)
3. Cuando se despliegue la siguiente pantalla, seleccione **Cargar archivo**. (Fuente: página 4)
4. Prepare un archivo con los campos indicados y conviértalo en un archivo `.csv`. (Fuente: páginas 6–7)
5. En la pantalla de carga, cargue el archivo `.csv`. Para mayor facilidad, se puede descargar el formato que debe tener y un ejemplo del mismo. (Fuente: página 5)
6. Al cargar el archivo, revise los links to pay que se van a crear y, para finalizar el proceso, haga clic en **Cargar archivo**. (Fuente: página 8)

### Resultado esperado
Cuando el archivo esté cargado y los links to pay estén en proceso, aparecerá un mensaje. Si alguno no fue creado exitosamente, se notificará. (Fuente: página 9)

### Errores, límites o excepciones documentadas
- La fuente indica que se notificará si algún link to pay no fue creado exitosamente, pero no especifica el contenido del mensaje ni cómo proceder en ese caso. (Fuente: página 9)

## Procedimiento: Consultar el estado y los detalles de links to pay

### Propósito
Consultar el estado de los links to pay ya creados. (Fuente: página 10)

### Pasos
1. En el menú que se despliega a mano izquierda, ingrese a **Link de pago → Consulta**. (Fuente: página 10)
2. En la siguiente pantalla, realice la búsqueda para verificar el estado de los links to pay. (Fuente: página 11)
3. Al realizar la búsqueda, revise la data básica de cada link to pay y su estado. Los estados posibles son **Pendiente**, **Exitosa**, **Error** y **Expirada**. La fuente indica que **Error** corresponde a cuando la liga no quedó bien cargada. (Fuente: página 12)
4. Ingrese a **Ver detalle** para visualizar la data de las transacciones exitosas o la data general del link to pay en estado pendiente. También aparecerá la URL de pago. (Fuente: páginas 12–13)

### Resultado esperado
La consulta permite ver la data básica de cada link to pay y su estado. Al ingresar a **Ver detalle**, se puede visualizar la data de las transacciones exitosas o la data general del link pendiente, así como la URL de pago. (Fuente: páginas 12–13)
