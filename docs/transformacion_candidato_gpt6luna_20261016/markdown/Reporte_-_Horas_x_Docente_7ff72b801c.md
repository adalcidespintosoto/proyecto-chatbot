## Procedimiento: generar el reporte «Horas x Docentes»

### Propósito
Generar el reporte «Horas x Docentes». (Fuente: diapositivas 1 y 6)

### Requisitos y permisos
- Acceder a «Profesores y Administrativos» e ingresar el usuario y la contraseña. La fuente no especifica otros requisitos ni permisos. (Fuente: diapositiva 3)

### Pasos
1. Desde un navegador, ingrese al sitio web de la Universidad: `http://www.unisimon.edu.co/`. En el menú principal, seleccione «Portales». (Fuente: diapositiva 2)
2. Diríjase a la sección «Profesores y Administrativos», digite su usuario y contraseña y presione el botón «Ingresar». (Fuente: diapositiva 3)
3. Después de ingresar, seleccione el módulo «Asignación Académica». (Fuente: diapositiva 4)
4. Seleccione el año y el período en el cual trabajará. Por defecto, se mostrará el período actual. El período seleccionado le indica al sistema qué información mostrar en todo el módulo. (Fuente: diapositiva 5)
5. Después de definir el período, seleccione en el menú la opción «Reporte». (Fuente: diapositiva 6)
6. Entre las opciones disponibles, seleccione el reporte «Horas x Docentes». (Fuente: diapositiva 6)
7. Para imprimir el reporte o generarlo en Excel, use los botones correspondientes. (Fuente: diapositiva 7)

### Resultado esperado
El reporte «Horas x Docentes» queda disponible para imprimir o generar en Excel mediante los botones correspondientes. (Fuente: diapositivas 6–7)
