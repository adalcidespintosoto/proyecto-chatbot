# Uso del aplicativo de Programas y Preparatorios

## Información del documento
- **Fuente original:** `Instructivo Programas y Preparatorios.pdf`
- **Sistema o módulo:** Aplicativo de Programas y Preparatorios; también se menciona «Registro y Control Académico».
- **Público o permisos mencionados por la fuente:** No se especifican.
- **Temas incluidos:** Ingreso al aplicativo, búsqueda, consulta, edición y creación de programas, reconocimientos y acuerdos de normativa interna, reportes de programas y gestión de preparatorios.

## Procedimiento: Ingresar al aplicativo

### Pasos
1. Desde la página web de la universidad, vaya a la sección «Portales»: `http://www.unisimon.edu.co/portales`. Ingrese su usuario y contraseña y presione «Acceder». (Fuente: página 3)
2. Para iniciar el proceso, seleccione el icono «Registro y Control Académico». (Fuente: página 4)

## Procedimiento: Buscar, consultar y editar programas

### Pasos
1. Dentro de «Registro y Control Académico», seleccione el icono «Programas». (Fuente: página 6)
2. Para realizar una búsqueda, seleccione al menos el campo «Facultad» y haga clic en «Buscar». Los campos marcados con (*) son obligatorios. (Fuente: página 7)
3. Una vez realizada la búsqueda, puede visualizar o editar la información de un programa seleccionando, respectivamente, «Ver» o «Editar». (Fuente: página 8)
4. Para editar un programa, modifique los campos necesarios y seleccione «Guardar». Los campos marcados con (*) son obligatorios; sin ellos, el sistema no permitirá guardar el registro. (Fuente: página 9)
5. En la ventana «Ver Programa», la información completa del programa está organizada por pestañas. (Fuente: página 10)

### Errores, límites o excepciones documentadas
- Si el programa no posee acuerdos o reconocimientos, esas pestañas se mostrarán vacías. (Fuente: página 10)
- No se podrá guardar un programa editado si faltan campos marcados con (*). (Fuente: página 9)

## Procedimiento: Crear un programa

### Pasos
1. Seleccione «Crear Programa». Se abrirá una ventana en la que debe diligenciar los campos que se guardarán. (Fuente: página 11)
2. Después de diligenciar los campos, seleccione «Guardar». Los campos marcados con (*) son obligatorios; sin ellos, el sistema no permitirá guardar el registro. (Fuente: página 12)
3. Una vez creado el programa, puede guardar los reconocimientos y los acuerdos de normativa interna que correspondan, seleccionando «Reconocimiento» y «Normativa Interna», respectivamente. (Fuente: página 13)

### Errores, límites o excepciones documentadas
- No se podrá guardar el registro si falta alguno de los campos marcados con (*). (Fuente: página 12)

## Procedimiento: Consultar y crear reconocimientos de un programa

### Pasos
1. Seleccione «Reconocimiento». Se abrirá una ventana con dos pestañas. La primera permite visualizar los reconocimientos obtenidos por el programa, organizados desde el más antiguo hasta el más reciente. (Fuente: página 14)
2. En la segunda pestaña puede crear un nuevo reconocimiento para ese programa. (Fuente: página 15)

### Errores, límites o excepciones documentadas
- Para guardar un reconocimiento, deben diligenciarse todos los campos marcados con (*). El sistema no permitirá guardar el registro si falta alguno. (Fuente: página 15)

## Procedimiento: Consultar y crear acuerdos de normativa interna de un programa

### Pasos
1. Seleccione «Normativa Interna». Se abrirá una ventana con dos pestañas. La primera permite visualizar todos los acuerdos del programa, organizados desde el más antiguo hasta el más reciente. (Fuente: página 16)
2. En la segunda pestaña puede crear un nuevo acuerdo para ese programa. (Fuente: página 17)

### Errores, límites o excepciones documentadas
- Para guardar un acuerdo, deben diligenciarse todos los campos marcados con (*). El sistema no permitirá guardar el registro si falta alguno. (Fuente: página 17)

## Procedimiento: Consultar y descargar reportes de programas

### Pasos
1. Para visualizar un reporte, seleccione «Buscar» en el menú lateral. (Fuente: página 18)
2. Seleccione la opción que corresponda en el menú lateral. Luego seleccione uno o más campos del filtro de búsqueda y haga clic en «Buscar» para mostrar los resultados. (Fuente: página 19)
3. Para descargar el resultado en un archivo Excel, seleccione el icono indicado en la interfaz. (Fuente: página 19)

### Errores, límites o excepciones documentadas
- Los campos marcados con (*) son obligatorios. (Fuente: página 19)

## Procedimiento: Buscar preparatorios

### Pasos
1. Seleccione el icono «Preparatorios». (Fuente: página 21)
2. En la ventana que se muestra, puede buscar por nombre o fragmento de nombre diligenciando el campo «Nombre», y también por «Tipo». Luego haga clic en «Buscar». (Fuente: página 22)

## Procedimiento: Editar un preparatorio y descargar resultados

### Pasos
1. Para editar el nombre de un registro, seleccione «Editar». (Fuente: página 23)
2. Modifique el nombre según sea necesario y haga clic en «Guardar». (Fuente: página 23)
3. Para descargar el resultado en formato Excel, haga clic en «Excel». (Fuente: página 23)

## Procedimiento: Crear preparatorios

### Pasos
1. Seleccione «Crear» y diligencie los campos que aparecen. Luego haga clic en «Guardar». (Fuente: página 24)
2. Si desea seguir guardando registros, seleccione «Nuevo» para que el formulario se limpie y pueda continuar. (Fuente: página 24)
