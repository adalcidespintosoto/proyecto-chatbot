# Gestión de Ayudas Educativas en SIA WEB

## Información del documento
- **Fuente original:** `Gestión de Ayudas Educativas.pdf`
- **Sistema o módulo:** SIA WEB; módulo «Ayudas Educativas».
- **Público o permisos mencionados por la fuente:** Usuarios con permisos de consulta de ayudas educativas (`EST_ESTUDIANTES_AYUDAS`) y de creación o modificación (`EST_ESTUDIANTES_AYUDASGRABAR`).
- **Temas incluidos:** Ingreso al portal, creación y búsqueda de ayudas educativas, consulta y gestión de conceptos de descuento y funcionarios.
- **Contenido inicial:** La página 1 contiene una descripción automática, no verificada, de una página institucional; la página 2 presenta el título «Gestión de Ayudas Educativas» y otra descripción automática, no verificada. (Fuente: páginas 1–2)

## Procedimiento: Ingresar a SIA WEB y abrir Ayudas Educativas

### Pasos
1. Desde la página web de la universidad, vaya a la sección «Portales» en `http://www.unisimon.edu.co/portales/administrativos`. Ingrese su usuario y contraseña, y presione «Acceder». (Fuente: página 3)
2. Al ingresar al portal SIA WEB, seleccione el icono «Matrícula». (Fuente: página 4)
3. Seleccione el icono «Ayudas Educativas». (Fuente: página 5)

### Requisitos y permisos
- Por defecto, el módulo solo será visible para usuarios con el permiso de consulta de ayudas educativas `EST_ESTUDIANTES_AYUDAS`. (Fuente: página 5)

## Procedimiento: Crear una ayuda educativa

### Propósito
Crear una ayuda educativa asociada a un documento o código. (Fuente: página 7)

### Requisitos y permisos
- El botón «Crear» estará habilitado solo para usuarios con el permiso de creación `EST_ESTUDIANTES_AYUDASGRABAR`. (Fuente: página 6)

### Pasos
1. Seleccione el botón «Crear». Se abrirá un formulario con los datos que se deben diligenciar para crear la ayuda educativa. (Fuente: página 6)
2. Ingrese el documento o código al cual se asociará la ayuda educativa. Presione «Enter» para que el sistema busque el nombre del estudiante. (Fuente: página 7)
3. Diligencie todos los demás campos. La fuente indica que los campos permiten ingresar texto para autocompletar la búsqueda. (Fuente: página 7)
4. Si el concepto de descuento o el funcionario que desea asociar no aparece entre las opciones de la lista desplegable y desea agregarlo como nuevo, seleccione «Agregar» junto al campo que desea diligenciar. Se abrirá una ventana para crear el nuevo registro. (Fuente: página 8)
5. Seleccione «Guardar» para finalizar. (Fuente: página 7)

### Resultado esperado
- El sistema mostrará un mensaje con el número de la ayuda educativa generada. (Fuente: página 7)

## Procedimiento: Buscar ayudas educativas

### Pasos
1. Seleccione el criterio de búsqueda. (Fuente: página 11)
2. Escriba el dato que desea buscar. (Fuente: página 11)
3. Seleccione «Buscar». (Fuente: página 11)

### Errores, límites o excepciones documentadas
- La descripción automática de la imagen de la página 11 menciona campos para «Documento», «Código estudiante», «Apellidos» y «Número de ayuda educativa», pero esa descripción no está verificada. (Fuente: página 11)

## Procedimiento: Consultar, editar o anular una ayuda educativa

### Pasos
1. En las opciones del registro, seleccione «Editar» para visualizar todos los datos de la ayuda educativa. (Fuente: página 12)
2. Para anular una ayuda, seleccione «Anular». Se abrirá una ventana de confirmación. (Fuente: página 12)

### Requisitos y permisos
- Solo los usuarios con el permiso `EST_ESTUDIANTES_AYUDASGRABAR` pueden editar o anular ayudas educativas. (Fuente: página 12)

### Errores, límites o excepciones documentadas
- Solo pueden anularse ayudas educativas cuyo estado sea «A». (Fuente: página 12)

## Procedimiento: Consultar y gestionar conceptos de descuento y funcionarios

### Pasos
1. Seleccione la opción correspondiente para visualizar el listado de conceptos de descuento o el de funcionarios. Dentro de cada listado también existe la opción de crear o agregar nuevos elementos. (Fuente: página 13)
2. Para crear un nuevo concepto de descuento, seleccione «Agregar». (Fuente: página 14)
3. Diligencie todos los campos del nuevo concepto de descuento y seleccione «Guardar». (Fuente: páginas 9, 15)
4. Para crear un nuevo funcionario, seleccione «Agregar». (Fuente: página 16)
5. Digite el número de identificación del funcionario y presione «Enter». El sistema mostrará el nombre relacionado. Si es correcto, seleccione «Agregar». (Fuente: páginas 10, 17)

### Resultado esperado
- Al consultar el número de identificación para agregar un funcionario, el sistema mostrará el nombre relacionado. (Fuente: páginas 10, 17)
- El sistema también indicará si ese número de identificación ya ha sido registrado como funcionario. (Fuente: páginas 10, 17)

### Errores, límites o excepciones documentadas
- La descripción automática de las imágenes de las páginas 9, 10, 15 y 17 contiene textos e interfaces que no concuerdan claramente con las instrucciones escritas; no se usan para añadir campos o pasos. (Fuente: páginas 9–10, 15, 17)

## Procedimiento: Editar o anular registros de los listados

### Pasos
1. En las opciones del registro, seleccione «Editar» para visualizar o modificar los datos de la ayuda educativa, según indica la fuente. (Fuente: página 14)
2. Para anular un registro, seleccione «Anular». (Fuente: página 14)

### Errores, límites o excepciones documentadas
- Solo pueden anularse registros cuyo estado sea «A». (Fuente: página 14)
