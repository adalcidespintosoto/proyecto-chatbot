# Gestión de Notas Crédito en SIA WEB

## Información del documento
- **Fuente original:** Gestión de Notas Crédito.pdf
- **Sistema o módulo:** SIA WEB; módulo «Notas Crédito».
- **Público o permisos mencionados por la fuente:** Se mencionan permisos para consultar, crear, editar, anular, usar y devolver notas crédito.
- **Temas incluidos:** Ingreso al portal, acceso al módulo, creación y búsqueda de notas crédito, opciones disponibles para un registro y confirmación de acciones.

## Procedimiento: Ingresar a SIA WEB y abrir el módulo «Notas Crédito»

### Pasos
1. Desde la página web de la universidad, ingrese a la sección «Portales» en `http://www.unisimon.edu.co/portales/administrativos`. Ingrese su usuario y contraseña y presione «Acceder». (Fuente: página 3)
2. Al ingresar al portal (SIA WEB), seleccione el icono «Matrícula». (Fuente: página 4)
3. Seleccione el icono «Notas Crédito». Por defecto, el módulo será visible solo para los usuarios que posean el permiso de consulta de notas créditos (`NOT_CONSULTAR`). (Fuente: página 5)

## Procedimiento: Crear una nota crédito

### Requisitos y permisos
- El botón «Crear» estará habilitado solo para los usuarios que posean el permiso de creación de notas créditos (`NOTACRE_CREAR`). (Fuente: página 6)

### Pasos
1. Seleccione el botón «Crear». Se abrirá un formulario con los datos que se deben diligenciar para crear la nota crédito. (Fuente: página 6)
2. Para iniciar, ingrese el código del estudiante al cual se asociará la nota crédito. (Fuente: página 7)
3. Seleccione cualquier otra parte del formulario. El sistema buscará el nombre del estudiante. (Fuente: página 7)
4. Diligencie todos los demás campos y seleccione «Guardar». (Fuente: página 7)

### Resultado esperado
- El sistema mostrará un mensaje con el número de la nota crédito generada. (Fuente: página 7)

## Procedimiento: Listar notas crédito

### Pasos
1. Seleccione el criterio de búsqueda. (Fuente: página 8)
2. Escriba el dato a buscar. (Fuente: página 8)
3. Seleccione el botón «Buscar». (Fuente: página 8)

## Procedimiento: Gestionar un registro de nota crédito

### Requisitos y permisos
- **Editar:** solo podrán realizar esta acción los usuarios con el permiso correspondiente (`NOTACRE_EDITAR`). (Fuente: página 9)
- **Anular:** solo podrán realizar esta acción los usuarios con el permiso correspondiente (`NOTACRE_ANULAR`). Además, solo podrán anularse las notas cuyo estado sea «A». (Fuente: página 9)
- **Usar:** requiere el permiso correspondiente (`NOTACRE_USAR`). (Fuente: página 9)
- **Devolver:** requiere el permiso correspondiente (`NOTACRE_DEVOLVER`). (Fuente: página 9)

### Opciones del registro
1. **Editar:** permite visualizar todos los datos de la nota crédito. Solo se podrán modificar los campos año, periodo, nivel, programa, documento y observación. (Fuente: página 9)
2. **Anular:** anula una nota crédito si cumple la condición de estado «A» y el usuario tiene el permiso correspondiente. (Fuente: página 9)
3. **Usar:** marca como usada una nota crédito. (Fuente: página 9)
4. **Devolver:** devuelve una nota crédito. (Fuente: página 9)
5. **Imprimir:** permite visualizar y descargar el formato de nota crédito. (Fuente: página 9)

### Pasos para confirmar una anulación, uso o devolución
1. Después de seleccionar el icono correspondiente, aparecerá una ventana de confirmación de la acción que se desea realizar. (Fuente: página 10)
2. Al seleccionar «SÍ», se llevará a cabo la acción solicitada. (Fuente: página 10)
