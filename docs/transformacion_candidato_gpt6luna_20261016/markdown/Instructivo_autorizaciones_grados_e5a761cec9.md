# Autorización de inscripción a grados en SIA WEB

## Información del documento
- Fuente original: *Instructivo autorizaciones grados.pdf*
- Sistema o módulo: SIA WEB, opción «Registro y Control Académico» y módulo «Autorizaciones».
- Público o permisos mencionados por la fuente: No se especifican.
- Temas incluidos: Ingreso al portal, consulta de autorizaciones, creación y eliminación de una autorización.

## Procedimiento: Ingresar a Autorizaciones

### Pasos
1. Desde la página web de la universidad, ingrese a la sección «Portales» mediante `http://www.unisimon.edu.co/portales/administrativos`. Ingrese su usuario y contraseña y presione «Acceder». (Fuente: página 2)
2. Al ingresar al portal (SIA WEB), seleccione el icono «Registro y Control Académico». (Fuente: página 3)
3. Seleccione el icono «Autorización Inscripción para Grado». (Fuente: página 4)

## Procedimiento: Consultar autorizaciones

### Pasos
1. Seleccione los campos del filtro de búsqueda. Al seleccionar el programa, se cargará automáticamente el listado de autorizaciones asociado a ese programa. También puede seleccionar «Buscar» si desea modificar la búsqueda. (Fuente: página 5)

## Procedimiento: Crear una autorización

### Pasos
1. Seleccione los campos del filtro de búsqueda y luego seleccione «Crear». Aparecerá una ventana. (Fuente: página 6)
2. La ventana se cargará con los datos seleccionados anteriormente. Ingrese el número de identificación y seleccione «Buscar». (Fuente: página 7)
3. Si la búsqueda es correcta, aparecerá el nombre del aspirante. Seleccione la fecha límite para uso de la autorización y diligencie una observación. (Fuente: página 7)
4. Seleccione «Guardar». (Fuente: página 7)

### Resultado esperado
- Si la búsqueda del número de identificación es correcta, aparece el nombre del aspirante. (Fuente: página 7)

## Procedimiento: Eliminar una autorización

### Pasos
1. En el registro correspondiente, seleccione el icono «Eliminar». Aparecerá un mensaje de confirmación. (Fuente: página 8)
2. En la ventana de confirmación se pregunta: «¿Está seguro que desea eliminar el registro seleccionado?». La imagen muestra las opciones «Si» y «No». (Fuente: página 8)

## Palabras y formas de búsqueda
Paráfrasis editoriales para mejorar la búsqueda; no son afirmaciones adicionales del documento: autorización de grado, inscripción para grado, consultar autorizaciones, crear autorización, eliminar autorización, SIA WEB, Registro y Control Académico.
