## Procedimiento: Acceder a Microsoft Teams

### Propósito
Acceder a Microsoft Teams. (Fuente: páginas 1–5)

### Requisitos y permisos
- Iniciar sesión en el correo institucional de Microsoft. (Fuente: página 2)
- Usar el usuario y la clave indicados en el Portal de Gestión Académico-Administrativa. Para conocer las credenciales, consultar el instructivo **Credenciales de Microsoft**. (Fuente: página 3)

### Pasos
1. Inicie sesión en su correo institucional de Microsoft desde el sitio web de Unisimon, en la sección **Servicios --> Correo Funcionarios Microsoft**. (Fuente: página 2)
2. Inicie sesión con el usuario y la contraseña de Microsoft indicados en el Portal de Gestión Académico-Administrativa. (Fuente: página 3)
3. Seleccione el icono de la aplicación Teams en el panel principal. (Fuente: página 4)
