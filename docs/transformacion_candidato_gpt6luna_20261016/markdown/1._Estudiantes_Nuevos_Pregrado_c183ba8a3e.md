# Generar el informe de inscripciones y matrículas de estudiantes nuevos de pregrado en SIAAF WEB

## Información del documento
- **Fuente original:** `1. Estudiantes Nuevos Pregrado.pptx`
- **Sistema o módulo:** SIAAF WEB; módulo «Rectoría».
- **Público o permisos mencionados por la fuente:** Portal «Profesores y Administrativos». La fuente indica que se debe ingresar con usuario y contraseña, pero no especifica permisos adicionales.
- **Temas incluidos:** Acceso al portal y generación del informe «Estudiantes Nuevos Pregrado».

## Procedimiento: Generar el informe «Estudiantes Nuevos Pregrado»

### Propósito
Crear el informe de inscripciones y matrículas de estudiantes nuevos de pregrado. (Fuente: diapositiva 1)

### Requisitos y permisos
- Ingresar al sistema con usuario y contraseña desde el «Portal Profesores y Administrativos». (Fuente: diapositivas 3–4)
- Para generar el reporte, aplicar los filtros «Año», «Periodo» y «Fecha». (Fuente: diapositiva 7)

### Pasos
1. Desde un navegador, ingresar al sitio web de la Universidad: `http://www.unisimon.edu.co/`. En el menú principal, seleccionar la opción «Portales». (Fuente: diapositiva 2)
2. Dirigirse a la sección «Portal Profesores y Administrativos». (Fuente: diapositiva 3)
3. Digitar el usuario y la contraseña y presionar el botón «Acceder». (Fuente: diapositiva 4)
4. Luego de ingresar al sistema, seleccionar el módulo «Rectoría». (Fuente: diapositiva 5)
5. Dentro del módulo, seleccionar el informe «Estudiantes Nuevos Pregrado». (Fuente: diapositiva 6)
6. Aplicar los filtros solicitados: «Año», «Periodo» y «Fecha». (Fuente: diapositiva 7)
7. Presionar el botón «Generar». (Fuente: diapositiva 7)

### Resultado esperado
Al presionar «Generar», se crea el reporte como documento PDF para su visualización. (Fuente: diapositiva 7)
