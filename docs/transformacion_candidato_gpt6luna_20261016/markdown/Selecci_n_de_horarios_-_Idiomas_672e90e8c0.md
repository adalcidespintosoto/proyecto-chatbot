- **Público o permisos mencionados por la fuente:** Estudiantes. Se indica que se debe ingresar con usuario y contraseña, sin especificar requisitos de acceso adicionales.
- **Temas incluidos:** Acceso al Portal de Estudiantes, ingreso al módulo, selección del programa de idiomas y escogencia de horario.

## Procedimiento: Seleccionar un horario de clases de idiomas

### Propósito
Escoger un horario de clases dentro del programa de idiomas. (Fuente: páginas 1, 6–9)

### Requisitos y permisos
- Se requiere el usuario y la contraseña para acceder al sistema. La fuente no especifica requisitos adicionales. (Fuente: página 4)

### Pasos
1. Desde un navegador, ingresar al sitio web de la Universidad: `http://www.unisimon.edu.co/` y seleccionar en el menú principal la opción «Portales». (Fuente: página 2)
2. Dirigirse a la sección «Portal Estudiantes». (Fuente: página 3)
3. Digitar el usuario y la contraseña para acceder al sistema y presionar el botón «Acceder». (Fuente: página 4)
4. Para ingresar al módulo, presionar el icono «Matrícula y Escogencia de Horario». (Fuente: página 5)
5. Seleccionar el programa de idiomas para iniciar el proceso. (Fuente: página 6)
6. Seleccionar la opción «Escoger horario de clases». (Fuente: página 7)
7. Seleccionar la asignatura deseada para escoger el horario. (Fuente: página 8)
8. Ubicar el horario y grupo deseado y presionar el botón «Escoger». (Fuente: página 8)
9. Para finalizar el horario, presionar el botón «Finalizar». (Fuente: página 8)

### Resultado esperado
La diapositiva 9 identifica un calendario para visualizar el horario escogido. No especifica si este calendario aparece después de presionar «Finalizar». (Fuente: páginas 8–9)
