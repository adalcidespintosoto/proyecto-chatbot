## Información del documento
- **Fuente original:** *Manual Evaluación CAQ - Aspirantes.pdf*
- **Sistema o módulo:** Evaluación CAQ; la fuente no identifica un nombre de sistema. (Fuente: páginas 1–3)
- **Público o permisos mencionados por la fuente:** Aspirantes. (Fuente: página 2)
- **Temas incluidos:** Ingreso al sitio web de la Universidad, acceso a la Evaluación CAQ, inicio de sesión, realización de la evaluación y cierre de sesión. (Fuente: páginas 2–7)

## Procedimiento: Realizar la Evaluación CAQ

### Propósito
Realizar la Evaluación CAQ. (Fuente: página 1)

### Pasos
1. Desde un navegador, ingrese al sitio web de la Universidad: `http://www.unisimon.edu.co/`. (Fuente: página 2)
2. En el menú principal, seleccione la opción **“Aspirantes”**. (Fuente: página 2)
3. Seleccione la opción **“Evaluación CAQ”**. (Fuente: página 3)
4. Ingrese su código y documento de identidad; luego presione el botón **“Ingresar”**. (Fuente: página 4)
5. Para comenzar la prueba, presione el icono **«Comenzar»**. (Fuente: página 5)
6. Responda todas las preguntas y luego presione el botón **“Guardar”**. (Fuente: página 6)
7. Una vez realizada la evaluación, presione el botón **“Cerrar sesión”**. (Fuente: página 7)

### Errores, límites o excepciones documentadas
- El sistema no permitirá finalizar la evaluación si falta responder alguna pregunta. (Fuente: página 6)
