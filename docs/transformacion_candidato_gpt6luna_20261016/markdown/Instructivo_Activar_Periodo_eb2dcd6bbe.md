## Información del documento
- Fuente original: *Instructivo Activar Periodo.pdf*
- Sistema o módulo: módulo «Atención a estudiantes»; opción «Reportes Consolidados».
- Público o permisos mencionados por la fuente: la opción para activar un nuevo periodo solo está disponible si el usuario posee permiso. El permiso debe solicitarse directamente; la fuente no indica a quién.
- Temas incluidos: ingreso al sistema y activación de un nuevo periodo para la descarga de información contenida en los reportes consolidados.

## Procedimiento: Activar un nuevo periodo para Reportes Consolidados

### Propósito
Activar el año y periodo que se desea para la descarga de la información contenida en los reportes consolidados. (Fuente: páginas 4–5)

### Requisitos y permisos
- Ingresar con usuario y contraseña desde la sección «Portales» de la página web de la universidad: http://www.unisimon.edu.co/portales/administrativos. (Fuente: página 2)
- Poseer permiso para usar el botón «Activar nuevo periodo». El permiso deberá solicitarse directamente; no se especifica a quién. (Fuente: página 4)

### Pasos
1. Desde la página web de la universidad, ingrese en la sección «Portales» indicada y escriba su usuario y contraseña. Presione el botón «Acceder». (Fuente: página 2)
2. Luego de ingresar al sistema, seleccione el módulo «Atención a estudiantes». (Fuente: página 3)
3. En el módulo, seleccione la opción del menú «Reportes Consolidados». (Fuente: página 4)
4. Seleccione el botón «Activar nuevo periodo». Este botón está disponible solo si el usuario posee permiso. (Fuente: página 4)
5. En la ventana emergente, seleccione el año y el periodo que desea activar. (Fuente: página 5)
6. Seleccione el botón «Activar». (Fuente: página 5)

### Resultado esperado
Después de activar el nuevo periodo, la página se recargará automáticamente y podrá ver el nuevo periodo escogido. (Fuente: página 6)
