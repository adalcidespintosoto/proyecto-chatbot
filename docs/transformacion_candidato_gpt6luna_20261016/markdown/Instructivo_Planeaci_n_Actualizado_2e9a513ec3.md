# Instructivo para el uso del aplicativo de Planeación Estratégica

## Información del documento
- **Fuente original:** `Instructivo Planeación Actualizado.pdf`
- **Sistema o módulo:** Aplicativo de Planeación Estratégica; módulos de Plan de Acción, Seguimiento y Reportes.
- **Público o permisos mencionados por la fuente:** Se menciona al «usuario» al indicar cómo formular un plan. No se especifican permisos.
- **Temas incluidos:** Acceso a Planeación Estratégica y Plan de Acción; formulación, edición, eliminación, visualización e impresión de planes; seguimiento y evidencias; generación de reportes. (Fuente: páginas 2–40)

## Procedimiento: Acceder a Plan de Acción
### Pasos
1. Luego de ingresar, seleccionar el módulo “Planeación Estratégica”. (Fuente: página 3)
2. Seleccionar la sección “Plan de Acción”. (Fuente: página 4)

## Procedimiento: Buscar planes de acción
### Propósito
Buscar un plan de acción mediante filtros y consultar el listado de planes almacenados, que cuenta con acciones para visualizar e imprimir. (Fuente: página 7)

### Pasos
1. Seleccionar filtros entre “Sede”, “Año” y “Proceso”. (Fuente: página 7)
2. Presionar el botón «Buscar». (Fuente: página 7)
3. Para eliminar el filtro, presionar el botón «Borrar». (Fuente: página 7)

## Procedimiento: Formular un plan de acción
### Propósito
El módulo del Plan de Acción permite formular y visualizar planes de acción, así como imprimir la formulación. (Fuente: página 5)

### Pasos
1. Para formular un nuevo plan de acción, seleccionar el botón «Formular Plan». (Fuente: página 8)
2. Completar cada uno de los campos y seleccionar el botón «Siguiente». El sistema no permitirá continuar con la formulación si falta ingresar algún campo. (Fuente: página 9)
3. En la ventana de formulación, seleccionar la «Dimensión» en la que se registrarán los Objetivos, Estrategias Asociadas y Compromisos. Luego, seleccionar el botón “Agregar”. El sistema no permitirá agregar un registro si no se seleccionó previamente una Dimensión. (Fuente: página 10)
4. Ingresar los campos requeridos del formulario y seleccionar “Guardar”. Para cancelar el registro, seleccionar “Cerrar”. El sistema no permitirá guardar el registro si faltan campos requeridos. (Fuente: página 11)
5. La formulación incluye información general del proceso y el año de formulación del Plan de Acción; un listado de Objetivos, Estrategias y Compromisos; porcentajes de proyección y cumplimiento del plan; y el botón “Finalizar”, que termina la formulación del Plan de Acción. (Fuente: página 12)

### Errores, límites o excepciones documentadas
- No se puede continuar con la formulación si falta algún campo por ingresar. (Fuente: página 9)
- No se puede agregar un registro sin seleccionar previamente una Dimensión. (Fuente: página 10)
- No se puede guardar un registro si faltan campos requeridos. (Fuente: página 11)

## Procedimiento: Editar un registro de la formulación
### Pasos
1. Para editar un registro, seleccionar el ícono de la columna “acciones”. (Fuente: página 13)
2. Modificar los campos deseados y seleccionar “Guardar”. Para cancelar la edición, seleccionar “Cerrar”. (Fuente: página 14)
3. El sistema no permitirá guardar el registro si faltan campos requeridos. (Fuente: página 14)

## Procedimiento: Eliminar un registro de la formulación
### Pasos
1. Seleccionar el ícono de la columna “acciones” correspondiente al registro. (Fuente: página 15)
2. En la ventana de confirmación, seleccionar el botón de confirmación que aparece. (Fuente: página 15)

## Procedimiento: Visualizar e imprimir un plan de acción
### Pasos
1. Para visualizar un plan, seleccionar el ícono correspondiente, ubicado en el módulo principal, en la columna de acciones. (Fuente: página 16)
2. Para imprimir un plan, seleccionar el ícono correspondiente, ubicado en el módulo principal, en la columna de acciones. (Fuente: página 17)

## Procedimiento: Realizar el seguimiento de un plan de acción
### Propósito
El panel de seguimiento incluye información general del proceso y el año de formulación del Plan de Acción; un listado de Objetivos, Estrategias y Compromisos; porcentajes de proyección y cumplimiento del plan; y el botón “Finalizar”, que termina el seguimiento del Plan de Acción. (Fuente: página 20)

### Pasos
1. Para realizar el seguimiento, visualizar el plan de acción seleccionando el ícono correspondiente, ubicado en el módulo principal, en la columna de acciones. (Fuente: página 19)
2. En la ventana de seguimiento, seleccionar la «Dimensión» en la que se realizará el seguimiento de los Objetivos, Estrategias Asociadas y Compromisos. (Fuente: página 21)
3. Después de que se carguen los Objetivos, Estrategias Asociadas y Compromisos, seleccionar el ícono de la columna de acciones del registro al que se desea hacer seguimiento. (Fuente: página 22)
4. El panel de seguimiento consta de una pestaña de descripción del seguimiento, datos informativos del seguimiento, campos de ingreso de seguimiento y un listado de evidencias. (Fuente: página 23)
5. En el panel, seleccionar la pestaña correspondiente al seguimiento que se realizará y completar los campos obligatorios. El sistema no permitirá guardar el seguimiento si algún campo obligatorio no se ingresó correctamente o si no se cumplen las validaciones correspondientes. (Fuente: página 24)

### Seguimiento 1 (junio): ingresar datos y validaciones
- El campo “Valor numérico Avance 30 de Junio” tiene como valor máximo el “Valor numérico meta año”. (Fuente: página 28)
- El campo “% de Avance a 30 de Junio” se llena automáticamente al ingresar “Valor numérico Avance 30 de Junio”. (Fuente: página 28)
- El campo “% de Cumplimiento Real” se llena automáticamente al ingresar “Cumplimiento Real”. (Fuente: página 28)
- El campo “Descripción Cualitativa Avance a 30 de Junio” es obligatorio y tiene una longitud máxima de 500 caracteres. (Fuente: página 28)

### Seguimiento 2 (diciembre): ingresar datos y validaciones
- El campo “Valor numérico Avance 30 de Diciembre” tiene como valor máximo el “Valor numérico meta año” si el Objetivo o Meta no tuvo avance en el primer semestre del año. De lo contrario, su valor máximo será la diferencia entre el “Valor numérico meta año” y el “Valor numérico Avance 30 de Junio”. (Fuente: página 33)
- El campo “% de Avance Acumulado a 30 de Diciembre” se llena automáticamente al ingresar “Valor numérico Avance 30 de Diciembre”. (Fuente: página 33)
- El campo “% de Cumplimiento Real” se llena automáticamente al ingresar “Cumplimiento Real”. (Fuente: página 33)
- El campo “Descripción Cualitativa Avance a 30 de Diciembre” es obligatorio y tiene una longitud máxima de 500 caracteres. (Fuente: página 33)

## Procedimiento: Crear y guardar seguimientos de junio y diciembre
### Pasos
1. En el panel de seguimiento, seleccionar la pestaña correspondiente al seguimiento que se realizará. Completar los campos obligatorios y cargar las evidencias deseadas. Al terminar, seleccionar “Guardar”. Para salir del panel de seguimientos, seleccionar “Cerrar”. (Fuente: páginas 27 y 29)
2. El sistema no permitirá guardar el seguimiento si algún campo obligatorio no se ingresó correctamente o si no se cumplen las validaciones correspondientes. (Fuente: páginas 27 y 29)

### Carga de evidencias
1. Seleccionar “Elegir archivos” y buscar y seleccionar en el ordenador los archivos que se cargarán. Se pueden cargar uno o más archivos. (Fuente: páginas 25 y 30)
2. Los archivos y los datos ingresados solo se guardarán al seleccionar “Guardar” en el panel de seguimiento. Después de seleccionar “Guardar”, las evidencias cargadas aparecerán en el listado de evidencias, ubicado al lado derecho del panel de seguimiento. (Fuente: páginas 25 y 30)
3. Al nombrar las evidencias, tener en cuenta que:
   - El nombre no debe superar los 90 caracteres, incluidos los espacios.
   - No se deben incluir caracteres especiales.
   - El nombre debe dar cuenta del documento cargado.
   - La fuente da como ejemplos de nombres: `Informe_socializacion_PEI` y `Registro_asistencia_capacitacion_riesgos`, en vez de `SCAN00123` o `foto01`. (Fuente: páginas 25 y 30)

### Observaciones
Si el plan de acción ya cuenta con seguimientos evaluados, el botón «Observaciones» permitirá visualizar las registradas durante la evaluación. (Fuente: páginas 26 y 31)

### Visualizar y descargar evidencias
En el listado de los compromisos formulados, en la columna «Evidencias A …», seleccionar «Ver más». Se abrirá una ventana con las evidencias cargadas para ese seguimiento, que también permitirá descargarlas. (Fuente: página 35)

### Errores, límites o excepciones documentadas
- El sistema no permitirá guardar un seguimiento si algún campo obligatorio no se ingresó correctamente o si no se cumplen las validaciones correspondientes. (Fuente: páginas 24, 27 y 29)
- Los nombres de evidencia están sujetos a los límites y condiciones indicados en “Carga de evidencias”. (Fuente: páginas 25 y 30)

## Procedimiento: Crear el seguimiento anual
### Pasos
1. En el panel de seguimiento, seleccionar la pestaña correspondiente al seguimiento que se realizará. (Fuente: página 32)
2. Ingresar el campo “Descripción Avance Año”. (Fuente: página 32)
3. Seleccionar “Guardar”. Para salir del panel de seguimientos, seleccionar “Cerrar”. (Fuente: página 32)

### Errores, límites o excepciones documentadas
El sistema no permitirá guardar el seguimiento si no se han ingresado correctamente los campos obligatorios. (Fuente: página 32)

## Procedimiento: Imprimir el seguimiento del Plan de Acción
### Pasos
1. En la ventana de seguimiento, seleccionar el botón “Seguimiento” para imprimir el formato de seguimiento del Plan de Acción. (Fuente: página 34)

## Procedimiento: Generar reportes
### Propósito
El panel de reportes consta de un menú de reportes, un filtro para generar e imprimir reportes y el contenido del reporte. (Fuente: página 37)

### Reporte consolidado por proceso
1. Seleccionar cada uno de los campos del filtro: “Sede”, “Año” y “Proceso/Dependencia”. (Fuente: página 38)
2. Seleccionar “Generar” para visualizar el reporte o el ícono indicado para exportar el contenido del reporte a un archivo en formato Excel. (Fuente: página 38)
3. Para generar e imprimir el reporte, se deben seleccionar todos los campos del filtro. (Fuente: página 38)

### Reporte consolidado general
1. Seleccionar cada uno de los campos del filtro: “Sede” y “Año”. (Fuente: página 39)
2. Seleccionar “Generar” para visualizar el reporte o el ícono indicado para exportar el contenido del reporte a un archivo en formato Excel. (Fuente: página 39)
3. Para generar e imprimir el reporte, se deben seleccionar todos los campos del filtro. (Fuente: página 39)

### Reporte de observaciones
1. Seleccionar cada uno de los campos del filtro. (Fuente: página 40)
2. Seleccionar “Generar” para visualizar el reporte o el ícono indicado para exportar el contenido del reporte a un archivo en formato Excel. (Fuente: página 40)
3. Para generar e imprimir el reporte, se deben seleccionar todos los campos del filtro. (Fuente: página 40)
