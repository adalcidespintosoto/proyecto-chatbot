# Proceso de graduación en SIAAF WEB

## Información del documento
- Fuente original: `Graduar.pptx`
- Sistema o módulo: SIAAF WEB; módulo «Registro y Control Académico».
- Público o permisos mencionados por la fuente: «Portal Profesores y Administrativos»; se solicita usuario y contraseña para acceder.
- Temas incluidos: acceso al sistema, navegación al módulo «Graduar», edición de información de estudiantes graduados y proceso de graduación.

## Procedimiento: Acceder a SIAAF WEB
### Pasos
1. Desde un navegador, ingrese al sitio web de la Universidad: http://www.unisimon.edu.co/. (Fuente: diapositiva 2)
2. En el menú principal, seleccione «Portales». (Fuente: diapositiva 2)
3. Diríjase a la sección «Portal Profesores y Administrativos». (Fuente: diapositiva 3)
4. Digite su usuario y contraseña y presione el botón «Acceder». (Fuente: diapositiva 4)

## Procedimiento: Abrir el módulo «Graduar»
### Pasos
1. Luego de ingresar al sistema, seleccione el módulo «Registro y Control Académico». (Fuente: diapositiva 5)
2. Luego de ingresar al módulo, seleccione la sección «Graduar». (Fuente: diapositiva 6)
3. Al acceder al módulo, se encuentran las opciones «Graduar» y «Graduados». (Fuente: diapositiva 7)

## Procedimiento: Editar información de un estudiante graduado
### Pasos
1. En «Graduados», seleccione el icono correspondiente al estudiante. (Fuente: diapositiva 8)
2. Actualice la información necesaria en el formulario desplegado y presione «Guardar» para almacenar los cambios realizados. (Fuente: diapositiva 9)

## Procedimiento: Realizar el proceso de graduación
### Pasos
1. Complete la información de sede y código del estudiante. (Fuente: diapositiva 10)
2. Presione «Buscar». (Fuente: diapositiva 10)
3. Seleccione el programa del estudiante. (Fuente: diapositiva 10)
4. Para graduar al estudiante, presione «Graduar». (Fuente: diapositiva 11)
5. Complete la información solicitada sobre la información de graduación. (Fuente: diapositiva 12)
6. Finalice el proceso presionando «Guardar». (Fuente: diapositiva 12)
