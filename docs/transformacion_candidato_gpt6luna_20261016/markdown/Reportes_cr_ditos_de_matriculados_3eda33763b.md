# Generar reportes de créditos de matriculados en SIAAF WEB

## Información del documento
- Fuente original: `Reportes créditos de matriculados.pptx`
- Sistema o módulo: SIAAF WEB; módulos «Crédito» y «Crédito Interno».
- Público o permisos mencionados por la fuente: Se indica el acceso desde «Portal Profesores y Administrativos» y el ingreso con usuario y contraseña.
- Temas incluidos: Acceso al sistema, navegación hasta el reporte, aplicación de filtros, generación, impresión y exportación a Excel.

## Procedimiento: Generar el reporte de créditos de matriculados

### Propósito
Generar el reporte «Reportes créditos de matriculados». (Fuente: diapositivas 1, 8–10)

### Requisitos y permisos
- Acceder al portal con usuario y contraseña. La fuente no especifica requisitos adicionales ni qué personas tienen permiso. (Fuente: diapositivas 3–4)

### Pasos
1. Desde un navegador, ingresar al sitio web de la Universidad: `http://www.unisimon.edu.co/`. Seleccionar en el menú principal la opción «Portales». (Fuente: diapositiva 2)
2. Dirigirse a la sección «Portal Profesores y Administrativos». (Fuente: diapositiva 3)
3. Digitar el usuario y la contraseña para acceder al sistema y presionar el botón «Acceder». (Fuente: diapositiva 4)
4. Una vez dentro del sistema, seleccionar el módulo «Crédito». (Fuente: diapositiva 5)
5. Seleccionar la opción «Crédito Interno». (Fuente: diapositiva 6)
6. Acceder a la opción «Reportes». (Fuente: diapositiva 7)
7. Seleccionar la opción «Reportes créditos de matriculados». (Fuente: diapositiva 8)
8. Aplicar los filtros necesarios y presionar el botón «Generar». La fuente no indica cuáles son los filtros. (Fuente: diapositiva 9)
9. Para imprimir el reporte o generar un documento en Excel, seleccionar el botón correspondiente a la acción deseada. (Fuente: diapositiva 10)

### Resultado esperado
El reporte se genera y puede imprimirse o generarse como documento en Excel, según la acción seleccionada. (Fuente: diapositivas 9–10)
