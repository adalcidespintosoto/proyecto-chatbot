# Creación de una hoja de vida en SIA WEB

## Información del documento
- **Fuente original:** Nueva Hoja de Vida.pdf
- **Sistema o módulo:** SIA WEB; el documento también menciona “Inscripción”.
- **Público o permisos mencionados por la fuente:** No se mencionan.
- **Temas incluidos:** Creación de una hoja de vida y diligenciamiento del formulario.

## Procedimiento: Crear una hoja de vida

### Propósito
Crear una nueva hoja de vida y asociarla a un nivel y programa académico. (Fuente: páginas 1–4)

### Pasos
1. Ingrese al portal SIA WEB y seleccione el icono “Inscripción”. (Fuente: página 1)
2. Seleccione el botón “Nuevo”. (Fuente: página 2)
3. Seleccione el nivel y el programa académico a los que se asociará la nueva hoja de vida; luego haga clic en el botón “Siguiente”. (Fuente: página 3)
4. Diligencie el formulario completando, como mínimo, los campos obligatorios: Tipo y Número de identificación, fecha y lugar de expedición, primer nombre, primer apellido, fecha de nacimiento, número de teléfono, celular y correo electrónico. Luego haga clic en el botón “Guardar”. (Fuente: página 4)
