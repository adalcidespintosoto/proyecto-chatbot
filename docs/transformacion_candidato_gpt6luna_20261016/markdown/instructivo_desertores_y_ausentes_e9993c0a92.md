## Procedimiento: Consultar estudiantes en Desertores y Ausentes

### Requisitos y permisos
- Ingresar al sistema mediante el portal para profesores y administrativos. La fuente indica que se requiere usuario y contraseña, pero no especifica permisos adicionales. (Fuentes: diapositivas 4–5)

### Pasos
1. Desde un navegador, ingresar al sitio web de la Universidad: `http://www.unisimon.edu.co/`. En el menú principal, seleccionar «Portales». (Fuente: diapositiva 3)
2. Dirigirse a la sección «Portal Profesores y Administrativos». (Fuente: diapositiva 4)
3. Digitar el usuario y la contraseña para acceder al sistema y presionar el botón «Acceder». (Fuente: diapositiva 5)
4. Después de ingresar al sistema, seleccionar el módulo «Desertores». (Fuente: diapositiva 6)
5. En el menú de desertores, seleccionar el icono “Desertores y Ausentes”. (Fuente: diapositiva 7)
6. Completar todos los filtros: año, periodo, tipo deserción, nivel y programa. Después, presionar el botón buscar. (Fuente: diapositiva 8)

## Procedimiento: Añadir o editar la causa de un estudiante

### Propósito
Añadir o editar la causa de deserción o ausencia de un estudiante seleccionado. (Fuentes: diapositivas 9–10)

### Pasos
1. Presionar el icono señalado para añadir o editar la causa. Se desplegará una ventana para elegirla. (Fuente: diapositiva 9)
2. Escoger la causa en la lista desplegable y presionar el botón aceptar. (Fuente: diapositiva 10)

### Resultado esperado
La causa de deserción o ausencia del estudiante seleccionado se actualizará automáticamente. (Fuente: diapositiva 10)
