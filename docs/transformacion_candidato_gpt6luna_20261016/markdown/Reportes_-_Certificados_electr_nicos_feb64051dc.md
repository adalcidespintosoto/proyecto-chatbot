# Generar el reporte de certificados electrónicos en SIAAF WEB

## Información del documento
- **Fuente original:** `Reportes - Certificados electrónicos.pptx`
- **Sistema o módulo:** SIAAF WEB; módulo «Registro y Control Académico».
- **Público o permisos mencionados por la fuente:** Portal «Profesores y Administrativos».
- **Temas incluidos:** Acceso al sistema, selección del módulo y la sección «Reportes», generación, visualización, impresión y exportación del reporte.

## Procedimiento: generar un reporte de certificados electrónicos

### Propósito
Crear un reporte de certificados electrónicos para visualizarlo y, si se desea, imprimirlo o exportarlo a Excel. (Fuente: diapositivas 1, 7–8)

### Requisitos y permisos
- La fuente indica acceder por el «Portal Profesores y Administrativos» y digitar usuario y contraseña. (Fuente: diapositivas 3–4)
- La fuente no especifica requisitos adicionales para completar los filtros de búsqueda. (Fuente: diapositiva 7)

### Pasos
1. Desde un navegador, ingrese al sitio web de la Universidad: `http://www.unisimon.edu.co/`. En el menú principal, seleccione «Portales». (Fuente: diapositiva 2)
2. Diríjase a la sección «Portal Profesores y Administrativos». (Fuente: diapositiva 3)
3. Digite su usuario y contraseña para acceder al sistema y presione el botón «Acceder». (Fuente: diapositiva 4)
4. Una vez dentro del sistema, seleccione el módulo «Registro y Control Académico». (Fuente: diapositiva 5)
5. Dentro del módulo, seleccione la sección «Reportes». (Fuente: diapositiva 6)
6. Complete los filtros de búsqueda y presione el botón «Generar». Esto crea el reporte para su visualización. (Fuente: diapositiva 7)
7. Para finalizar, puede imprimir el reporte o exportarlo a Excel mediante los botones correspondientes. (Fuente: diapositiva 8)

### Resultado esperado
El botón «Generar» crea el reporte para su visualización. La fuente también indica que puede imprimirse o exportarse a Excel con los botones correspondientes. (Fuente: diapositivas 7–8)
