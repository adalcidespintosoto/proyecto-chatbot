# Solicitud y generación de certificados en el Portal de Estudiantes

## Información del documento
- **Fuente original:** `Certificados estudiantes_v2.pptx`
- **Sistema o módulo:** Portal de Estudiantes
- **Público o permisos mencionados por la fuente:** Estudiantes; la fuente indica que se debe ingresar con usuario y contraseña, pero no especifica permisos.
- **Temas incluidos:** Acceso al portal, generación del volante de pago y visualización del certificado.

## Procedimiento: Generar el volante de pago y visualizar el certificado

### Propósito
Generar el volante de pago asociado al certificado y, una vez pagado, visualizar el certificado en el portal. (Fuente: diapositivas 2, 8–10)

### Pasos
1. Desde un navegador, ingrese al sitio web de la Universidad: http://www.unisimon.edu.co/. En el menú principal, seleccione «Portales». (Fuente: diapositiva 3)
2. Diríjase a la sección «Portal estudiantes». (Fuente: diapositiva 4)
3. Seleccione la sede Barranquilla. (Fuente: diapositiva 5)
4. Digite su usuario y contraseña para acceder al sistema y presione el botón «Acceder». (Fuente: diapositiva 6)
5. Seleccione el apartado «certificados». (Fuente: diapositiva 7)
6. Para generar el volante de pago, seleccione el icono señalado. (Fuente: diapositiva 8)
7. Seleccione el programa y, posteriormente, marque el periodo. Luego presione el botón «generar» para generar el volante de pago. (Fuente: diapositiva 9)
8. Una vez que el volante se encuentre pagado, busque en la parte derecha el certificado, que se podrá visualizar con el icono señalado. (Fuente: diapositiva 10)

### Resultado esperado
El volante de pago se genera después de seleccionar el programa y el periodo y presionar «generar». Una vez pagado el volante, el certificado se puede visualizar en la parte derecha mediante el icono señalado. (Fuente: diapositivas 9–10)
