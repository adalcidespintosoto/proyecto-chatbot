# Parametrización de factores y causas en SIAAF WEB

## Información del documento
- **Fuente original:** `instructivo parametrizacion desertores y ausentes.pptx`
- **Sistema o módulo:** SIAAF WEB; módulo «Desertores». (Fuente: diapositivas 2, 6)
- **Público o permisos mencionados por la fuente:** Portal Profesores y Administrativos. Se solicita ingresar usuario y contraseña, pero no se especifica quién tiene permisos para parametrizar factores y causas. (Fuente: diapositivas 4–5)
- **Temas incluidos:** Acceso al sistema y creación de factores y causas. (Fuente: diapositivas 3–12)

## Procedimiento: Acceso al módulo «Desertores»

### Pasos
1. Desde un navegador, ingrese al sitio web de la Universidad: `http://www.unisimon.edu.co/`. Seleccione en el menú principal la opción «Portales». (Fuente: diapositiva 3)
2. Diríjase a la sección «Portal Profesores y Administrativos». (Fuente: diapositiva 4)
3. Digite su usuario y contraseña para acceder al sistema y presione el botón «Acceder». (Fuente: diapositiva 5)
4. Luego de ingresar al sistema, seleccione el módulo «Desertores». (Fuente: diapositiva 6)

## Procedimiento: Parametrizar factores y causas

### Propósito
Parametrizar factores y causas en el módulo «Desertores» de SIAAF WEB. (Fuente: diapositivas 2, 6–7)

### Pasos
1. Para crear un factor, presione el botón señalado; se desplegará una ventana. (Fuente: diapositiva 8)
2. Cree el factor y, posteriormente, presione el botón «aceptar». El listado anterior se actualizará automáticamente. (Fuente: diapositiva 9)
3. Para añadir una causa a un factor, presione el icono del «mas» señalado en pantalla. Se desplegará una ventana con opciones. (Fuente: diapositiva 10)
4. Presione «crear causa». Se desplegará una ventana para añadir la causa. (Fuente: diapositiva 11)
5. Una vez creada la causa, se actualizará el listado de causas asociadas a ese factor. (Fuente: diapositiva 12)
