# Manual de usuario del Sistema Administrativo de Ingreso — Registro de Ingreso

## Información del documento
- **Fuente original:** *Manual de Usuario - Registro de Ingreso.pdf*
- **Sistema o módulo:** Sistema Administrativo de Ingreso; el documento también lo identifica como Portal CovidApp.
- **Público o permisos mencionados por la fuente:** Funcionarios o encargados del control de ingreso; usuarios con perfil lector; estudiantes, funcionarios, contratistas y visitantes. La autorización de contratistas y visitantes se gestiona por medio de Bienestar Laboral.
- **Temas incluidos:** Acceso y sesión; módulos personales y de salud; código QR; lectura de ingreso; registro de contratistas y visitantes; creación de visitantes.
- **Nota sobre el contenido visual:** Algunas páginas incluyen descripciones automáticas de imágenes que no están verificadas. Se señalan en «Puntos por validar» cuando su contenido no coincide claramente con el texto del procedimiento.

## Procedimiento: Acceder al sistema e iniciar sesión

### Propósito
Ingresar al Sistema Administrativo de Ingreso mediante el enlace indicado en el manual. (Fuente: páginas 2–4)

### Requisitos y permisos
- El funcionario o encargado de controlar el ingreso debe utilizar el usuario y la contraseña creados para cada sede específica. (Fuente: página 4)

### Pasos
1. Acceder a `https://covidapp.unisimon.edu.co`. El manual identifica el enlace como «Link de acceso sistema administrativo de ingreso – Portal CovidApp». (Fuente: página 3)
2. Digitar el usuario y la contraseña creados para la sede específica. (Fuente: página 4)

### Resultado esperado
Al iniciar sesión, se muestra el dashboard o página de aterrizaje. El usuario tiene acceso a los módulos habilitados según su perfil. (Fuente: página 5)

## Procedimiento: Usar los módulos habilitados para el perfil lector

### Propósito
El perfil lector corresponde a usuarios que realizan la gestión de ingreso de estudiantes y funcionarios. Sus funciones se centran en el módulo «Tomar Lecturas». (Fuente: páginas 6, 11)

### Requisitos y permisos
- El usuario debe tener asignado el perfil lector. (Fuente: página 6)
- Con ese perfil también aparecen habilitados los módulos «Datos Personales», «Factores de Riesgo», «Encuesta de Sintomatología» e «Ingreso», pero el usuario con este perfil no tiene que diligenciarlos. (Fuente: página 6)

### Pasos
1. Iniciar sesión y localizar en el dashboard los módulos habilitados según el perfil. (Fuente: páginas 5–6)
2. Para gestionar la toma de lecturas, ingresar a la opción «Tomar Lecturas». Esta opción muestra opciones adicionales. (Fuente: página 11)
3. En «Tomar Lecturas», las opciones indicadas son «Lector ingreso», «Visitantes» y «Volver al menú principal». (Fuente: página 12)

### Errores, límites o excepciones documentadas
- Aunque los módulos personales, de factores de riesgo, sintomatología e ingreso aparecen habilitados para el perfil lector, el manual indica que esos usuarios no tienen que diligenciarlos. (Fuente: página 6)

## Procedimiento: Consultar o actualizar datos personales

### Propósito
Ver la información básica del usuario en la opción «Datos Personales» y actualizarla si es necesario. (Fuente: página 7)

### Pasos
1. Ingresar a la opción «Datos Personales». (Fuente: página 7)
2. Revisar la información básica y actualizarla si se requiere. (Fuente: página 7)

## Procedimiento: Registrar o actualizar factores de riesgo

### Pasos
1. Si se presenta alguna de las condiciones de salud descritas en el listado, seleccionar la que corresponda. (Fuente: página 8)
2. Seleccionar el botón «Guardar». (Fuente: página 8)
3. Si no se presenta ninguna condición de salud preexistente, seleccionar inmediatamente «Guardar». (Fuente: página 8)

### Resultado esperado
La encuesta queda diligenciada. (Fuente: página 8)

### Errores, límites o excepciones documentadas
- La encuesta se diligencia una sola vez, salvo que cambie la condición de salud; si cambia, se debe actualizar. (Fuente: página 8)

## Procedimiento: Completar la encuesta diaria de sintomatología

### Propósito
La encuesta de síntomas es obligatoria diariamente para ingresar a la institución. (Fuente: página 9)

### Pasos
1. Realizar la encuesta de síntomas cada día. (Fuente: página 9)
2. Si se presenta algún síntoma, marcarlo y guardar la información. (Fuente: página 9)
3. Si no se presenta ningún síntoma, seleccionar «Guardar». (Fuente: página 9)

### Errores, límites o excepciones documentadas
- La encuesta se diligencia una sola vez al día, salvo que cambie la condición de salud. Si cambia, se debe actualizar. (Fuente: página 9)

## Procedimiento: Mostrar el código QR para ingresar a la institución

### Pasos
1. Después de realizar la encuesta de síntomas, ingresar a la sección «Ingreso». (Fuente: página 10)
2. Mostrar el código QR al personal de seguridad al momento de ingresar a la institución. (Fuente: página 10)

### Resultado esperado
El código QR se utiliza para presentarlo al personal de seguridad durante el ingreso. (Fuente: página 10)

### Errores, límites o excepciones documentadas
- El código QR tiene una vigencia de 3 minutos. Si expira, se debe generar uno nuevo accediendo nuevamente a la sección «Ingreso». (Fuente: página 10)

## Procedimiento: Registrar el ingreso de estudiantes o funcionarios con QR

### Propósito
Registrar el ingreso mediante la lectura del QR presentado por el estudiante o funcionario. El módulo también ofrece una opción para registrar el ingreso sin QR. (Fuente: páginas 13–14, 19)

### Pasos
1. Ingresar a «Lector ingreso» dentro del módulo «Tomar Lecturas». (Fuente: páginas 11–13)
2. Seleccionar la opción «Con QR». (Fuente: páginas 13–14)
3. Si es la primera vez que se selecciona «Con QR», aceptar que se comparta la cámara del dispositivo para realizar el escaneo. (Fuente: página 14)
4. Enfocar el código QR presentado por el usuario. El sistema valida la información y determina si el código es válido. (Fuente: página 14)
5. Si el código es válido, revisar la información del estudiante o funcionario que se muestra. (Fuente: página 15)
6. Seleccionar obligatoriamente la temperatura indicada por el termómetro láser o pistola de temperatura. Las opciones descritas son «Menor a 38° C» y «Mayor o igual a 38°C». (Fuente: páginas 16–17)
7. Completar el área a la cual se dirige el estudiante o funcionario si se desea: este campo es opcional y puede dejarse en blanco. (Fuente: página 16)
8. Registrar el ingreso. (Fuente: páginas 16–18)
9. Si se selecciona «Mayor o igual a 38° C» y se registra el ingreso, el sistema emite una advertencia. Se recomienda solicitar al estudiante o funcionario que espere a un lado y continuar escaneando y registrando a los demás usuarios mientras se comunica con el área encargada: Bienestar Universitario o Bienestar Laboral, para determinar el proceso a seguir. (Fuente: página 17)

### Resultado esperado
- Si se registra una temperatura «Menor a 38° C», el sistema emite un mensaje informativo de bienvenida y confirma que el registro se guardó; después de esto, el estudiante o funcionario puede ingresar a la institución. (Fuente: página 18)
- Si el QR es válido, se muestra la información del estudiante o funcionario. (Fuente: página 15)

### Errores, límites o excepciones documentadas
- Si el QR está vencido, el sistema notifica que expiró su vigencia. Se debe informar al estudiante o funcionario que regrese a su menú principal e ingrese nuevamente a «Ingreso» para generar otro QR vigente. (Fuente: página 15)
- El manual recomienda que todos los usuarios presenten su QR para que el proceso de ingreso sea más rápido. (Fuente: página 14)
- El texto de la advertencia de temperatura que aparece en la descripción automática de la imagen de la página 17 no coincide claramente con la explicación del procedimiento; se registra en «Puntos por validar». (Fuente: página 17)

## Procedimiento: Registrar el ingreso de estudiantes o funcionarios sin QR

### Requisitos y permisos
- Esta opción se puede usar si el estudiante o funcionario no puede mostrar su código QR y notifica que sí realizó la encuesta diaria de sintomatología. (Fuente: página 19)

### Pasos
1. En «Lector ingreso», seleccionar la opción «Sin QR». (Fuente: páginas 13, 19)
2. En el formulario, ingresar el tipo de documento, el documento de identificación y la temperatura de ingreso. (Fuente: página 19)
3. Ingresar el área a la que se dirige solo si se desea; este dato es opcional. (Fuente: página 19)
4. Registrar el ingreso. (Fuente: páginas 19–20)

### Resultado esperado
- Si la información registrada es correcta, el sistema notifica que es válida y el usuario puede ingresar a la institución. (Fuente: página 20)

### Errores, límites o excepciones documentadas
- Si el sistema detecta que el usuario todavía no realizó la encuesta de sintomatología, notifica al vigilante o funcionario que efectúa el registro. Este debe informar al usuario que no puede ingresar hasta completar la encuesta. (Fuente: página 20)

## Procedimiento: Registrar el ingreso de contratistas y visitantes desde el módulo «Visitantes»

### Propósito
El módulo «Visitantes» permite realizar distintas funciones, incluido el registro de ingreso de contratistas y visitantes. (Fuente: página 21)

### Requisitos y permisos
- Contratistas y visitantes no tienen acceso al sistema. Su configuración y autorización deben ser gestionadas por Bienestar Laboral. (Fuente: página 22)
- Al llegar a la institución, el contratista o visitante debe presentarse en garita o ante el funcionario que esté realizando el control de ingreso. (Fuente: página 22)

### Pasos
1. Ingresar al módulo «Visitantes». (Fuente: páginas 21–22)
2. En el formulario de búsqueda, ingresar el tipo y número de documento del contratista o visitante. (Fuente: página 22)
3. Si se encuentra un contratista o visitante, continuar con el registro de ingreso correspondiente. El módulo está destinado a registrar a contratistas y visitantes que pretendan ingresar a la institución. (Fuente: página 22)

### Errores, límites o excepciones documentadas
- Si la fecha de ingreso del contratista o visitante está vencida, el sistema lo notifica al funcionario que realiza el registro, quien debe seguir la información indicada en el mensaje. (Fuente: página 23)
- Si el contratista o visitante está bloqueado, el sistema lo notifica al funcionario que realiza el registro, quien debe seguir la información indicada en el mensaje. (Fuente: página 23)
- La descripción automática de la imagen de la página 23 menciona una fecha concreta de vencimiento, pero no queda claro que corresponda al aviso descrito en el texto del procedimiento. No se incorpora como instrucción vigente. (Fuente: página 23)

## Procedimiento: Registrar el ingreso de un contratista

### Pasos
1. Buscar al contratista desde el módulo «Visitantes» con su tipo y número de documento. (Fuente: página 22)
2. Si la información del contratista es válida, revisar la información básica que muestra el sistema. (Fuente: página 24)
3. Completar la encuesta breve: reportar los síntomas y responder las preguntas. Si no presenta alguno de los síntomas, no marcarlo. Si ninguna pregunta aplica, responder «NO». (Fuente: página 25)
4. Diligenciar el área a la que se dirige y la temperatura de ingreso. Ambos datos son obligatorios. (Fuente: página 26)
5. Completar el registro de ingreso. (Fuente: páginas 24–26)

### Resultado esperado
Se completa el registro de ingreso del contratista. (Fuente: páginas 24–26)

### Errores, límites o excepciones documentadas
- Como sugerencia, se recomienda realizar este proceso desde el computador dispuesto en garita para registrar la información más rápido. (Fuente: página 26)
- Para escanear el código QR de estudiantes o funcionarios, se recomienda utilizar la tableta habilitada en cada sede para mayor comodidad. (Fuente: página 26)

## Procedimiento: Registrar el ingreso de un visitante

### Pasos
1. Buscar al visitante desde el módulo «Visitantes» con su tipo y número de documento. (Fuente: página 22)
2. Una vez encontrado por el sistema, revisar el formulario con su información básica. Esa información puede actualizarse durante el proceso de ingreso. (Fuente: página 27)
3. Completar la encuesta breve: reportar los síntomas y responder las preguntas. Si no presenta alguno de los síntomas, no marcarlo. Si ninguna pregunta aplica, responder «NO». (Fuente: página 28)
4. Diligenciar el área a la que se dirige y la temperatura de ingreso. Ambos datos son obligatorios. (Fuente: página 29)
5. Completar el registro de ingreso. (Fuente: páginas 27–29)

### Resultado esperado
Se completa el registro de ingreso del visitante. (Fuente: páginas 27–29)

### Errores, límites o excepciones documentadas
- Como sugerencia, se recomienda realizar el proceso desde el computador dispuesto en garita para registrar la información más rápido. (Fuente: página 29)

## Procedimiento: Volver a registrar el ingreso de un contratista o visitante

### Pasos
1. Si el contratista o visitante se desplaza entre sedes, o necesita entrar nuevamente a la misma sede y el vigilante o funcionario le solicita repetir el registro, seguir el flujo de registro de ingreso. (Fuente: página 30)
2. Si el sistema indica que la encuesta de síntomas ya fue diligenciada y pregunta si se desea actualizarla, decidir si se actualiza la información. (Fuente: página 30)
3. Si no se necesita actualizarla, seleccionar «NO» y finalizar el registro de ingreso para que quede constancia en el sistema. (Fuente: página 30)

## Procedimiento: Crear un visitante

### Requisitos y permisos
- Los visitantes que no se encuentren registrados al presentarse en garita o ante el funcionario encargado pueden ser creados desde la opción de creación indicada en el módulo. (Fuente: página 31)
- Los contratistas solo pueden ser creados por personal autorizado de Bienestar Laboral, porque deben cumplir procesos administrativos para su autorización previa. (Fuente: página 31)

### Pasos
1. Ingresar a la opción de creación de visitantes. (Fuente: páginas 31–32)
2. Completar el formulario con la información básica del visitante. (Fuente: página 32)
3. Responder la encuesta de síntomas. (Fuente: página 32)
4. Ingresar el área de visita y la temperatura de ingreso para registrar al visitante. (Fuente: página 32)

### Resultado esperado
Una vez creado el visitante, no es necesario volver a crearlo en una visita posterior. Basta con buscarlo por tipo y número de documento y realizar el registro de ingreso. (Fuente: página 32)
