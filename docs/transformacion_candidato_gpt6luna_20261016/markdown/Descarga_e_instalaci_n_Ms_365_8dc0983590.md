# Descarga e instalación de Office

## Información del documento
- **Fuente original:** `Descarga e instalación Ms 365.pdf`
- **Sistema o módulo:** Microsoft Office; el archivo fuente también lo identifica como Ms 365.
- **Público o permisos mencionados por la fuente:** Se indica el uso del correo institucional de Microsoft y de credenciales indicadas en el Portal de Gestión Académico-Administrativa. No se especifica quiénes pueden realizar el trámite.
- **Temas incluidos:** Inicio de sesión, descarga e instalación de Office y aceptación del contrato de licencia.

## Procedimiento: descarga e instalación de Office

### Propósito
Descargar e instalar Office. (Fuente: páginas 1–11)

### Requisitos y permisos
- Iniciar sesión con el correo institucional de Microsoft desde el sitio web de Unisimon, en la sección **Servicios → Correo Funcionarios Microsoft**. (Fuente: página 2)
- Iniciar sesión con el usuario y la clave indicados en el **Portal de Gestión Académico-Administrativa**. (Fuente: página 3)

### Pasos
1. Inicie sesión en su correo institucional de Microsoft desde el sitio web de Unisimon, en **Servicios → Correo Funcionarios Microsoft**. (Fuente: página 2)
2. Inicie sesión con su usuario y contraseña de Microsoft; la fuente indica usar el usuario y la clave indicados en el **Portal de Gestión Académico-Administrativa**. (Fuente: página 3)
3. Seleccione el botón **«Instalar Office»** en el panel principal. (Fuente: página 4)
4. Seleccione la opción **«Otras opciones de instalación»**. (Fuente: página 5)
5. Seleccione el botón **«Instalar Office»**. (Fuente: página 6)
6. Guarde en su equipo el archivo que se descargue. (Fuente: página 7)
7. Siga las instrucciones para continuar con el proceso de instalación. (Fuente: página 8)
8. Espere mientras se realiza la instalación. (Fuente: página 9)
9. Cuando la instalación haya finalizado, haga clic en **«Cerrar»**. (Fuente: página 10)
10. Al ingresar a alguna de las nuevas herramientas de Office, acepte el contrato de licencia. (Fuente: página 11)
