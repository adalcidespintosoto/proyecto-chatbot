# Gestión de caracterización de estudiantes

## Información del documento
- **Fuente original:** Gestión de caracterización.pdf
- **Sistema o módulo:** Gestión de Caracterización
- **Público o permisos mencionados por la fuente:** No se especifican.
- **Temas incluidos:** Ingreso al portal, búsqueda de estudiantes por nivel, programa académico y semestre; activación del formulario de caracterización; consulta de la hoja de vida; descarga del listado en Excel.

## Procedimiento: Ingresar al portal y abrir Gestión de Caracterización

### Pasos
1. Desde la página web de la universidad, ingrese a la sección «Portales»: http://www.unisimon.edu.co/portales/administrativos. (Fuente: página 3)
2. Ingrese su usuario y contraseña y presione el botón «Acceder». (Fuente: página 3)
3. Seleccione el icono «Bienestar». (Fuente: página 4)
4. Seleccione el icono «Caracterización». (Fuente: página 5)

## Procedimiento: Buscar estudiantes y gestionar su caracterización

### Pasos
1. Seleccione el nivel y el programa académico. (Fuente: página 6)
2. Seleccione el semestre. (Fuente: página 6)
3. Haga clic en el botón «Buscar». (Fuente: página 6)
4. En el listado de estudiantes, para activar el formulario de caracterización de un estudiante, seleccione el icono «Activar caracterización». (Fuente: página 7)
5. Para visualizar toda la información de caracterización, seleccione el icono «Hoja de vida». (Fuente: página 7)
6. Para descargar el listado, seleccione el botón «Excel». (Fuente: página 8)

### Resultado esperado
- Después de la búsqueda, se listan todos los estudiantes. (Fuente: página 7)
- El icono «Hoja de vida» permite visualizar toda la información de caracterización. (Fuente: página 7)
- La fuente indica que el botón «Excel» sirve para descargar el listado. (Fuente: página 8)
