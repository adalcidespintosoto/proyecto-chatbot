# Gestión de ingreso de estudiantes

## Información del documento
- **Fuente original:** *Gestión de Ingreso - Solo Consulta.pdf*
- **Sistema o módulo:** Gestión de Ingreso de Estudiantes
- **Público o permisos mencionados por la fuente:** Las opciones de Proceso, Niveles y Programas dependen de los permisos asociados al usuario. Aprobar requisitos está sujeto a permisos de usuario; aprobar documentos cargados corresponde a un usuario del área u oficina responsable del requisito. Editar campos de la Hoja de vida requiere permiso para editarlos.
- **Temas incluidos:** Ingreso al portal, consulta de aspirantes, verificación y aprobación de requisitos, confirmación de inscripción y consulta o edición de la Hoja de vida.

## Procedimiento: Consultar aspirantes

### Propósito
El módulo permite consultar y gestionar el proceso de admisión de un aspirante, desde la inscripción hasta la matrícula. (Fuente: página 4)

### Requisitos y permisos
Las opciones disponibles en los campos **Proceso**, **Niveles** y **Programas** dependen de los permisos asociados al usuario. (Fuente: páginas 4–5)

### Pasos
1. Desde la página web de la universidad, ingrese a la sección **“Portales”**: http://www.unisimon.edu.co/portales/administrativos. (Fuente: página 2)
2. Ingrese su usuario y contraseña y presione el botón **“Acceder”**. (Fuente: página 2)
3. Una vez dentro del Portal, seleccione **“Gestión de Ingreso de Estudiantes”**. (Fuente: página 3)
4. Para realizar la consulta, seleccione el proceso, periodo, nivel y programa académico. (Fuente: página 5)
5. De manera opcional, personalice la búsqueda mediante las opciones del campo **“Tipo de Búsqueda”** e ingrese un texto en el campo **“Buscar”**. (Fuente: página 5)
6. Seleccione el botón **“Buscar”**. (Fuente: página 5)

## Procedimiento: Revisar requisitos y confirmar la inscripción

### Propósito
Consultar los requisitos que debe cargar el aspirante y realizar las acciones disponibles para verificarlos. Cuando todos los requisitos estén aprobados, se puede confirmar la inscripción. (Fuente: páginas 7–8)

### Requisitos y permisos
- Aprobar un requisito está sujeto a los permisos del usuario. (Fuente: páginas 7–8)
- Los documentos cargados por el aspirante deben ser aprobados por un usuario del área u oficina responsable de ese requisito. (Fuente: página 8)
- Las pruebas o evaluaciones son verificadas automáticamente por el sistema cuando se realizan; el sistema marca entonces el requisito como **“realizado”**. (Fuente: página 8)

### Pasos
1. Después de buscar un aspirante, seleccione el botón **“Requisitos”**. Aparecerá una ventana con todos los requisitos que el aspirante debe cargar. (Fuente: páginas 6–7)
2. Para cada requisito, puede realizar las acciones siguientes:
   - **Aprobar:** acción sujeta a permisos de usuario. En el caso de documentos cargados, la aprobación corresponde a un usuario del área u oficina responsable del requisito. (Fuente: páginas 7–8)
   - **Ver:** permite observar y posteriormente descargar los requisitos que sean documentos cargados. (Fuente: página 8)
   - **Actualizar/modificar documento:** permite reemplazar un archivo cargado por el aspirante si no cumple con lo solicitado o está dañado. (Fuente: página 8)
3. Una vez que todos los requisitos estén aprobados, seleccione **“Confirmar inscripción”**. (Fuente: página 7)

### Resultado esperado
Al realizarse una prueba o evaluación, el sistema marca el requisito correspondiente como **“realizado”**. Cuando todos los requisitos estén aprobados, se puede seleccionar **“Confirmar inscripción”**. (Fuente: páginas 7–8)

## Procedimiento: Consultar o modificar la Hoja de vida

### Propósito
Consultar los datos que el aspirante registró durante el proceso en trámite. (Fuente: página 9)

### Requisitos y permisos
Editar campos del formulario requiere contar con el permiso correspondiente. (Fuente: página 9)

### Pasos
1. Después de buscar un aspirante, seleccione el botón **“Hoja de vida”**. Aparecerá una ventana con todos los datos que el aspirante registró durante el proceso en trámite. (Fuente: páginas 6 y 9)
2. Si cuenta con permiso para editar campos, aparecerá el botón **“Guardar”**. Selecciónelo para finalizar cualquier modificación que realice. (Fuente: página 9)
