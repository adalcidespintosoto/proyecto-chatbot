# Instructivo del módulo Verificación de pagos

## Información del documento
- **Fuente original:** *Instructivo Verificación pagos V2.pdf*
- **Sistema o módulo:** Matrícula → Verificación de pagos
- **Público o permisos mencionados por la fuente:** No se especifican.
- **Temas incluidos:** Ingreso al portal, acceso al módulo, filtros de búsqueda, filtrado de resultados por columna y exportación a Excel.

## Procedimiento: Ingresar al módulo Verificación de pagos

### Pasos
1. Desde la página web de la universidad, ingrese en la sección «Portales» mediante `http://www.unisimon.edu.co/portales/administrativos`. Ingrese su usuario y contraseña y presione «Acceder». (Fuente: página 3)
2. Seleccione el módulo «Matrícula». (Fuente: página 4)
3. Seleccione el módulo «Verificación de pagos». (Fuente: página 5)

## Procedimiento: Buscar registros en Verificación de pagos

### Pasos
1. Use los filtros obligatorios. Además, hay tres búsquedas diferentes según lo requerido; cada tipo de búsqueda activa campos específicos. (Fuente: página 6)
2. Diligencie los campos de la búsqueda y seleccione «Buscar». (Fuente: página 6)
3. Una vez listados los resultados, puede filtrar cada columna de la tabla según las coincidencias encontradas con la cadena de texto o número que escriba. (Fuente: página 7)

### Errores, límites o excepciones documentadas
- La fuente indica que hay filtros obligatorios y filtros adicionales, pero no especifica cuáles son sus campos. (Fuente: página 6)
- La fuente indica que existen tres tipos de búsqueda, pero no identifica sus nombres ni los campos que activa cada tipo. (Fuente: página 6)

## Procedimiento: Exportar el listado a Excel

### Pasos
1. Para exportar a formato Excel el listado resultante, seleccione el botón «Exportar». (Fuente: página 8)

### Resultado esperado
- Se exporta el listado resultante a formato Excel. (Fuente: página 8)
