# Instructivo para el uso del aplicativo de Evaluación CAQ

## Información del documento
- **Fuente original:** *Manual Evaluación CAQ - Funcionarios.pdf*.
- **Sistema o módulo:** Aplicativo de Evaluación CAQ.
- **Público o permisos mencionados por la fuente:** El documento se titula “Manual ... Funcionarios” y señala que se debe seleccionar la opción “Funcionarios”. No especifica permisos. (Fuente: páginas 1–2)
- **Temas incluidos:** Acceso al aplicativo; creación, edición y eliminación de ofertas de evaluación CAQ; generación y visualización de reportes. (Fuente: páginas 2–15)

## Procedimiento: Acceder al aplicativo de Evaluación CAQ

### Pasos
1. Desde un navegador, ingrese al sitio web de la Universidad: `http://www.unisimon.edu.co/`. (Fuente: página 2)
2. En el menú principal, seleccione la opción “Funcionarios”. (Fuente: página 2)
3. Diríjase a la sección “Servicios Web” y seleccione “Evaluación CAQ”. (Fuente: página 3)
4. Ingrese su usuario y contraseña y presione el botón “Ingresar”. (Fuente: página 4)

## Procedimiento: Crear una oferta de evaluación CAQ

### Pasos
1. Luego de ingresar al sistema, seleccione el módulo “Configuración”. (Fuente: página 5)
2. Para crear una oferta de evaluación CAQ, presione el botón “Crear”. (Fuente: página 6)
3. Diligencie los campos y presione el botón “Guardar”. (Fuente: página 7)

### Errores, límites o excepciones documentadas
- El sistema no permitirá guardar la oferta si falta algún campo requerido. (Fuente: página 7)

## Procedimiento: Editar una oferta de evaluación CAQ

### Pasos
1. En el módulo “Configuración”, presione el ícono “Editar”. (Fuente: página 8)
2. Edite los campos necesarios y presione el botón “Guardar”. (Fuente: página 9)

### Errores, límites o excepciones documentadas
- El sistema no permitirá guardar la oferta si falta algún campo requerido. (Fuente: página 9)

## Procedimiento: Eliminar una oferta de evaluación CAQ

### Pasos
1. En el módulo “Configuración”, presione el ícono “Borrar”. (Fuente: página 10)
2. En la ventana emergente, presione el botón “si”. (Fuente: página 10)

## Procedimiento: Generar y visualizar un reporte de evaluación

### Pasos
1. Luego de ingresar, seleccione el módulo “Reportes”. (Fuente: página 11)
2. Seleccione el período y el programa académico sobre el que desee realizar la búsqueda. (Fuente: página 12)
3. Presione el botón “Generar”. (Fuente: página 13)
4. Presione el ícono “Imprimir” de la evaluación que desee visualizar. (Fuente: página 14)
5. A continuación, podrá visualizar el reporte de la evaluación seleccionada. (Fuente: página 15)

## Palabras y formas de búsqueda
