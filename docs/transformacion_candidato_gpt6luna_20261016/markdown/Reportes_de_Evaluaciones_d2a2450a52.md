# Generación de reportes de evaluaciones en SIAAF WEB — Bienestar

## Información del documento

- **Sistema o módulo:** SIAAF WEB; módulo Bienestar.
- **Público o permisos mencionados por la fuente:** Se indica el acceso a «Portal Profesores y Administrativos». No se especifican permisos adicionales.
- **Temas incluidos:** Acceso al sistema, navegación al módulo de evaluaciones, generación de reportes, descarga de un reporte y restablecimiento de una prueba de un estudiante.

## Procedimiento: Generar y descargar reportes de evaluaciones

### Propósito
Generar el listado de evaluaciones realizadas y generar el reporte que se desea descargar. (Fuente: diapositivas 8–9)

### Requisitos y permisos
- Se requiere ingresar al sistema con usuario y contraseña. No se reproducen credenciales. (Fuente: diapositiva 4)
- La ruta de acceso indicada es «Portal Profesores y Administrativos». (Fuente: diapositivas 2–4)

### Pasos
1. Desde un navegador, ingrese al sitio web de la Universidad: `http://www.unisimon.edu.co/`. En el menú principal, seleccione «Portales». (Fuente: diapositiva 2)
2. Diríjase a la sección «Portal Profesores y Administrativos». (Fuente: diapositiva 3)
3. Digite su usuario y contraseña y presione el botón «Acceder». (Fuente: diapositiva 4)
4. Luego de ingresar, seleccione el módulo «Bienestar». (Fuente: diapositiva 5)
5. Seleccione el icono «Evaluaciones». (Fuente: diapositiva 6)
6. Ingrese a la sección «Reportes de Evaluaciones». (Fuente: diapositiva 7)
7. Seleccione los filtros de búsqueda para generar el listado de evaluaciones realizadas y presione el botón «Generar». (Fuente: diapositiva 8)
8. Ubique el reporte que desea descargar y presione el botón indicado para generarlo. La diapositiva no permite identificar el texto o icono del botón. (Fuente: diapositiva 9)

### Resultado esperado
Se genera el listado de evaluaciones realizadas y, al seleccionar el botón correspondiente al reporte, se genera el reporte que se desea descargar. La fuente no describe el formato ni el destino de la descarga. (Fuente: diapositivas 8–9)

## Procedimiento: Restablecer la prueba de un estudiante
