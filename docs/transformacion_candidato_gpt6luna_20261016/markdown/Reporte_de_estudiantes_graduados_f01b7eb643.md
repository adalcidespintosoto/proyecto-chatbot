# Generar el reporte de estudiantes graduados en SIAAF WEB

## Información del documento
- Fuente original: `Reporte de estudiantes graduados.pptx`
- Sistema o módulo: SIAAF WEB; módulo «Estadísticas Institucionales».
- Público o permisos mencionados por la fuente: «Profesores y Administrativos».
- Temas incluidos: Acceso al sistema y generación del reporte de estudiantes graduados.

## Procedimiento: Generar el reporte de estudiantes graduados

### Propósito
Generar el reporte de estudiantes graduados. (Fuente: diapositivas 1 y 7–8)

### Requisitos y permisos
- Dirigirse al «Portal Profesores y Administrativos». (Fuente: diapositiva 3)
- Digitar el usuario y la contraseña para acceder al sistema. (Fuente: diapositiva 4)

### Pasos
1. Desde un navegador, ingresar al sitio web de la Universidad: http://www.unisimon.edu.co/ y seleccionar en el menú principal la opción «Portales». (Fuente: diapositiva 2)
2. Dirigirse a la sección «Portal Profesores y Administrativos». (Fuente: diapositiva 3)
3. Digitar el usuario y la contraseña para acceder al sistema y presionar el botón «Acceder». (Fuente: diapositiva 4)
4. Luego de ingresar al sistema, seleccionar el módulo «Estadísticas Institucionales». (Fuente: diapositiva 5)
5. En la sección «Estudiantes», seleccionar la sede en la cual se generará el reporte. (Fuente: diapositiva 6)
6. Para generar el reporte, presionar el botón «Ver» en la sección «Distribución de estudiantes graduados». (Fuente: diapositiva 7)
7. Seleccionar el filtro, el tipo de visualización, el Año y Periodo; posteriormente, presionar el botón «Generar». (Fuente: diapositiva 8)

## Palabras y formas de búsqueda
Paráfrasis editoriales para mejorar la búsqueda; no son afirmaciones adicionales del documento: reporte de graduados, reporte de estudiantes graduados, distribución de estudiantes graduados, generar estadísticas de graduados, Estadísticas Institucionales, SIAAF WEB.

## Puntos por validar
- La diapositiva 7 contiene la frase «presionar el botón “Ver” el la sección». Se interpreta como una referencia al botón «Ver» en esa sección, pero la errata «el la» no puede confirmarse frente al documento visual original.
- La diapositiva 8 indica seleccionar «el filtro», pero no especifica qué filtro ni sus opciones.
- No se detallan las opciones disponibles para el tipo de visualización, el Año y Periodo, ni el resultado que aparece después de presionar «Generar».
